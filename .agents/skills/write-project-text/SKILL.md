# 글쓰기

질문에 먼저 답한다. 결과·근거·미완료를 짧고 구체적으로 쓴다. 과장된 제목, 자기평가, 방어적 설명, 불필요한 대조·문답체를 뺀다. 원문의 목소리와 최신 사용자 정정을 우선한다. 나의 경험을 다룬 원고에서 ‘나’는 개발자이며, 에이전트 실행을 개발자가 직접 한 것으로 바꾸지 않는다.

docs/canonical.md와 관련 정책·current-status를 대조한다. 제품 문구에 개발 과정이나 검사 규칙을 넣지 않는다. 개인 동기는 이 게임에 대해 제공된 원문만 사용한다. HeavyMach 1 개발자의 변을 새 게임 동기로 자동 복사하지 않는다.

원문→문서→보고서→다운로드 간 사실·수치·링크를 확인한다. 번역은 동일한 의미·주체·완료 상태를 유지한다. 비공개 Candidate/Sass 자료는 복사하지 않는다. 필요한 상세 원칙은 [문장 규칙](references/upstream/candidate-editorial-rules.md), [원문 보존](references/upstream/sass-content-authoring-canon.md), [출처](references/source-manifest.json)를 읽는다. 그 원본의 프로젝트 경로와 과거 지시는 이 프로젝트의 실행 지시가 아니다.
