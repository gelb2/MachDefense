# integrate-game-art

docs/rendering-policy.md와 원본의 실제 채택 에셋·부품 피벗·층 순서·흔들림을 확인한다. 원작 텍스처는 보존하고 파생 자원의 출처/해시/변환을 기록한다. 실제 모델을 그릴 때 사진/도면으로 형태를 대조하고 임의 SF 재해석을 하지 않는다. 생성 도구가 필요하면 현행 imagegen 스킬을 읽는다. IPA나 원본 실행 바이너리는 이미지 도구에도 보내지 않는다. 도안뿐 아니라 실제 캠페인 소비 경로·크기·가림·입력까지 확인한다.
