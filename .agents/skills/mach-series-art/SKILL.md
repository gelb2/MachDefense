# Mach 시리즈 아트

세 작품의 원작 미술 담당은 박재철(PaperBlue)이다. 사용자 제공 정보와 [조사 근거](references/style-study.md)를 따른다. 이름만 넣은 생성 프롬프트로 화풍을 재현했다고 판단하지 않는다. 원본의 어떤 부품·구조·색·가장자리를 따르는지 명시한다.

## 참조 선택

작품과 용도를 먼저 정한다. HeavyMach1의 측면 유닛, HeavyMach2·MachDefense의 탑뷰 유닛, 타이틀·로딩 일러스트는 서로 다른 참조 묶음이다. 같은 작가의 다른 그림을 이유로 게임의 시점이나 도트 크기를 바꾸지 않는다. 같은 이름의 PNG라도 작품별 캔버스·그림 범위·회전 중심을 다시 측정한다.

현재 게임에서 실제로 쓰는 원작 에셋 세 개 이상을 고른다. 같은 계열의 작은 것·큰 것·최종 강화형을 포함한다. 추가 생성 유닛, 탈락 시안, 보고서 미리보기를 원작 참조로 사용하지 않는다. 자료마다 작품·버전·부품명·SHA-256을 남긴다. IPA와 실행 바이너리는 로컬에서만 읽는다.

## 그림에서 유지할 요소

- **실루엣:** 넓은 차체·두꺼운 장갑과 좁은 포신의 대비, 원형 회전축과 사각 장갑의 조합을 유지한다. 강화는 패널·장착물 구성으로 표현한다. 레벨 증가를 전체 확대나 점진적인 축소로 표현하지 않는다.
- **구조:** 몸체·포탑·포신·레이더·궤도·다리의 역할과 연결을 드러낸다. 회전 부품을 고정 몸체에 그려 넣지 않는다. 떠 있는 부품이나 지지점 없는 장식은 수정한다.
- **재질:** 회녹색·회색·상아색 금속을 중간톤으로 쓰고, 패널 틈은 어둡게, 모서리는 짧고 밝게 처리한다. 장비 계열의 원작 팔레트를 먼저 채집한다. 모든 부품에 두꺼운 검은 테두리·흰 테두리·네온을 두르지 않는다.
- **색의 역할:** 적갈색·황토색·노랑·빨강·청색은 도색과 표식, 위험 표시, 무기 종류를 구분하는 작은 면적에 쓴다. 기존 색 비율을 보지 않고 새 강조색을 추가하지 않는다.
- **유닛 해상도:** 확대 생성 그림의 세부를 그대로 축소하면 뭉개진다. 실제 표시 크기에서 몸체·무장·접합부가 먼저 읽혀야 한다. 픽셀 군집과 부분 알파를 원본과 비교한다. ‘픽셀아트’라는 단어만으로 8비트풍 제한 팔레트나 계단식 검은 외곽선을 넣지 않는다.
- **일러스트:** 큰 기계의 무게와 원근, 전경의 선명한 장갑과 연기 속 배경의 대비, 차가운 하늘과 따뜻한 포화의 대비를 따른다. 모든 면을 똑같이 선명하게 그리지 않는다. 원본의 색·구도·광원을 먼저 설명한 뒤 확장한다.

## 제작과 연결

1. PNG 전체 크기, 알파 그림 범위, 원작 연결점·총구·층 순서, 게임 배율을 기록한다. 애니메이션 시트는 프레임 수로 나눠 비교한다. 투명 여백을 물체 크기로 취급하지 않는다.
2. 실물 장비는 사진·도면으로 외형을 확인하고, 작품의 시점·명암·색에 맞춘다. 실제 모델을 임의 SF 기체로 재설계하지 않는다. 사용자가 승인한 비례 예외는 그 유닛에만 적용한다.
3. 생성·수정 도구에 원작 PNG를 직접 제공한다. 부품별 그림을 준비하고 기존 조립 코드·데이터가 소비하게 한다. 그림을 넣기 위해 충돌 반경·사거리·이동·데미지 규칙을 바꾸지 않는다.
4. 균일 배율로 자르고 배치한다. X/Y를 따로 늘려 외곽 상자에 맞추지 않는다. 매 단계 min-fit으로 줄이지 않는다. 차이가 큰 그림은 다시 만든다. 정수 픽셀 반올림과 실제 형태 차이를 수치로 구분한다.
5. 몸체 단독·무장 단독·조립본을 원작과 같은 배율로 비교한다. 무장에 가려져 강화 차이가 사라지는지, 각 단계의 길이·폭과 포신 길이가 변하는지 확인한다.
6. 실제 치트앱에서 원작과 새 부품을 동시에 배치한다. 회전·이동·사격·레이더·피격·그림자·생산 아이콘을 확인한다. 고해상도 시안 승인과 게임 연결 검증을 구분한다. 확대 도안만으로 완료하지 않는다.

## 작업 전 기록할 값

`작품 / 대상 / 원작 참조와 해시 / 원본 캔버스와 알파 범위 / 기준 유닛 대비 크기 / 연결점과 총구 / 팔레트 / 변경할 장갑·구조 / 보존할 외곽과 시점 / 실제 앱 검사`

MachDefense 추가 강화는 `extend-machdefense-art`의 부품 목록과 원본 조립 근거를 함께 적용한다. HeavyMach1 크기 수치를 다른 작품에 옮기지 않는다. 작가의 미술 사조·제작 도구·영향 관계는 확인된 출처가 있는 경우에만 사실로 쓴다.

## 신규 포탑 색조 재검수 — 2026-11-07

사용자는 라이플·발칸을 포함한 신규 포탑이 임의로 어두워졌다고 지적했다. PNG 대조에서 라이플·발칸·이온의 불투명 픽셀 평균 밝기가 원작 최종 단계보다 약 25%·22%·27% 낮았다. 캔버스와 외곽 크기가 같아도 포신의 내부 굵기, 밝은 장갑 면적, 도트 덩어리와 경계가 달라질 수 있다.

같은 계열 원작의 마지막 세 단계에서 밝은 금속·중간톤·그림자·강조색을 채집한다. 생성 결과의 검은 테두리, 둥근 굴곡 음영, 원작에 없는 강조색을 실제 픽셀 크기에서 검사한다. 평균 밝기만 올려 보정 완료로 판단하지 않는다. 전체 길이·폭과 색·명암·내부 부품 굵기는 각각 검사한다.

## 표면 질감 검사

색상과 외곽 크기만으로 원작 재질을 따랐다고 판단하지 않는다. 같은 계열 원작 3단계의 밝은 면·중간톤·패널 틈을 따로 확대해 보고, 국소적인 얼룩과 마모, 끊긴 하이라이트의 크기와 면적을 비교한다. 원작에 없는 균일한 노이즈·흠집·녹을 추가하지 않는다. 넓은 매끈한 음영과 연속된 광택 띠가 남았는지도 검사한다.

생성 원본과 런타임 크기로 축소한 결과를 각각 확인한다. 축소 필터가 픽셀 덩어리를 흐리는지, 최근접 축소가 원작에 없는 거친 계단을 만드는지 비교한다. 필터 이름만으로 정답을 정하지 않는다. 사용자 후속 검수에서 질감 부족을 지적한 시안은 미완료로 남기고 Resources 교체 후보로 자동 채택하지 않는다.
