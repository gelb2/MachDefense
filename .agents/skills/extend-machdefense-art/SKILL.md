# 강화 외형 제작

사용자는 원작자가 만든 그림과 새 그림을 구분하기 어려울 만큼 같은 화풍·색·도트 처리를 요구했다. 새로운 화풍을 제안하는 과제가 아니다. 원작의 최종 단계 부품을 바탕으로 같은 크기 안에서 장갑·기계 구조의 구성을 바꾼다. 강화 레벨을 이유로 물체 크기를 키우지 않는다. 광택 있는 3D, 벡터 외곽선, 과한 네온, 새 문장·문양을 추가하지 않는다.

1. `docs/rendering-policy.md`, `docs/coordinate-policy.md`와 `tools/apply_level10.py`를 읽는다. `MachBuild_Name → MachList → MachInfo → PartsInfo → PartsList → TileList → Images`에서 실제 소비 파일을 찾는다. 기지는 `PlayerLoadout`의 기지·무장·레이더 조립도 확인한다.
2. 최종 3단계 원작을 실제 픽셀 크기와 확대 화면으로 본다. 전체 실루엣, 무장 방향, 부품 경계, 회전 중심, 총구, 금속 색, 명암, 가장자리 픽셀을 기록한다. 파일 이름이 approved라고 참조를 확정하지 않는다. 입력 파일과 결과의 SHA-256을 남긴다.
3. 현행 imagegen 도구에 원작 PNG를 직접 제공한다. 같은 장비의 추가 레벨만 그린다. 원작의 방향·화각·장갑 색·표시 크기·분리 부품을 유지한다. 원본 IPA·실행 바이너리는 보내지 않는다. 원작 파일을 덮어쓰지 않는다.
4. 공용 포탑 몸체·받침 Lv.6–10과 포탑 무장 6종 Lv.6–10, 기지 몸체·기관총·레이더 Lv.8–10의 누락 여부를 표로 확인한다. 이미 10단계가 있는 메크는 새로 그리지 않는다. 특수공격은 유닛 외형과 구분하고 기존 아이콘·발사체·효과를 유지하는지 별도 기록한다.
5. 각 시안을 원본과 같은 크기로 나란히 표시한다. 고해상도 그림만 보고 채택하지 않는다. 잘못된 무장 방향·유실된 부품·떠 있는 연결부·과한 외곽선·일그러진 비율은 수정한다. 생성 모델의 그림만으로 원작의 도트 처리가 재현됐다고 단정하지 않는다.
6. 시안과 게임 자원을 구분한다. 연결 시 부품별 자르기·투명도·논리 크기·피벗·총구·층 순서·레이더 회전·흔들림을 원작 구조로 설정하고 실제 게임의 정지·이동·사격·회전 화면을 검사한다. 시안 제작 요청만으로 Resources와 운영 앱의 그림을 교체하지 않는다.

HeavyMach1의 `integrate-game-art`에서 실제 소비 자원 추적, 탈락 해리어를 참조한 오류, 임의 SF 재해석 금지, 실제 게임 크기 검사를 가져왔다. 이 프로젝트의 형태 기준은 MachDefense의 원작 부품이다. 산출물은 `Art/Level10/`의 시안·프롬프트·출처 명세와 기존 통합 보고서에 연결한다.

## 몸체·무장 크기 — 2026-11-07 사용자 지시

원작 `MachInfo`의 전체 조립 트리와 `MachList.BaseParts`를 함께 확인한다. 무장 이미지 목록만 보고 전체 외형 대상이라고 보고하지 않는다. 원작 포탑 6종은 `Turret_b_01..05` 몸체를 공유한다. 추가 몸체 5단계가 기존 39개 시안에서 빠졌던 점을 반영한다.

몸체는 Lv.5의 64×64 캔버스·53×60 그림 범위와 연결점을 기준으로 한다. 무장도 각 계열의 Lv.5 그림 범위·몸체 대비 비율을 유지한다. PNG 해상도, 투명 여백, 실제 그림 범위, 기기 배율, 충돌 반경을 구분한다. 알파 영역을 각각 잘라 동일 상자에 꽉 채우는 비교는 실제 조립 검사를 대신하지 못한다. 원본 캔버스·피벗으로 몸체와 무장을 조립하고 Lv.1·3·5 및 원작 메크와 같은 월드 배율로 비교한다.

HeavyMach의 Heli001/Heli006 비교, Tank001 85×30 기준 쉴카·퉁구스카 비교는 절차의 참고다. 그 게임의 크기 수치를 이 게임에 복사하지 않는다. [부품별 측정과 소비 코드](../../../docs/evidence/turret-body-scale-20261107.md)를 따른다.

## 조립 시안의 축소 검사

최대 경계 안에 들어간다는 검사만으로 같은 크기라고 보고하지 않는다. 원작의 길이·폭과 각 단계 실제 표시 치수를 함께 기록한다. 추정 피벗으로 네 방향 경계의 최소 배율을 고르면 단계마다 크기가 줄 수 있다. 포신 길이와 폭, 장착 링·총구의 위치를 별도로 검사한다. 비율이 다른 생성 그림은 높이·너비를 따로 늘려 맞추지 않는다. 폭 차이가 남으면 수치를 표시하고 수정 대상으로 남긴다.

몸체는 단독 그림과 무장을 얹은 그림을 모두 본다. 패널 변화가 무장에 가려지면 노출된 측면·뒤쪽 구조에서 구분되도록 다시 그린다. 원본 포탑 6종 Lv.1~5는 몸체·무장이 함께 바뀌지만 몸체 3→4의 변화는 작았다. [원본 세 판본 대조](../../../docs/evidence/turret-original-stage-change-20261107.md).

세 작품의 공통 미술과 작품별 차이는 [mach-series-art](../mach-series-art/SKILL.md)를 함께 읽는다. 추가 레벨의 형태 기준은 계속 MachDefense 원본 부품이다.

## 새 부품 설계 — 2026-11-07 사용자 수정

원작 부품 재사용만으로 제작 범위를 제한하지 않는다. 같은 계열 Lv.1~5에서 반복되는 형태·색 역할·지지 구조·질감을 비교한 뒤 필요한 새 부품을 설계한다. 원작 최종형을 조금씩 변색하거나 흠집만 추가해서 추가 레벨을 만들지 않는다. 새 구조가 실제 크기와 몸체·무장 조립 후에도 구분되는지 확인한다. 작가의 관찰 가능한 그림 문법과 확인하지 않은 제작 도구·의도는 구분한다.
