# restore-machdefense

docs/restoration-plan.md와 source-provenance.md를 읽는다. 원본은 외부 경로에서 읽기만 하고 로컬 REA에만 제공한다. 기준 판본을 확인한 뒤 함수/데이터/ABI 증거를 기록하고 새 소비 코드와 연결한다. HeavyMach 1의 주소·메모리 구조·수치를 옮기지 않는다. 원작 버튼·렌더·시간·저장 규칙을 보존하고 같은 조건으로 일반/치트 앱을 검증한다. 기존 hm-defense 포크는 이 복원의 기반이 아니다.

## 원본 동작 대조

- 각 행동의 원본 함수·조건·이미지/타일·음원·새 소비 코드를 함께 기록한다. 파일이 없으면 비슷한 파일로 대체하지 않고 포팅판 실제 출력을 확인한다.
- 생산·구매·승패·저장 성공과 안내·딤·글로우·효과음·전환 표시를 각각 검사한다. 음원 호출 횟수만으로 올바른 출력음이 확인됐다고 기록하지 않는다.
- 강화는 구매 레벨·차감뿐 아니라 피해·생산 시간·수집·생성·체력·외형 변경 시점을 검사한다.
- 생명주기는 중단 알림의 도착 순서와 종료 알림 누락, 미디어 서비스 재설정, 실제 재생 시간·출력을 검사한다.
- 기기별 설치본과 검사본을 구분한다. 사용자 플레이 중인 정식 앱을 검사용 앱으로 덮어쓰지 않는다.
