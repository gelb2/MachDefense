# debug-machdefense-android

실제 adb serial과 transport를 조회한다. 기존 기기나 다른 앱을 초기화하지 않는다. 무선 페어링/연결 포트를 구분하고 비밀을 로그에 쓰지 않는다. 빌드 패키지·SHA·저장 백업을 확인해 일반/치트 앱을 각각 설치·실행·조작한다. 실패 로그를 보존하고 입력 해제·일시정지·앱 종료·홈 복귀를 검사한다. 현재 Android 타깃은 미구현이다. 명령 예시는 docs/reference/heavymach1/skills/debug-heavymach-android에서 참고하되 실제 MachDefense ID로 검증한다.
