# 포탑 재시안 35개

원작 Lv.3–5를 참조한 공용 몸체·6종 무장 Lv.6–10 시안이다. 게임 자원에는 연결하지 않았다. 치수 차이와 단계별 구분 보강이 남아 있다.

[전체 설명과 설치 결과](../../../../docs/evidence/turret-redraw-20261107.md), [부품 측정](review/measurements.json).

`generation.json`에 내장 imagegen으로 생성·수정한 프롬프트와 원본 출력 경로를 보존했다. 각 원본 참조의 SHA-256은 측정 파일에 있다. `review/*-comparison.webp`는 원작 3·4·5와 시안 6–10, `review/*-assembled.webp`는 원작 5와 시안 6–10 조립이다. PNG는 검토용으로 자르고 균일 축소했다. 색 변경이나 비균일 늘리기는 하지 않았다.
