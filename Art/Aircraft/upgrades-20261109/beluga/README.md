# 벨루가 날개 뿌리 보강판

승인된 7자세 그림의 날개 뿌리 판과 모서리·접합부를 분리해 작은 가로 띠, 세로 지지대와 장갑판으로 재조립했다. Lv.1–10의 구성이 다르다. 각 선회 자세는 해당 자세의 원래 그림을 사용한다. 새 엔진을 추가하거나 주색·기체 크기·원본 파일을 바꾸지 않았다. 무장 그림은 이번 후보에 포함하지 않는다.

위·아래 두 파츠를 각 32×29 셀 7개로 준비했다. body socket 0에 위 self socket `[-10,-23]`, 아래 `[-10,25]`, z=1이 연결 후보다. 화면의 셀 좌상단은 각각 `(64,28)`, `(64,76)`이다. 140파츠 자세의 원래 기체 외곽 침범은 0이다.

[원본 조각·위치·검사](authored-registration.json), [CgBI 준비 결과](manifest.json), [원작 참조·해시·범위](provenance.json). 기존 그림의 재조립 결과이며 새로 생성한 벨루가 그림을 채택했다고 보고하지 않는다. 실제 게임의 층·팬 가림·회전·그림자와 레벨 차이는 제품 연결 뒤 검사한다.
