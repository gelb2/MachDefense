# 샤이엔 장갑·미사일 하우징

Lv.1–10 장갑 10개와 미사일 하우징 10개를 준비했다. 장갑 한 파일은 28×14 셀 7개다. 중립과 좌우 6자세를 포함한다. 승인 몸체는 변경하지 않았다.

장갑은 기존 body socket 0에 self socket `[6, 0]`, z=2로 연결한다. 중립 24×8은 셀 안 `(2, 3)`이다. 셀 위치는 몸체 `(35, 37)`이다. 70자세 모두 승인 몸체의 투명 외곽을 벗어나지 않는다.

미사일은 18×13이며 후방 8열의 하우징 내부만 바꿨다. 원래 알파와 전방 10열·발사관·총구는 보존했다. `ADuctGun`은 기존 전방 장식 파츠로 유지한다.

[생성·원작 참조와 해시](provenance.json), [자르기·등록·보존 검사](authored-registration.json), [CgBI 준비 결과](manifest.json). 독립 장갑의 판 겹침과 접합부를 그렸으며 색 변경이나 전체 확대·축소로 레벨을 구분하지 않았다. 이 준비 검사는 실제 World의 로터 가림·회전·사격·그림자 검사를 대신하지 않는다.
