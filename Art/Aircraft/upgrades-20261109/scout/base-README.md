# 스카웃 기본 단계 표면

Lv.1용 간단한 두 장갑판과 뒤쪽 연결대, 기관포·미사일 후방 하우징을 준비했다. 몸체 64×47·주색·전체 외곽과 Lv.2–10 자원은 변경하지 않았다.

장갑은 기존과 같은 16×17 셀 7개다. body socket 0, self socket `[-1,-1]`, z=2로 연결한다. 몸체 내 셀 좌상단은 `(25,14)`다. 강한 우선회는 기존 강화 장갑처럼 셀 내부 `(+1,+1)`로 등록했다. 7자세 모두 승인 몸체 외곽 침범은 0이다.

기관포·미사일은 기존 전체 알파와 전방 포신·발사관·총구를 바꾸지 않고 후방 하우징만 교체했다. [장갑 등록](base-cover-manifest.json), [무장 검사](base-manifest.json), [생성 원본·프롬프트·참조 해시](base-provenance.json). [제품 연결과 실제 World·UI 검사](../../../../docs/evidence/scout-base-surface-20261109.md)를 마쳤다.
