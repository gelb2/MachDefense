# 스카웃 Lv.2–10 외형 부품

`rgba/`는 실행 자원 준비에 사용하는 덮개9개와 무장18개의 제작 PNG다. 실행용 CgBI PNG·파츠 정의·레벨별 조립은 별도 준비 절차가 소비한다. 이 폴더의 파일 수가 사용자 시각 검수나 웹 전투 검증 완료를 뜻하지 않는다. Lv.1 기본 표면 개선은 후속 작업으로 남아 있다.

[출처와 생성 프롬프트](provenance.json)에 원작 참조, 승인 몸체·무장, 사용한 생성 결과의 SHA-256, 각 파일의 선택·준비 경로를 기록했다. 원작 머신건 메크 Lv.8–10의 `P_Body_16/17/18`과 실제 무장 그림을 비교했다. 원작 파일은 수정하지 않았다.

덮개는 정면 후보와 새로 그린 좌우6자세를7타일로 포장했다. 모든 레벨에 같은16×17 셀과 엔진 어깨 연결점을 사용한다. 가장 강한 우선회 프레임에는9개 레벨 공통(+1,+1) 등록값을 적용했다. 63개 자세 모두 승인 몸체 알파 밖 증가와 포장 중 픽셀 손실이0이다. [정적 포장 검사](registered-cover-audit.json). 최초 배치의 윤곽 침범과 작은 어깨판의 약한 구분은 기각 근거로 보존했다.

무장은 생성한 뒤쪽 하우징만 기존 장착 영역에 조립했다. 기관총14×7, 미사일13×8의 전체 알파와 앞쪽 포신·발사관은 승인 그림과 같다. 기관총의 앞쪽 x=8..13, 미사일의 x=6..12를 그대로 복사했고 총구·소켓은 바꾸지 않았다. 생성한 무기 전체를 단계마다 줄이는 방식은 사용하지 않았다. [하우징 검사](weapon-housing-audit.json).

큰 생성 원본의 구조가 작은 게임 크기에서도 읽히는지는 실제 조립·선회·발사 화면으로 판단한다. 위 정적 검사와 출처 기록만으로 도색·질감·입체감의 전체 요구를 완료 처리하지 않는다.
