# AH-10 장갑·후방 하우징

Lv.1–10 중앙 개방 장갑 10개와 기관포·캐논·미사일 후방 하우징 각 10개다. 기존 로켓·공습의 분리된 7자세와 총구는 보존한다.

장갑은 24×22 셀 7개이며 중립 그림은 전 레벨 19×16이다. 몸체 셀 위치 `(28,47)`, parent socket 0, self socket `[-2,2]`, z=1로 연결했다. 강한 우선회 자세는 전 레벨 공통으로 셀 안 y를 1픽셀 올렸다. 70자세 모두 승인 몸체 밖으로 그림이 나가지 않는다. 중앙 구멍으로 기존 기계 구조를 보존한다.
