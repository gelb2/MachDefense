# 복원 순서

2026-11-07: 초기 복원·모듈화·플랫폼 확장 단계는 진행했고 v0.5를 배포했다. 아래는 최초 계획과 변경 순서를 보존한 기록이다. 남은 작업은 [현행 TODO](usability-todo.md), 구현과 검사는 [현재 상태](current-status.md)를 따른다.

1. 외부 원본 3종의 해시·번들·기기·실행 바이너리·에셋 차이를 조사하고 기준 판본을 정한다.
2. 원본을 변경하지 않고 로컬 호환 실행 가능성을 조사한다. 실행되면 화면·입력·저장·교전 기준을 확보한다. HeavyMach 1의 touchHLE 패치를 주소 변경 없이 재사용하지 않는다.
3. 로컬 REA에서 함수·호출·데이터·ABI를 분석한다. 입력 SHA·주소·Evidence와 소비 코드를 연결한다. 외부 서버로 원본을 보내지 않는다.
4. 원작 규칙을 소스와 준비 에셋으로 구현한다. 소스/에셋 기반 제품 빌드는 IPA와 무관해야 한다.
5. 같은 초기 조건으로 비교판과 일반/치트 앱의 전체 교전·진행·저장·화면·음향을 비교한다.
6. 한 플랫폼에서 검증한 뒤 요청된 플랫폼을 확장한다. 기존 정상 플랫폼과 코어를 보존하고 생명주기·GPU·오디오·저장을 검사한다.
7. 독립 clone 빌드·기기 실행·문서·기여 기록을 확인하고 develop→main으로 병합한다. 릴리스는 main 커밋에 태그를 붙인다. 공개는 별도 지시 때만 한다.

단계마다 docs/current-status.md와 docs/evidence의 요구→함수→코드→검사 연결을 갱신한다. 1.0.5를 최초 호환 실행 대상으로 정했고 iOS 비교판을 개발 중이다. 세 판본의 파일·표 비교를 마쳤고 별도 위메이드판 시뮬레이터 검사를 진행했다. 후속 사용자 지시로 [소스 재개발](source-reimplementation-plan.md)을 시작했다.

## 사용자 확정 순서 — 2026-11-04

포팅판을 먼저 완성한다. 메인게임 진입·유닛 생산·교전뿐 아니라 업그레이드, 이름 입력, 미션 진행, 저장·재실행을 확인하고 발견된 호환 오류를 수정한다. 이 단계가 완료된 뒤 소스코드 재개발과 기기 화면 크기 대응을 진행한다. HeavyMach 1에서 수행한 재구현·화면 대응 작업도 이 순서에 따른다. 포팅판의 호환 오류를 남긴 채 다음 단계로 넘어가지 않는다.

## 포팅판 치트 검증

[포팅판 치트 검증과 재개발 비교 계획](compatibility-cheat-validation-plan.md)에 따라 별도 치트앱·테스트 시작 조건·검사 맵을 준비한다. 정상 난이도 플레이로 자금을 모으는 시간을 강화 검사 선행 조건으로 삼지 않는다. 전체 기능·실제 클리어·다음 스테이지·프로필·저장을 포팅판에서 확인한 후 같은 조건을 재개발판에 적용한다.

재개발 착수 전에 [사용자 플레이 관측](port-observations-20261104.md)의 MD-PLAY·MD-UI·MD-ART 항목을 확인한다. 가격·표시 언어·자글거림의 원본 대조 결과를 구현 근거로 사용한다.

소스 재개발 전 [공용 에셋·유니버설 앱 사전조사](universal-assets-plan.md)를 수행한다. 판본별 고해상도 자원을 비교하고 공용 세트를 정한 뒤 원본 논리 크기를 보존해 적용한다.

## 판본 조사 순서 — 2026-11-04 후속 요청

당시 다음 작업으로 [일반·HD·전체 빌드 조사](version-audit-plan.md)를 정했다. 확보한 3개뿐 아니라 추가 판본의 존재와 확보 여부를 확인하고 코드·에셋·영문 표시 차이를 비교한 뒤 소스 재개발 계획을 정한다. 전체 호환판 캠페인 검사 완료만을 기다리지 않고 판본 차이와 기준 선택에 필요한 검사를 먼저 수행한다. 신규 앱은 영어만 지원한다.

## 위메이드 기준 후속 순서

기존 indieapps 1.0.5 포팅판과 사용자 저장을 보존한다. 위메이드 1.0.3은 별도 번들·저장으로 만들고 iPhone 시뮬레이터부터 검사한다. 위메이드의 미션·에셋을 기준으로 삼아 차이를 기록한 뒤 소스 재개발을 시작한다. 현재 결과와 다음 단계는 [통합 보고 원고](editorial/machdefense-report.md)에 연결한다.


## 현재 구현 순서 — 최신 사용자 지시

사용자는 위메이드 비교판 검사 이후 HeavyMach 1과 같은 기술 구성을 사용해 소스를 새로 작성하고 시뮬레이터로 검증하도록 지시했다. [소스 재개발 계획](source-reimplementation-plan.md)에 따라 진행한다. 포팅판의 미검사 항목은 재개발 비교에서도 계속 확인한다. 메뉴·전투·저장 전체가 연결되기 전에는 새 앱을 완성됐다고 기록하지 않는다.

치트앱의 조건 설정·직접 조작 기능은 구현했다. 현재 순서는 포팅판 대조 → 앱 아이콘 → UI·회전 재검사 → 치트앱 전체 연속 검사 → 성능·음향·메모리·생명주기 → iPhone·iPad 화면 확장 계획이다. 세부 순서와 미션 완료 기준은 [소스 재개발 계획](source-reimplementation-plan.md)이 소유한다.
