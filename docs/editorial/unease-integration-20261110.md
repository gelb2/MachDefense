# 「헤비멕1과는 다른 위화감」 원고 결합 준비

2026-11-10. 글 제목은 **헤비멕1과는 다른 위화감 — 신 리셴코주의와 차우세스쿠의 타자기**로 유지한다. README의 「위화감」과 릴리즈 노트는 [이 원고](../public/unease-and-typewriters.md)로 연결한다. 원고 서두에는 이번에 확정한 헬기 개선 보류와 선택 사용 안내를 붙였다. 아래는 기존 본문과 이후 초안을 한 글로 묶기 위한 구성이다. 원문과 별도 초안은 보존했다.

## 한 글로 읽힐 순서

| 순서 | 내용 | 가져올 원문과 처리 |
|---|---|---|
| 1 | 헬기유닛 구현 중단에 대한 소고 | 2026-11-10 지시의 짧은 서문. Mach 시리즈 전체 복원이 우선이며, 헬기의 미학적 완성도와 개선 보류·선택 사용을 밝힌다. |
| 2 | 헬기를 기획한 이유 | [추가 글감 2](aircraft-refusal-materials-20261109.md#2-추가-글감-원문--헬기-기획과-출시-불확실성)와 [작업 기록](helicopter-work-record-20261109.md)의 회피기동·최소 기능 문단. 중복 설명을 한곳에 둔다. |
| 3 | 승인 시안과 원작 절차가 어긋난 과정 | 작업 기록의 크기·색조·선회·조립·이동·레벨별 외형 문단. [경위서](../evidence/aircraft-work-failure-20261109.md)와 [외형 오류](../evidence/new-unit-art-errors-20261108.md)를 붙인다. |
| 4 | 이미지 생성 차단, 후속 편집 거부, 경위서 책임 전가 | 기존 원고의 Gemini 도안·글씨 편집·경위서 문단과 작업 기록의 오류 7건을 연결한다. 오류 전문은 [작업 기록의 오류 절](helicopter-work-record-20261109.md#이미지-생성-오류-기록)에 보존한다. 도구 오류와 편집을 호출하지 않은 행동을 혼동하지 않는다. |
| 5 | 헤비멕1과 다른 위화감 | 기존 원고의 정치인 페이지·자기소개·BTS·유고슬라비아/슬로베니아·80%·48시간 문단. 사용자의 표현을 유지한다. |
| 6 | 레퍼런스와 미국제 AI에 관한 가설 | [추가 글감 9–11](aircraft-refusal-materials-20261109.md#9-레퍼런스와-업무-거부에-관한-가설)과 기존 원고 말미. Su-25·하인드·AH-10·아머드코어6, 쉴카·퉁구스카, 이미지 작업 경험을 한 흐름에 놓는다. 작가명 정정과 사용자의 가설 표현을 보존한다. |
| 7 | 신 리셴코주의와 차우세스쿠의 타자기 | 기존 원고의 역사 자료·과학적 사회주의 논거·타자기 비유. 기업을 변호하는 문장이나 사용자가 철회한 완곡한 재서술을 끼워 넣지 않는다. |
| 8 | 남은 시간과 개선 보류 | [추가 글감 6·7·12](aircraft-refusal-materials-20261109.md)와 작업 기록의 서문을 연결한다. 마지막 타자기 문장은 사용자 직접 수정인 **“역사상 가장 불투명하고”**를 따른다. |

## 보존할 구분

- [2026-11-08 초안](unease-and-typewriters-draft-20261108.md), [현재 공개 원고](../public/unease-and-typewriters.md), [2026-11-09 작업 기록](helicopter-work-record-20261109.md), [글감 전문](aircraft-refusal-materials-20261109.md)을 삭제하거나 덮어쓰지 않는다. 통합 본문을 작성할 때 이 대응표로 누락을 대조한다.
- 사용자 직접 수정 `c7cfd8a`의 “역사상 가장 불투명하고”를 적용한다. 이전 “역사상 자아 불투명하고”로 되돌리지 않는다.
- [AI를 패는 방법론·쇼펜하우어 토론 기술 글감](ai-argument-method-material-20261109.md)은 사용자가 분리한 다른 원고다. 이 글에 다시 합치지 않는다.
- 당시 “출시는 미지수”였던 상황과 현재 “출시했으나 개선은 보류”한 상태를 시간 순서로 연결한다. 기존 실패 기록을 현재 수정 완료나 사용자 승인으로 바꾸지 않는다.
- 공개 원고와 영문판, README와 릴리즈 노트는 같은 보류 이유와 같은 읽기 경로를 제공한다. 본문에 담을 오류 횟수·작업 소요·크레딧 수치는 각각의 원문과 보존 로그에 맞춘다.
