# 복원 계약

원본 IPA와 해시를 고정하고 비교 실행판을 확보한다. REA 의사 코드를 원작 개발 소스라고 부르지 않는다. 불명확한 ABI·타입·호출은 어셈블리와 런타임 근거로 확인한다.

소스 구현은 원본의 이동·교전·무기·충돌·데미지·스폰·진행·저장·음향·부품 조립을 대조한다. 같은 초기 상태·입력·시간·난수 조건에서 차이를 기록한다. 원본의 수치를 새로운 밸런스로 바꾸지 않는다.

최종 앱은 IPA를 실행하거나 런타임에 해체하지 않는다. 준비된 소스·에셋·빌드 구성만으로 새 clone에서 빌드한다. 호환 실행판은 비교 도구이고 제품 빌드 입력이 아니다. 준비된 자원은 파일별 출처·SHA를 관리한다.
