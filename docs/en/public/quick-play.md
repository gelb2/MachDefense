## Install as a PWA

Install the PWA to play without building with Xcode or Android Studio. Open it like an app from your home screen. Once resources finish downloading, it can play and save progress offline.

- iPhone / iPad: open the address above in Safari and choose **Share → Add to Home Screen**.
- Android: open it in Chrome and press **INSTALL GAME**. If installation instructions appear, choose **Install app** or **Add to Home screen** from Chrome's menu.
- Mac: choose **INSTALL GAME** in Chrome or **File → Add to Dock** in Safari.

Open the installed app, finish the resource download, and play. To play in a browser tab, press **PLAY IN BROWSER**. Use touch, a mouse, or a trackpad to produce units, and drag the battlefield to move the view. [Controls](gameplay.md).

## Move progress to another device

Generate a code with **GET CODE** on the slot-selection screen and enter it through **ENTER CODE** on another device. Added turret, base, and special-attack levels transfer too. For progress using the level-10 extension, update the receiving app or PWA to **v0.4 or later**. Older versions reject codes containing unsupported levels.

## If leveling up is difficult

I am sharing a recovery code from my own playthrough in the native iPhone app. It lets you skip part of collecting and upgrading mechs, and play with unlocked equipment and funds.

| Shared progress | Contents |
|---|---|
| Profile | Slot 1; the other 4 slots are empty |
| Next available mission | Stage 42 |
| Credits | 20,329Cr |
| Owned units | 12 types: MachineGun, ShotGun, Missile, HMG, PlasmaGun, Tanker, IonRifle, RifleTurret, MissileTurret, PlasmaCannon, IonCannon, Vulcan |
| Remaining special attacks | Air bombardment: 4; air missiles, nuclear bomb, and Crossfire: 1 each; EMP: 0 |

Unit order, upgrades, funds, and remaining special attacks are exactly as saved on the iPhone. After restoring, select the profile and continue playing.

### Apply the code

1. On the profile-selection screen, use **GET CODE → COPY** to save a copy of your current progress elsewhere.
2. Copy the shared code below and paste it into **ENTER CODE**.
3. Press **CHECK → YES** to restore.
4. Select the restored profile and enter a mission.

**This code replaces all 5 profiles together.** To return to your own progress, enter the code you kept in step 1 using the same procedure. The same code works on iPhone, iPad, Android, and web/PWA.
