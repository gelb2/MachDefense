# Controls and saves

<!-- language-nav:start -->
[한국어](../../public/gameplay.md) | [English](gameplay.md)
<!-- language-nav:end -->

iOS, iPadOS, Android, and web/PWA use the same C++ game code.

Create a profile or select a slot, then choose a mission. Tap a unit in the right-hand list to produce it. For a turret, tap again to choose its placement. Scroll the production list vertically. On the web, wheel and trackpad scrolling work over that list. Wheel and keyboard movement of the battlefield camera are not yet available; drag the battlefield to view another area. In a browser, use the mouse to click and drag the same screens.

The bottom buttons switch between unit and special-attack lists. UPGRADE & EQUIP handles equipment upgrades and INSTALL/UNINSTALL. BASE UPGRADE handles base upgrades. MENU offers pause, resume, and save-and-exit.

When the funds button glows, open emergency resupply and press CLAIM. Close the window to continue the battle. After leaving and returning to the app, press Resume Game in the pause menu.

To transfer progress, copy a code with **GET CODE → COPY** on the slot-selection screen. Paste it into **ENTER CODE** on another device, then press **CHECK → YES**. iPhone, iPad, Android, and web/PWA use the same MD1 code. It transfers progress, owned units, upgrades, remaining special attacks, and funds for all 5 slots. It restores the last saved state, excluding units and projectiles that were moving in an active battle.

When transferring turret, base, or special-attack levels above the original caps, the receiving app or PWA must also be v0.4 or later. Earlier versions reject those codes.

The existing save is backed up before restoration. CANCEL or NO keeps current progress. After a successful restore, select a slot and continue playing.
