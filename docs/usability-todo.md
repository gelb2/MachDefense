### iPad 소스판 사용자 관측 — 2026-11-04

- [ ] MD-SOURCE-UI-01: 강화 버튼 아래 비용 숫자가 오른쪽으로 밀린다. 원작의 숫자 기준점·정렬·버튼과의 간격을 대조해 수정한다. 실제 iPad 치트 앱에서 사용자와 작업자가 확인했다. 관련 강화 메뉴 전체와 일반 앱도 다시 검사한다.
- [ ] MD-SOURCE-UI-02: 생산 아이콘 속 유닛이 원작의 위쪽 대신 오른쪽을 향한다. 원작 생산 아이콘의 기체·포탑 방향과 부품 조립 회전값을 대조해 수정한다. 전장 유닛 이동·조준 회전과 아이콘 회전을 구분한다. 스테이지 클리어 후 “You have got a new mech” 보상창의 유닛 아이콘도 오른쪽으로 돌아가 있다는 사용자 관측을 추가했다. 생산창·보상창의 미리보기 공통 경로를 확인한다. 생산 가능한 전체 유닛 아이콘·신규 유닛 보상창과 일반·치트 앱에서 재검사한다. 우측 특수기술 아이콘은 사용자가 정상 표시를 확인했으므로 방향 수정 대상에서 제외한다.

두 항목은 현재 소스판의 원작 재현 오류다. 미리보기 전체 부품을 90도 회전하고 비용을 원작 기준점에 오른쪽 정렬하도록 수정했다. 관련 코어 회귀 검사는 통과했다. 전체 생산·강화·보상 화면과 일반 앱 대조는 남아 있다. 화면 확장 전에 마친다.

### iPad 화면 회전 — 2026-11-04 사용자 관측

- [ ] MD-ROTATION-01: iPad를 가로로 돌리면 가로 전환을 시도하다 세로로 돌아오는 듯한 회전 효과가 발생한다. 사용자 확인에 따르면 원작은 세로 정방향과 세로 뒤집기 두 방향만 지원했다. 신규판도 이 두 세로 방향을 기준으로 수정·검증한다.

- [ ] MD-ROTATION-03: 실제 iPad에서 정방향→가로→세로 뒤집기→가로→정방향을 검사한다. 각 세로 방향의 화면·터치 좌표, 메뉴·전투·모달·중단 후 복귀를 일반/치트 앱에서 확인한다. 원작과 두 세로 방향을 맞추는 작업은 화면 확장과 별개로 현재 재현 오류에 포함한다.

Info.plist·프로젝트 생성 설정·ViewController를 두 세로 방향으로 수정했다. 실제 회전과 터치 검사는 남아 있다.
