### MD-AUDIO-BACKEND-01 — 포팅판 음향 구현 재사용과 원작 재생 절차 대조

- 사용자 지시: 포팅판 검증은 원본의 검증된 기술·로직·자원 처리 절차를 재개발에 이어 쓰기 위한 것이다. OpenAL 처리를 그 기준으로 수정하고 사운드가 정상적으로 나오는지 검사한다. 모듈화 단계에 함께 포함한다.
- 확인: 위메이드 1.0.3 원본 armv7 실행 파일은 `/System/Library/Frameworks/OpenAL.framework/OpenAL`에 연결한다. 포팅판 touchHLE의 `src/frameworks/openal.rs`는 이 경로의 호출을 받아 OpenAL Soft로 처리한다. 수정 전 소스판은 Apple OpenAL에 직접 연결했다. 현재는 OpenAL Soft를 사용한다. 원작의 API 호출과 포팅판의 실제 라이브러리를 구별해 기록한다.
