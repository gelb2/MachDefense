# 긴급지원 지급량 초안 — 2026-11-05

공용 Economy·BattleClock·Session에서 계산한다. 게임에는 아직 지원금을 추가하지 않았다. 아래 값은 원본 표·현행 계산에 근거한 첫 조정안이다. 전투 결과를 비교해 최종 지급량을 정한다.

## 기준값

셀은 Cell Storage와 전투 중 용량 확장으로 적재 한도가 정해진다. 기본 500~4,700셀, 전투 중 최대 6배다. Cell Research는 60fps에서 초당 12~26.4셀을 생산한다. 크레딧은 SaveData의 32비트 정수 잔액이며 셀처럼 용량을 강화하는 항목이 없다. 정수의 표현 한도를 경제적 적재량으로 사용하지 않는다.

MachineGun 첫 단계는 60셀, Missile 150셀, RifleTurret 200셀, HeavyMissile 300셀, IonRifle 800셀이다. 첫 단계 폭격은 150Cr, 미사일 공습 210Cr, 핵폭탄 300Cr이다. 기지 첫 강화는 500~800Cr다. 미션 완료 보상은 `500 + 25 × (미션 번호 - 1)`Cr다. 적 처치 드롭은 별도다.

## 제안식

- 30초: 크레딧 지원. 현재 미션 완료 보상의 20%를 10Cr 단위로 내린다. 보유 크레딧이 많다고 지원액을 늘리지 않는다.
- 45초: 셀 지원. `min(현재 셀 용량 × 20%, 현재 자연 생산량 12초분)`을 10셀 단위로 내린다. 용량 확장만으로 지원액이 폭증하지 않는다.
- 60초: 혼합 지원. 앞의 크레딧·셀 지원액 각각 절반을 10단위로 내린다.
- 세 항목을 모두 받아도 추가 크레딧은 미션 완료 보상의 약 30%, 추가 셀은 자연 생산량 약 18초분 이하다.
- 셀은 실제 남은 공간까지만 지급한다. 가득 차 있으면 수령을 소비하지 않는다. 혼합 지원은 크레딧·셀의 미수령 잔액을 따로 남겨 넘친 셀이 사라지거나 크레딧이 중복 지급되지 않게 한다.
- 활성화 시간은 해당 미션에서 실제 진행된 게임 시간이다. 일시정지·백그라운드 시간은 제외한다. 별도 OS 타이머나 프레임별 파일 쓰기는 넣지 않는다.

| 조건 | 30초 크레딧 | 45초 셀 | 60초 혼합 | 최대 총지원 |
|---|---:|---:|---:|---:|
| 미션 1 / 용량 500 / 연구 Lv.1 | 100Cr | 100셀 | 50Cr + 50셀 | 150Cr + 150셀 |
| 미션 17 / 용량 1,000 / 연구 Lv.5 | 180Cr | 200셀 | 90Cr + 100셀 | 270Cr + 300셀 |
| 미션 40 / 용량 2,300 / 연구 Lv.6 | 290Cr | 210셀 | 140Cr + 100셀 | 430Cr + 310셀 |
| 미션 80 / 용량 4,700 / 연구 Lv.10 | 490Cr | 310셀 | 240Cr + 150셀 | 730Cr + 460셀 |

미션 17은 현재 아이폰의 진행도·셀 강화 조건이다. 다른 행은 비교용 조건이며 해당 미션에 반드시 이 강화 수준이라는 뜻은 아니다. 미션 1의 총 150셀은 초기 MachineGun 두 대와 잔여 30셀, 또는 Missile 한 대에 해당한다. 총 150Cr는 기본 폭격 한 번이다. 최초 기지 강화 500~800Cr를 지원만으로 즉시 구매할 수는 없다. 최고 조건의 460셀도 첫 단계 IonRifle 한 대 가격보다 적다.

## 반복 수령과 저장

각 항목은 한 미션에서 한 번 수령하는 안이다. 셀은 전투마다 초기화되지만 크레딧은 누적된다. 실패·재시작으로 크레딧 지원을 반복 수령하면 30초마다 돈을 벌 수 있으므로, 프로필·미션별 크레딧 수령 상태를 재실행 후에도 보존해야 한다. 원본 슬롯의 알려지지 않은 바이트를 임의로 사용하지 않는다. 추가 상태 저장 방식과 원본 슬롯 보존을 구현 전에 확정한다. 세부 저장·혼합 미수령 처리와 지급량은 아직 구현하지 않았다.

## 검증

현재 Core의 생산·구매 함수에 지급 전후 값을 넣어 생산 가능 수, 기지·유닛·스킬 강화 구매 가능 수를 대조한다. 미션 1·17·40·80에서 같은 난수와 생산 입력으로 지원 없음/있음을 비교한다. 클리어 시간·기지 잔여 체력·특수기술 소비·실패율을 기록한다. 이 전투 비교는 아직 실행하지 않았다.

0셀·용량 직전·가득 참, 일시정지, 정확히 30/45/60초, 재시작·재실행, 연속 탭·중복 입력, 최대 정수 근처 크레딧을 검사한다. 지급은 기존 경제 갱신으로 연결하고 수령 때만 상태를 저장한다. 인게임 UI는 C++ Frame·원본 에셋·원본 폰트를 사용한다.
