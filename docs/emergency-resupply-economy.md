# 긴급지원 반복 지급량 — 2026-11-05

사용자 요구는 한 미션에서 한 번 받는 지원이 아니다. 전투 중 크레딧 30초마다, 셀 45초마다, 혼합 60초마다 소량을 반복 제공한다. 이전 1회 지급 계산과 미션별 1회 제한은 폐기했다. 사용자가 아래 금액을 승인했고 공통 C++ 모듈에 구현했다. [검사 기록](evidence/emergency-resupply-20261105.md).

## 기준과 이전 계산의 차이

셀 용량은 기본 500~4,700, 전투 중 최대 6배다. 자연 생산은 연구 단계에 따라 60fps 기준 초당 12~26.4셀이다. 크레딧에는 셀 같은 적재 한도가 없다. 미션 완료 보상은 `R = 500 + 25 × (미션 번호 - 1)`Cr다.

이전 미션 1의 100Cr/100셀/혼합50Cr·50셀을 그대로 반복하면 10분 동안 2,500Cr·1,800셀을 제공한다. 1회 합계150Cr·150셀만으로 경제 영향을 설명한 것은 사용자 요구와 달랐다.

## 반복 지급식

- 30초마다: `floor(R × 4%)`Cr.
- 45초마다: `S = floor(min(현재 셀 용량 × 10%, 자연 생산 4초분))`셀.
- 60초마다: `floor(R × 2%)`Cr와 `floor(S / 2)`셀.
- 소수 부분만 버린다. 이전의 10단위 절삭은 소액 지원을 지나치게 줄이므로 적용하지 않는다.
- 크레딧의 장기 평균은 분당 미션 보상의 약10%다. 셀은 장기 평균 자연 생산량의 약12.2% 이내를 추가한다. 셀 기준 초당 생산은 현재 원작 틱 규칙을 사용하며 실제 벽시계로 게임 시간을 바꾸지 않는다.
- 전투 시간30·60·90초,45·90·135초,60·120·180초에 각각 지원분을 준비한다. 수령 시각 때문에 다음 지원 시각이 밀리지 않는다. 정지·지원창·백그라운드 시간은 세지 않는다.

| 조건 | 30초마다 Cr | 45초마다 셀 | 60초마다 혼합 | 5분 총지원 | 10분 총지원 |
|---|---:|---:|---:|---:|---:|
| 미션1 / 용량500 / 연구Lv.1 | 20 | 48 | 10Cr + 24셀 | 250Cr + 408셀 | 500Cr + 864셀 |
| 미션17 / 용량1,000 / 연구Lv.5 | 36 | 67 | 18Cr + 33셀 | 450Cr + 567셀 | 900Cr + 1,201셀 |
| 미션40 / 용량2,300 / 연구Lv.6 | 59 | 72 | 29Cr + 36셀 | 735Cr + 612셀 | 1,470Cr + 1,296셀 |
| 미션80 / 용량4,700 / 연구Lv.10 | 99 | 105 | 49Cr + 52셀 | 1,235Cr + 890셀 | 2,470Cr + 1,885셀 |

총량은 해당 게임 시간의 경계를 포함하고 전투 중 강화값이 일정한 조건이다. `floor(t/30)×Cr + floor(t/60)×혼합Cr`, `floor(t/45)×셀 + floor(t/60)×혼합셀`로 계산했다. 적재 공간 때문에 실제 수령한 셀은 총지원보다 적을 수 있다.

미션1에서 지원만으로 초기 MachineGun 한 대분60셀을 60초까지 마련한다. 5분 셀 지원은 MachineGun 여섯 대와48셀, 또는 Missile 두 대와108셀이다. 크레딧은 5분250Cr, 10분500Cr로 기본 폭격·강화 구매에 영향을 준다. 고의로 전투를 오래 끌면 크레딧이 계속 쌓이는 것은 반복 지급의 결과다. 이 영향을 반복 지급 금지로 막지 않고 전투 비교로 지급액을 조정한다.

## 수령·저장

사용자는 기존 버튼으로 지원을 수령한다. 받지 않은 지원분은 해당 전투의 항목별 대기 잔액으로 누적한다. 미수령이라는 이유로 다음 인터벌 지원을 지우거나 횟수를 제한하지 않는다. 용량을 넘는 셀도 대기 잔액에 남기며 혼합 항목의 Cr·셀을 따로 차감한다. 받을 수 있는 자원이 있으면 버튼을 빛나게 한다.

수령과 다음 주기 계산은 공통 C++ 상태에서 처리한다. 같은 지원분의 연속 탭만 중복 지급으로 막는다. 새 인터벌 지원은 정상 지급한다. 셀 금액은 각 인터벌 도달 시점의 용량·연구 수준으로 계산한다.

프로필·미션별 영구 수령 금지표는 만들지 않는다. 전투 재시작은 시간0부터 다시 시작하며 첫 지원을 기다린다. 기존 앱이 전투 중간 상태를 저장하지 않는 조건에서 지원 시간·미수령분도 같은 전투 수명을 따른다. 이미 수령한 크레딧은 기존 슬롯 자금과 함께 기존 저장 시점에 보존한다. 별도 지원 파일·다중 파일 복구 기록을 만들던 이전 계획은 철회한다. 타이머·글로우·수령 버튼마다 새 디스크 쓰기를 추가하지 않는다.

## 검사

30·45·60초 첫 경계뿐 아니라90·120·135·180초와5·10·30분의 횟수·총액을 자동검사한다. 수령을 미뤘을 때 누적, 부분 셀 수령, 혼합 중복 탭, 정지·복귀, 재도전과 기존 저장 후 재실행을 확인한다.

미션1·17·40·80에 같은 난수·생산 입력을 넣고 지원 없음/있음의 생산 수·클리어 시간·기지 체력·특수기술 소비를 비교한다. 전투를 오래 끌거나 지원을 모아 한꺼번에 받는 조건도 포함한다. 산식·반복 지급·수령·저장 자동검사는 통과했다. 지원 유무에 따른 미션별 클리어 난이도 비교는 후속 과제다.
