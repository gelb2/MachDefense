## 헬기 관련 작업 보류 — 2026-11-09

Mach 시리즈 전체 복원을 우선하기 위해 헬기 유닛의 모든 TODO와 미완성 작업을 보류한다. 도색·입체감·선회·사거리·디버깅·디자인·성능 검증도 포함한다. 릴리즈의 헬기는 원하는 사람만 사용하면 된다. 아이패드 개선과 락온 시스템 기획, 헬기 외 성능·기획 과제는 유지한다. [원고와 보류 이유](../editorial/helicopter-work-record-20261109.md).

## 배포와 플랫폼

- PWA 전환·해시 검증·변경 자원 재사용·95개 조각의 로컬 검사는 끝났다. 운영 업데이트 때도 저장과 실행 자원을 대조한다.
- Tauri Mac의 파일 저장·복원·자동 종료·서명·앱 교체 검사는 끝났다. 직접 메뉴·Cmd-Q 종료도 확인했다. 운영 다운로드·실제 업데이트와 창 닫기 검사를 보강한다.
- Mac 전장 카메라에 휠·트랙패드·키보드 이동을 검토한다. 현재 휠은 생산 목록에서만 동작한다.
- Galaxy USB 기본 설정의 재연결 유지, 무선 디버깅, 추가 Android 기기·OS와 배포용 서명을 확인한다.

## 게임과 화면

- 생산 목록 순서 편집과 저장·복원 연계를 만든다. INSTALL·UNINSTALL과 생산 대기열 7개를 유지한다.
- 원형 구조물·밀집 포탑의 길찾기와 원본/재구현의 포탑 설치 좌표 차이를 조사한다. 원본도 허용하는 미션3 구덩이 설치는 유지한다.
- 실제 시간에 따른 셀 생산량과 게임 틱을 측정한다. 합성 90Hz 입력에서 Android가 45틱/초가 되는 조건을 실제 기기에서도 확인한다.
- 크레딧·셀의 자동 생산·드롭·보상을 계산하고 1.25배로 늘렸을 때를 검토한다. 증액은 아직 확정하지 않았다.
- 반복 긴급지원의 장기 자금 흐름·난이도·성능을 비교한다.
- 타이틀·스플래시 가장자리와 iPad·데스크톱의 확대 비율을 원본 자원·시야와 비교한다. 기각한 1280×800 그림은 사용하지 않는다.
- 월드 배경·HUD·유닛의 표시 경계를 조사한다. HUD 외형 재설계와 화면 밖 적에 대한 포탑 반격은 보류했다.
- 적을 터치하면 가까운 메크가 크로스파이어를 발사하는 락온을 설계한다. 메크마다 3초 간격이며 기존 특수기술은 유지한다.

## 검사와 기록

- 원본과 발사·생산·피격·클리어의 실제 출력음을 녹음해 비교한다.
- 같은 조건의 반복 측정, 첫 발과 동시 발사, 장시간 발열·메모리, 120Hz 기기를 검사한다.
- iPhone 설치형 PWA, 사진 촬영·알람·전화·잠금 뒤 복귀, 두 세로 방향의 회전과 입력을 직접 검사한다.
- 비정상 레벨이 든 로컬 저장의 보정·초기 로드·메뉴·전투를 조사한다. 정상 코드 복원 검사와는 별도다.
- 포팅판의 이름 입력·가격 합성·영문 선택·필터·MapInfo와 같은 난수 조건의 전투를 추가 대조한다.
- 「나는 이렇게 테스트했다」「나는 이렇게 일을 시켰다」를 사용자 글감과 검사 근거로 작성한다. Sass 집필 자료는 별도로 정리한다.
- Mesabloo에게 보낼 감사 연락의 채널과 영어 초안을 준비한다. 발송 전에 작성자가 검토한다.
