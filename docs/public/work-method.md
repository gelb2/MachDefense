MachDefense를 시작할 때는 HeavyMach1을 복원하며 겪은 일이 있었다. 사격마다 저장하고, 게임 그림을 UIKit 경로에서 반복 생성하고, 이미 있는 게임 버튼 절차를 두고 플랫폼별 버튼을 만들던 구현을 내가 지적하고 고치게 했다. 다음 게임에서는 그때의 절차와 검증 도구를 가져오도록 했다.

## 포팅판 대조

먼저 포팅판을 실행하게 했다. 내가 아이폰에서 생산·교전·기지 파괴·미션 승리와 실패를 확인했다. 그다음 원작 기능을 새 소스코드로 재구현하고, 포팅판과 비교하도록 지시했다.

포팅판은 원작 동작을 확인할 기준이었다. 생산 아이콘의 방향, 비용 표시, 포탑 배치 안내, 소리와 결과 화면까지 비교해야 했다. 재구현판에서 돌아간 유닛 아이콘이나 빠진 생산 완료음을 발견할 때마다 원작과 대조하라고 했다. 게임이 시작되고 적을 부술 수 있다는 것만으로 복원이 끝났다고 볼 수는 없었다. [원작 대조와 수정](troubleshooting.md)

## 개발 계획과 수정 범위

나는 보고서를 반드시 쓰게 하고, 개발 계획을 먼저 세우게 했다. 빠진 요구와 이해할 수 없는 구현 방향을 읽었다. 과제가 크면 어느 부분을 고칠지, 게임 규칙을 담은 코어 모듈을 건드리는지 물었다. 작업 브랜치를 나누고 커밋도 나눠서 잘못된 변경을 되돌릴 수 있게 했다.

내 표현을 빌리자면, Codex의 기상천외한 개발 방향과 아키텍처 파괴행각, 하나에 꽂히면 업무지시까지 무시하고 자기 할 것만 하며 토큰을 태우는 행각을 막으려고 코덱스를 쥐어팼다. HeavyMach1에서 지적한 실수를 기억하라고 하는 것만으로는 충분하지 않았다.

## 기지 기관총 발사 시 끊김

아이패드에서 기지 기관총이 쏠 때 화면이 끊겼다. 적 탱크의 포탄에서는 같은 현상이 보이지 않았다. 나는 발사마다 객체를 만들거나 자원을 다시 그리는지, HeavyMach1 때처럼 저장을 반복하는지 물었고 Instruments로 확인하도록 했다.

Codex가 만든 효과음 처리에는 발사마다 오디오 컨텍스트를 연결했다가 해제하는 코드가 있었다. 원작은 초기화한 컨텍스트를 유지했다. Time Profiler에는 오디오 출력 시작·중단을 기다리는 경로가 나왔다. 컨텍스트와 음원 버퍼를 재사용하도록 고쳤다.

그 뒤에는 화면 연결과 활성 전환에서 오디오 세션을 메인 스레드로 설정한 코드도 발견됐다. OS 응답을 기다리면 게임 입력과 그리기가 함께 밀릴 수 있었다. 이 호출을 직렬 작업 큐로 옮겼다. 이후에도 내가 백그라운드에서 돌아와 보니 음악만 들리고 효과음이 사라져 있었다. 이번에는 출력 장치 재시작이 빠져 있었다. 각각의 원인과 수정은 [트러블슈팅](troubleshooting.md)에 남겼다.

## Android 이식 범위

Android를 만드는 동안 이미 동작하는 iOS·iPadOS 파일을 바꾸지 말라고 했다. 게임의 이동·피해·생산·강화·저장·메뉴·HUD는 공용 코드를 쓰고, Android 쪽은 화면·터치·파일 접근·생명주기·음향 연결을 맡게 했다.

첫 Android 이식에서 Apple·공통 소스·모듈·자원·검사·루트 빌드 설정 2,978개 파일의 해시가 작업 전후 같았다. Android의 화면 생성 순서와 오디오 재개 오류도 Android 쪽에서 수정했다. 내 아이폰의 진행을 옮겨 Galaxy에서 Stage 33에 들어가 생산과 장비를 확인했다. [Android 구현과 저장 이전](../evidence/android-native-20261106.md)

나중에 내가 승인한 강화 확장이나 복원 코드처럼 모든 플랫폼에 필요한 기능은 공용 모듈에 넣었다. 한 플랫폼을 붙이느라 기존 코드를 바꾸는 일과, 게임 전체의 기능을 확장하는 일을 구분해 지시했다.

## 10레벨 확장·생산 HUD·포탑 외형

포탑·기지·특수공격의 상한을 10레벨로 늘릴 때는 원작 테이블 구조를 유지하게 했다. 추가 단계의 공격력·내구력·사거리·발사 수와 비용을 먼저 보고받았다. 적용된 앱에서 사거리가 늘지 않는 것을 내가 발견해 다시 수정시켰다. 생산 목록도 기존 INSTALL·UNINSTALL을 살리고 설치된 유닛을 모두 스크롤해 고르게 했다.

그림은 별도로 검수했다. 포탑 무기부는 원작 5레벨을 그대로 쓰고 몸체만 채택한 시안으로 바꾸도록 정했다. 게임 기능이 늘었다고 Codex가 마음대로 원작의 크기·화풍·질감을 바꿀 수 있게 두지 않았다. [추가 기능](features.md) · [강화·HUD 검사](../evidence/level10-hud-20261107.md)

보고서에는 수정한 코드와 실제 검사 결과를 붙이게 했다. 나는 정식 앱을 플레이하고, Codex는 치트 앱에서 그 조건을 다시 만들었다. 서로 확인한 결과를 대조하면서 다음 작업을 정했다.
