# 조작과 게임 기능

프로필을 만들거나 기존 슬롯을 선택한 뒤 미션을 고른다. 화면은 세로로 사용한다.

| 화면 요소 | 조작 |
|---|---|
| 오른쪽 생산 목록 | 유닛을 눌러 셀을 사용하고 생산한다. 포탑은 설치할 지점을 추가로 누른다. |
| 전장 | 드래그해 다른 구간을 본다. 메크와 적은 각자의 이동·교전 규칙으로 동작한다. |
| 하단 유닛·특수기술 버튼 | 오른쪽 목록을 전환한다. 특수기술을 선택하고 전장의 목표 지점을 누른다. |
| UPGRADE & EQUIP | 장비를 강화하고 생산 목록에 넣거나 뺀다. 특수기술은 크레딧으로 보충·강화한다. |
| BASE UPGRADE | 기지 무장·방어력·생산 시간·연구·셀 용량을 강화한다. |
| MENU | 일시정지·재개·저장 후 나가기·도움말을 연다. |
| 자금 버튼 | EMERGENCY RESUPPLY를 열고 준비된 지원을 받는다. |

원작에는 프로필 슬롯 5개와 위메이드판 기준 미션 80개가 있다. 전투의 셀과 저장되는 크레딧을 구분한다. 셀은 현재 전투에서 생산에 사용한다. 미션별 클리어 횟수와 장비·강화·잔량은 프로필에 남는다.

긴급지원은 전투 시간 30·45·60초마다 크레딧·셀·혼합 지원을 준비한다. 지원 창에 수령 가능 금액이 표시되며 CLAIM을 누르면 받는다. [지급 계산](../emergency-resupply-economy.md).

치트 앱의 TEST 버튼으로 검사 조건을 설정할 수 있다. 일반 앱에는 이 버튼이 없다.
