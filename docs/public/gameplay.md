# 조작과 저장

iOS·iPadOS·Android 네이티브 앱과 웹·PWA가 같은 C++ 게임 코드를 사용한다.

프로필을 만들거나 슬롯을 선택한 뒤 미션을 고른다. 오른쪽 목록에서 생산할 유닛을 누른다. 포탑은 설치할 위치를 한 번 더 누른다. 생산 목록은 위아래로 스크롤한다. 웹의 휠·트랙패드 스크롤은 생산 목록에서 동작한다. 전장 카메라의 휠·키보드 이동은 아직 없으며, 전장을 드래그해 다른 구간을 본다. 브라우저에서는 같은 화면을 마우스로 클릭하고 드래그할 수 있다.

하단 버튼으로 유닛과 특수기술 목록을 전환한다. UPGRADE & EQUIP은 장비 강화와 INSTALL·UNINSTALL, BASE UPGRADE는 기지 강화다. MENU에서 일시정지·재개·저장 후 나가기를 선택한다.

자금 버튼이 빛나면 긴급지원 창에서 CLAIM을 눌러 지원을 받는다. 창을 닫으면 전투를 계속한다. 앱에서 나갔다 돌아온 뒤에는 일시정지 메뉴의 Resume Game을 누른다.

진행을 옮길 때는 슬롯 선택 화면의 **GET CODE → COPY**로 코드를 복사한다. 다른 기기의 **ENTER CODE**에 붙여넣고 **CHECK → YES**를 누른다. iPhone·iPad·Android·웹/PWA가 같은 MD1 코드를 사용한다. 전체 5슬롯의 진행·보유 유닛·강화·필살기 잔량·자금을 함께 옮긴다. 마지막으로 저장한 상태를 복원하며, 전투 중 움직이던 유닛과 발사체는 포함하지 않는다.

원작 상한을 넘긴 포탑·기지·특수공격 레벨을 옮길 때는 받는 앱과 PWA도 v0.4 이상이어야 한다. 이전 버전은 해당 코드를 거절한다.

복원 전 저장은 백업된다. CANCEL이나 NO를 누르면 현재 진행을 유지한다. 복원에 성공하면 슬롯을 골라 계속 플레이한다.
