# 실행과 검사

## iOS·iPadOS

iPhone·iPad에 일반·치트 앱을 설치했다. 80미션 진행·저장, 전체 강화 구매·일반 무장, 생산·특수공격 검사를 수행했다. 실제 iPad에서는 10분 전투와 20회 월드 진입도 확인했다. 반복 긴급지원과 효과음 복귀 수정 뒤의 결과는 별도 기록에 있다.

## Android

Galaxy와 에뮬레이터에서 각각 기존 C++ 검사 35개와 앱 실행 검사 13개가 통과했다. 실제 게임 입력으로 생산·강화창·긴급지원·승패·다음 미션·재도전을 확인했다. Surface와 Activity 재생성, 홈 왕복, 오디오 포커스 조건 주입도 검사했다. 에뮬레이터에서는 80개 미션의 로딩과 렌더를 확인했다.

Galaxy 전투 약 65초, 3,935프레임에서 프레임 간격 중앙값은 16.67ms, 99백분위는 16.85ms였다. 25ms 초과는 1회였고 게임 저장 쓰기는 없었다. 사용자는 Android 정식 앱의 첫 미션 시작과 클리어에 문제가 없었다고 확인했다.

아이폰의 32미션 완료 저장을 Galaxy 일반 앱에 옮겼다. Stage 33 진입, 해금된 생산 유닛 12종, 특수기술 5종, 강화·자금·점수·잔량과 재실행 보존을 확인했다. 아이폰 저장은 작업 전후 같은 바이트였다.
