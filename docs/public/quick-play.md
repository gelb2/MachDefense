# Quick Play — PWA와 공유 복원 코드

[MachDefense 플레이·PWA 설치](https://gelb2.github.io/MachDefense/)

## PWA로 설치하기

Xcode나 Android Studio로 빌드하지 않고 플레이하려면 PWA를 설치한다. 홈 화면에서 앱처럼 열 수 있고, 자원 다운로드가 끝나면 인터넷 없이도 플레이하고 진행을 저장한다.

- iPhone·iPad: Safari에서 위 주소를 열고 **공유 → 홈 화면에 추가**를 선택한다.
- Android: Chrome에서 위 주소를 열고 **INSTALL GAME**을 누른다. 설치 안내가 나오면 Chrome 메뉴에서 **앱 설치** 또는 **홈 화면에 추가**를 선택한다.
- Mac: Chrome의 **INSTALL GAME** 또는 Safari의 **파일 → Dock에 추가**를 선택한다.

설치한 앱을 열고 자원 다운로드를 마친 뒤 플레이한다. 브라우저 탭에서 바로 하려면 **PLAY IN BROWSER**를 누른다. 터치나 마우스·트랙패드로 유닛을 생산하고, 전장을 드래그해 이동한다. [조작 방법](gameplay.md).

## 레벨업이 힘든 사람을 위한 방법

내 아이폰 네이티브 앱에서 직접 플레이한 진행도의 복원 코드를 공유한다. 메크를 모으고 강화하는 과정을 일부 건너뛰고, 해금된 장비와 자금으로 플레이할 수 있다.

| 공유 진행도 | 내용 |
|---|---|
| 프로필 | 1번 슬롯, 나머지 4개 슬롯은 비어 있음 |
| 진입 가능한 다음 미션 | Stage 42 |
| 크레딧 | 20,329Cr |
| 보유 유닛 | 12종: MachineGun, ShotGun, Missile, HMG, PlasmaGun, Tanker, IonRifle, RifleTurret, MissileTurret, PlasmaCannon, IonCannon, Vulcan |
| 특수기술 잔량 | 공중 폭격 4회, 공중 미사일·핵폭탄·크로스파이어 각 1회, EMP 0회 |

유닛 순서·강화·자금·특수기술 잔량은 아이폰 저장값 그대로다. 복원 후에는 선택한 프로필에서 이어서 플레이한다.

### 코드 적용

1. 게임의 프로필 선택 화면에서 **GET CODE → COPY**로 현재 진행도를 복사해 따로 보관한다.
2. 아래 공유 코드를 복사하고 **ENTER CODE**의 입력란에 붙여넣는다.
3. **CHECK → YES**를 눌러 복원한다.
4. 복원된 프로필을 선택하고 미션에 들어간다.

**현재 코드는 전체 프로필 5개를 함께 교체한다.** 기존 진행으로 돌아갈 때는 1번에서 보관한 자신의 코드를 같은 방법으로 입력한다. iPhone·iPad·Android·웹/PWA에서 같은 코드를 사용한다.
