# 검증 계획

포팅판 대조 중 반복 검사를 먼저 자동화하라는 최신 지시에 따라 Apple XCTest 3종을 연결했다. [자동검사 결과와 명령](evidence/apple-automated-sweep-20261104.md). 같은 입력과 기대값을 자동으로 재검사하고, 차이가 난 항목을 직접 확인한다. 이후 앱 아이콘·UI·실기기 성능·화면 확장 순서는 유지한다.

준비 검사: 문서 연결·스킬 원본 해시·IPA 차단·원본 읽기 전용 검증·원격 private 상태를 확인한다.

원본 분석 후: 전체 유닛/무기/미션 목록, 초기 저장, 입력·시간·난수 조건, 화면 캡처와 원본 함수 대응을 작성한다. 일반/치트 앱의 전체 교전·성장·모달 입력·저장 복원·배경 복귀를 검사한다. 원본 버튼의 외형·상태·입력 영역을 대조한다.

플랫폼 확장 후: iPhone/iPad 시뮬레이터·실기기, native Mac, Android 에뮬레이터·실기기, 웹/PWA/Tauri를 구현된 범위별로 검사한다. 성능은 실제 기기와 Instruments 등 도구·부착 조건·측정 시간·분포를 기록한다. 시뮬레이터 성능을 실기기 성능으로 보고하지 않는다.

설치→실행→직접 조작→로그 저장→입력 해제→앱 종료→홈 화면 복귀를 구분한다. 타이틀 실행만으로 전체 게임 정상으로 판정하지 않는다. 게임 구현 전에는 위 검사를 완료 표시하지 않는다.

포팅 단계의 실행 순서와 기능 목록은 [포팅판 치트 검증 계획](compatibility-cheat-validation-plan.md)을 따른다. 치트앱과 일반 앱의 저장을 분리한다.

[사용자 실기기 관측과 비교 ID](port-observations-20261104.md)를 기능 검증표에 포함한다. 사용자 확인과 시뮬레이터 재현을 각각 기록한다.

[유니버설 에셋 검사](universal-assets-plan.md)에 따라 기기별 에셋 선택·합성·확대 품질과 논리 크기·입력 일치를 확인한다.

## 재개발판 검사 단계

최신 실행 순서는 포팅판 대조 → 인게임 일러스트 앱 아이콘 제작 → 아이콘 방향·가격·회전 재검사 → 치트앱 전체 기능 연속 검사 → 성능·음향·메모리·생명주기 검사 → iPhone·iPad 화면 확장 계획 수립이다. 빠른 기능 검사와 실제 속도 성능 측정을 구분한다.

[소스 재개발 계획](source-reimplementation-plan.md)의 최신 순서를 따른다. 치트앱의 값 설정과 실제 버튼 조작으로 원작 기능을 구현하면서 80개 미션의 진행·보상·저장·재실행을 검사한다. 전체 해금이나 강제 승리만으로 정상 진행 검사를 대신하지 않는다.

그다음 현재 원본 화면 배치에서 전체 회귀·생명주기·장시간 실행·성능·독립 빌드를 검사한다. **iPhone·iPad 화면 확장은 이 전체 검증 뒤에 진행한다.** 화면 확장 후 배치·터치와 영향을 받는 전투·진행·저장을 다시 검사한다. 이전 단계의 유효한 증거는 보존하고 재사용한다.

치트·80개 미션의 최신 결과는 [치트 앱과 캠페인 검사](evidence/source-cheat-campaign-20261104.md)를 따른다. 강제 기지 파괴·치트 조건 자동 교전·원래 난이도의 플레이 비교는 서로 다른 검사로 기록한다.

## 전체 무기와 효과의 프레임 검사

2026-11-04 사용자 지시로 화면 확장 전 반드시 수행한다. [MD-PERF-01~05](usability-todo.md#전체-무기-프레임-검사--2026-11-04-사용자-지시)를 따른다. 원본 무장 표에서 기지·아군·적·특수기술과 강화 단계 목록을 만들고 치트앱의 실행 결과를 각 항목에 연결한다. 공유 무기 정의는 같은 정의인지 확인한 뒤 중복 측정을 줄이되, 서로 다른 기체의 발사 위치·총구·탄피·동시 발사 연결은 각각 확인한다.

발사 없는 대기와 첫 발사·연사·비행·명중·폭발·다수 동시 사격을 비교한다. 실제 프레임 간격과 계산·그리기 명령 생성·렌더 제출·화면 제출 대기를 ms로 기록한다. 목표 간격과 분포·초과 수를 함께 남긴다. 측정값은 메모리에 모아 검사 종료 시 저장한다. Time Profiler를 부착한 결과와 분리한 결과를 구분하고, 메모리 검사 도구가 추가한 부하를 게임 자체 부하로 단정하지 않는다.

기지 기관총 발사 끊김과 적 탱크 포탄 정상 관측을 첫 재현으로 검사한다. 파일 접근·이미지 디코딩·GPU 업로드·효과 생성·사운드 처리 중 지연 위치를 측정하여 수정하고, 같은 조건과 일반 앱에서 다시 확인한다. 아직 전 무기 실기기 프레임 측정은 완료하지 않았다.

## iPad 지원 방향

사용자가 원작에서 확인한 방향은 세로 정방향과 세로 뒤집기다. [MD-ROTATION-01~03](usability-todo.md#ipad-화면-회전--2026-11-04-사용자-관측)에 따라 가로 회전을 시도했다가 되돌아오는 현상을 조사한다. 일반·치트 앱에서 두 세로 방향의 화면과 터치, 전투·메뉴·모달·중단 복귀를 검사한다.
