# 검증 계획

준비 검사: 문서 연결·스킬 원본 해시·IPA 차단·원본 읽기 전용 검증·원격 private 상태를 확인한다.

원본 분석 후: 전체 유닛/무기/미션 목록, 초기 저장, 입력·시간·난수 조건, 화면 캡처와 원본 함수 대응을 작성한다. 일반/치트 앱의 전체 교전·성장·모달 입력·저장 복원·배경 복귀를 검사한다. 원본 버튼의 외형·상태·입력 영역을 대조한다.

플랫폼 확장 후: iPhone/iPad 시뮬레이터·실기기, native Mac, Android 에뮬레이터·실기기, 웹/PWA/Tauri를 구현된 범위별로 검사한다. 성능은 실제 기기와 Instruments 등 도구·부착 조건·측정 시간·분포를 기록한다. 시뮬레이터 성능을 실기기 성능으로 보고하지 않는다.

설치→실행→직접 조작→로그 저장→입력 해제→앱 종료→홈 화면 복귀를 구분한다. 타이틀 실행만으로 전체 게임 정상으로 판정하지 않는다. 게임 구현 전에는 위 검사를 완료 표시하지 않는다.

포팅 단계의 실행 순서와 기능 목록은 [포팅판 치트 검증 계획](compatibility-cheat-validation-plan.md)을 따른다. 치트앱과 일반 앱의 저장을 분리한다.

[사용자 실기기 관측과 비교 ID](port-observations-20261104.md)를 기능 검증표에 포함한다. 사용자 확인과 시뮬레이터 재현을 각각 기록한다.

[유니버설 에셋 검사](universal-assets-plan.md)에 따라 기기별 에셋 선택·합성·확대 품질과 논리 크기·입력 일치를 확인한다.

## 재개발판 검사 단계

[소스 재개발 계획](source-reimplementation-plan.md)의 최신 순서를 따른다. 치트앱의 값 설정과 실제 버튼 조작으로 원작 기능을 구현하면서 80개 미션의 진행·보상·저장·재실행을 검사한다. 전체 해금이나 강제 승리만으로 정상 진행 검사를 대신하지 않는다.

그다음 현재 원본 화면 배치에서 전체 회귀·생명주기·장시간 실행·성능·독립 빌드를 검사한다. **iPhone·iPad 화면 확장은 이 전체 검증 뒤에 진행한다.** 화면 확장 후 배치·터치와 영향을 받는 전투·진행·저장을 다시 검사한다. 이전 단계의 유효한 증거는 보존하고 재사용한다.
