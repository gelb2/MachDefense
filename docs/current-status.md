## C++ 소스 재개발

`GameSession`이 원본 메뉴·문 전환·World·HUD·강화·결과창·저장을 연결한다. `createGame`을 구현했고 일반·치트 시뮬레이터 앱을 빌드했다. iPhone·iPad 시뮬레이터에서 직접 프로필 생성·첫 미션·도움말 종료·생산·아군 이동을 확인했다. iPad에서는 공습 목표 지정·재고 차감·Save & Exit·종료 후 재실행도 검사했다. 최초 연결 검사 22개에 치트·캠페인·연출·저장 실패 검사를 추가한 당시 31종이 통과했다. 이후 FrameIO 검사를 추가했으며 변경별 실행 결과는 아래 근거 문서에 기록한다.

- 공용 C++20: 저장·표·청크·조립·생산·이동·무기·투사체·상태이상·드롭 아이템·공습·집중사격·보상·기지/장비 강화·메뉴·HUD.
- Apple: Objective-C++ 실행기, OpenGL ES GPU 렌더, OpenAL 버퍼 재사용, 이름 입력, 파일 저장, 앱/오디오 생명주기.
- 원본 이미지 1,109개·음원 80개·고유 표 94개·MCB 3개를 준비했다. 제품 빌드 입력에 IPA·호환 실행기는 없다.
- 원본 저장 3개의 바이트 왕복, 신규 프로필 기본 장비·5슬롯, 기지 강화 6종의 3,900 Cr 차감을 검사했다.
- 80맵을 phone/pad 좌표 조건에서 각각 읽어 기지 위치·체력·조립과 스프라이트 범위를 검사했다. 이 검사는 80개 미션을 실제 플레이해 클리어한 결과가 아니다.
- GameSession 검사에서 프로필 생성·미션 진입·생산·일시정지·비활성 복귀·강화창·결과창·다음 미션을 연결했다. 승리는 검사 코드로 적 기지를 파괴해 발생시킨다.
- 저장은 프로필 변경, 결과창, Save & Exit에서 실행한다. 전투 tick과 발사·피해 때 파일을 쓰지 않는다.
