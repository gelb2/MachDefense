# 게임 기획

원작 MachDefense의 교전·생산·진행·성장·저장·화면·음향을 복원한다. 기준 판본의 실제 규칙은 원본 비교와 분석으로 확정한다. 새 유닛·자동조준·HUD 편집 등 HeavyMach 1에서 추가한 기능을 자동으로 가져오지 않는다.

최초 목표는 원작과 비교 가능한 Apple 실행판이다. 원본 패키지는 iPhone/iPad 대상으로 표시되며 일반판과 WeMade 판본의 차이를 먼저 확인한다. 출시 플랫폼·최소 OS·새 기능은 조사 결과와 사용자 지시로 확정한다.

## 광고 표시 금지 — 2026-11-04

사용자 지시: HeavyMach 1·HeavyMach 2·MachDefense 모두 광고를 표시하지 않는다. 원본 호환판과 소스 재구현판, 모든 플랫폼에 적용한다. 광고 배너·전면 광고·보상형 광고를 추가하지 않고 광고를 요청하지 않는다. 원본에 광고 API 호출이 있으면 광고를 표시하지 않는 호환 처리를 마련한다. 원본 IPA는 수정하지 않는다.

## 긴급지원

전투 하단의 기존 자금 버튼을 누르면 EMERGENCY RESUPPLY가 열린다. 크레딧은 30초, 셀은 45초, 혼합 지원은 60초마다 준비된다. 받을 자원이 있으면 자금 버튼이 스킬 선택 때와 같은 밝은 타일로 바뀐다. CLAIM은 표시된 자원을 수령하며, 셀 용량을 넘는 잔여분은 같은 전투 동안 보관한다. CLOSE로 전투에 돌아간다. 지원 창·일시정지·백그라운드 동안 지원 시간도 멈춘다. 전투를 다시 시작하면 대기 지원분과 시간은 초기화한다. [금액](emergency-resupply-economy.md).

## 진행도 복원과 추가 플랫폼 계획

슬롯 선택 화면에서 진행도를 코드로 생성하고 다른 기기에서 복원한다. 원본 5슬롯을 유지하며 전체/단일 슬롯과 확장 설정의 복원 범위를 모든 플랫폼에서 동일하게 제공할 계획이다. 공용 게임을 웹·PWA·Tauri Mac에서도 실행한다. [설계·작업 순서](save-transfer-web-tauri-plan.md). 현재 웹/PWA는 전체 5슬롯 복원을 제공한다. 단일 슬롯·확장 설정·네이티브 앱의 복원 UI·Tauri 연결은 남았다. [구현 결과](evidence/web-pwa-20261106.md).


## 강화 상한 통일 — 2026-11-07 확정 요구

플레이어의 메크·탱커·포탑·기지 강화·특수공격의 최대 레벨을 모두 10으로 맞춘다. 현재 10인 항목은 유지하고, 포탑 5→10, 기지 Cannon·Defense 7→10, Bomb·Missile·Nuclear 5→10, EMP 4→10, Crossfire 8→10을 추가한다. 미사용 특수공격이나 적 유닛을 새로 해금하는 요구는 아니다.

기존 단계의 성능·외형·소리를 유지한다. 기존 최종 단계에서 다음 단계로 넘어가는 강화 비용과 연결은 추가해야 한다. 새 단계도 레벨별 표와 원작 부품 조립·무기·이펙트·음원 선택 절차를 사용한다. 공격력뿐 아니라 발사 수·간격·재장전·사거리·효과 범위의 단계별 변화를 함께 설계한다. 기존 핵폭탄의 1발 고정, 크로스파이어의 탄당 피해 고정처럼 계열별 성장 특성을 대조한다. 13개 항목·59단계의 수치 확장을 v0.4에 구현했다. 후속 폭발 반경·이온·플라즈마 효과 수정은 별도 작업 브랜치에 있다. ### 1차 구현: 수치 확장과 최종 레벨 자원 재사용

2026-11-07 사용자 지시: 원작 상한 이후 단계는 공격력·체력·발사 수·발사 간격·재장전·사거리·효과 범위·가격 등 수치부터 설계한다. 새 이미지·발사체 그림·효과 이미지·사운드는 만들지 않는다. 계열별 원작 최종 레벨의 몸체·포신·레이더·아이콘·발사체·이펙트·음원을 재사용한다. 현재 10레벨인 항목의 기존 값은 유지한다.

원작 테이블의 열·형식과 게임 계산 절차를 유지하고 필요한 레벨 행·참조를 추가한다. 기존 상한의 다음 강화 가격과 다음 행 연결만 확장을 위해 수정한다. 기지처럼 단계 번호로 부품 이름을 만드는 경로는 성능 단계와 재사용할 외형 단계를 구분한다. 외형을 최종 레벨로 고정해도 무기 성능까지 기존 상한으로 고정되지 않게 검사한다. 새로운 부품 조립 정의가 필요한 경우에도 기존 이미지와 연결점을 재사용한다.

확장 수치는 계열별 기존 패턴을 근거로 정한다. 탄당 피해·연사 횟수·발사 간격·재장전을 함께 계산해 연속 사격 화력을 비교한다. 간격의 양수 하한, 한 틱 발사 수, 최대 동시 탄환·효과·음향 호출과 정수 범위를 확인한다. 기존 1발형·연사형 특성을 유지하며 모든 항목에 같은 배율을 적용하지 않는다. 원작 표를 만드는 데 사용한 공식으로 표현하지 않는다.

원본 상한까지의 동작 대조, 신규 각 단계의 구매·생산·공격·효과·저장·복원 검사, 기지 공격/방어 조합, 다수 고레벨 포탑과 특수공격의 치트 전투·프레임 측정을 수행한다. iOS·iPadOS·Android·Web/PWA가 같은 표와 공통 처리를 사용한다. 기존 복원 코드의 형식은 유지하고 표 기반 레벨 검증과 이전 앱으로의 복원 결과를 확인한다.

### 추가 레벨 외형 시안 — 2026-11-07 후속 지시

수치 확장 후 사용자가 원작 화풍·도트·부품 조립을 따르는 새 외형 시안을 요청했다. 포탑 6종 Lv.6–10과 기지 몸체·기관총·레이더 Lv.8–10 대상이다. [전용 스킬](../.agents/skills/extend-machdefense-art/SKILL.md)과 [39개 시안](../Art/Level10/20261107/README.md)을 사용한다. 원본 그림을 보존하고 시안 검수 후 별도로 조립·렌더·사격 검사를 한다. 현재 앱은 최종 원작 그림을 재사용한다. 후속 대조에서 공용 포탑 몸체 5개가 누락돼 전체 시안 대상은 44개로 정정했다. 이후 몸체 5개를 제작하고 원작 연결점과 크기로 조립 미리보기를 만들었다. 추가 레벨은 원작 최종 단계의 표시 크기·몸체와 무장 비율·연결점을 유지한다. 업그레이드를 이유로 물체 크기를 늘리지 않는다. ### 락온 처치 — 2026-11-07 기획

적 포탑·탱크를 포함한 모든 적 유닛을 대상으로 한다. 터치한 적과 가장 가까운 메크 한 대가 크로스파이어를 발사한다. 현재 크로스파이어 레벨의 피해·탄수·속도·효과를 그대로 사용하고 메크별 3초 간격을 둔다. 사거리 내 적이 없으면 락온과 레티클을 숨기며 표적 사망 시 해제한다. 기존 크로스파이어와 전투 규칙을 보존하고 프레임·메모리 검사를 포함한다. 아직 구현하지 않았다. [세부 요구](usability-todo.md#md-lockon-strike-01--락온한-적을-터치해-처치).

## 레이저 포탑 해금 — 2026-11-07

발칸 포탑을 보유하고 미션 30을 클리어하면 레이저 포탑 Lv.1을 확정 지급한다. 발칸을 늦게 얻었다면 다음 클리어에서 지급한다. 미션 30 이후 저장은 프로필을 선택할 때도 조건을 확인해 소급 지급한다. 이미 레이저를 보유하면 레벨·설치 상태를 유지하며 다시 지급하지 않는다. 발칸을 아직 얻지 못한 경우에는 기존 추첨 정책을 유지하므로 레이저 지급도 늦어진다.

원작 레이저는 생산비 200셀, Lv.1 탄당 피해 20·사거리 표 값 220·14연사다. 발칸은 600셀·피해 20·사거리 300·40연사다. 레이저는 발칸보다 강한 상위 대체 무기가 아닌 저렴한 추가 선택지로 배치한다. 가격·전투 수치·음원은 바꾸지 않는다. [해금 구현과 검사](evidence/laser-turret-unlock-20261107.md).
