# 화면·스테이지 전환

슬롯→메뉴→미션→전투→결과→성장/업그레이드→다음 미션의 실제 원본 전환을 기록한다. 모달 창의 입력 소비와 게임 tick 중단/재개를 연결한다. 배경 전환 뒤 중복 창, 열린 창 뒤 전투 진행, 닫히지 않는 버튼을 검사한다.

포팅판 원본 분석과 실행 검증을 진행 중이다. 소스 재개발은 아직 시작하지 않았다.

2026-11-04 사용자 실기기 확인: 적 기지 파괴→미션 클리어, 아군 기지 파괴→실패 창→미션 선택 복귀. 다음 스테이지와 저장 지속 검사는 남았다. [MD-PLAY-02/03](port-observations-20261104.md).
