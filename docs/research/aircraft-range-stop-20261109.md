# 헬기 사거리 내 정지

2026-11-09. 헬기가 사거리 안에서도 표적 중심의 경로를 계속 따라가던 동작을 수정했다. 표적을 사거리 안에서 포착하면 감속해 정지한다. 표적이 지정 사거리 밖으로 나가면 다시 접근한다. 원본 유닛의 추격·표적 선택·이동 코드와 헬기 사거리·HP·가격·무장·레벨 수치는 그대로다.

수정은 헬기 전용 `AircraftTactics.hpp`에 한정했다. 재접근 때에는 표적 중심 대신 사거리 80% 지점을 목적지로 삼고, 90% 안에 들어오면 다시 감속한다. 재출발 기준은 사거리 밖이다. 경계에서 계속 정지·출발하지 않도록 두 거리를 나눴다. 이미 사거리 안에서 포착한 새 표적에는 그 자리에서 감속한다. 긴급회피가 끝나면 표적 거리를 다시 판단한다.

## 확인 결과

- [수정 전 재현](../evidence/aircraft-repair-20261109/range-before.txt): 600틱 뒤에도 속도가 0이 아니어서 정지 조건이 실패했다.
- [코어 55개](../evidence/aircraft-repair-20261109/range-core.txt) 통과. 새 검사는 4종×Lv.1·10×휴대폰·태블릿 16조건에서 접근·공격·정지, 표적 이탈 후 재접근, 표적 사망 후 재탐색, 사거리 유지와 저장 쓰기 0회를 확인했다. 12방향 접근 검사도 통과했다.
- [Chrome](../evidence/aircraft-repair-20261109/range-chrome.json)·[WebKit](../evidence/aircraft-repair-20261109/range-webkit.json)의 실제 웹 치트빌드에서 네 기체 Lv.1·10의 정지 상태 사격을 확인했다. 정지 뒤 120틱 동안 위치가 그대로이며 실제 피해·발사음이 발생했다.
- [원본 보존](../evidence/aircraft-repair-20261109/range-preservation.json): 보호 파일 2,652개와 원본 유닛 160개 조건의 결과가 같다.

이전의 ‘사격 중 표적 주위를 12방향으로 계속 순환한다’는 검사는 최신 정지 지시와 충돌하므로 접근·정지 검사로 바꿨다. 긴급회피의 12방향 선택 검사는 유지했다.

## 전투 결과 비교

같은 난수·미션 55·스카웃 3기·7,200틱 관찰에서 [수정 전](../evidence/aircraft-repair-20261109/mission55-before-stop.txt) Lv.1은 3기 사망, Lv.10은 2기 사망이었다. [정지 수정 후](../evidence/aircraft-repair-20261109/mission55-after-stop.txt)에는 각각 2기·0기 사망이었다. 이 한 조건에서는 적에게 계속 접근하던 경로를 없앤 뒤 생존 결과가 달라졌다. 전체 캠페인의 생존율이나 밸런스 확정값으로 확대하지 않는다. 표·피해·무적 시간은 이번 단계에서 조정하지 않았다.
