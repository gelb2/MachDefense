# 헬기 긴급회피 가속·감속

2026-11-09. 헬기 긴급회피를 경로 전반 가속·후반 감속으로 바꿨다. 거리의 절반 지점에서 최고속도에 도달하고, 목적지에서 속도 0으로 멈춘다. 회피 방향 후보·목적지 선택·재사용 대기·최대 무적 0.45초와 원본 발사체·피격 코드는 유지했다.

## 시간과 속도

수정 전 네 기체의 Lv.1·10, 휴대폰·태블릿, 네 시작 속도 조건을 합친 64개를 기록했다. [수정 전 궤적](../evidence/aircraft-repair-20261109/dodge-before.csv)의 실제 종료 시간은 약 0.249~0.398초였다. 도착 조건 때문에 최대 무적 시간보다 먼저 끝나는 경우를 포함한다.

새 곡선은 회피 시작 때 기존 이동 계산으로 종료 틱을 구한다. 이 계산은 발동당 최대 28번으로 제한되며 새 타이머·스레드·DB·파일 기록을 쓰지 않는다. 선택한 목적지까지 직선 이동하며, 시작 속도 중 회피 방향의 성분을 반영한다. 경로에 수직인 시작 속도를 그대로 운반하는 비행 물리 모형은 아니다.

[수정 후 궤적](../evidence/aircraft-repair-20261109/dodge-after.csv)과 [64조건 대조](../evidence/aircraft-repair-20261109/dodge-comparison.json)에서 목적지와 종료 틱이 모두 같았다. 모든 조건에서 목적지 초과 없이 정확히 도착했고 최종 속도는 0이었다. 같은 시간·선택 거리를 유지하면서 전반 가속·후반 감속을 적용해, 중간 최고속도는 이전의 약 1.313~1.652배가 됐다. 최고속도 증가를 숨기거나 기존 속도 상한까지 유지했다고 보고하지 않는다. 실제 헬기의 공력 전체를 재현한 것도 아니다.

## 검사

- [코어 56개](../evidence/aircraft-repair-20261109/dodge-core.txt) 통과. 새 검사는 위 64조건에서 기존 종료 틱·목적지, 전반 속도 증가·후반 속도 감소, 중간 지점의 최고속도, 목적지 정지, 저장 쓰기 0회를 대조한다. 기존 일시정지·무적·대기·진영·피격음 검사도 통과했다.
- [Chrome](../evidence/aircraft-repair-20261109/dodge-chrome.json)·[WebKit](../evidence/aircraft-repair-20261109/dodge-webkit.json)에서 실제 연속 회피·회피 중 HP 보호·회피 밖 피해와 플레어 표시를 확인했다. 두 브라우저의 기록은 보호 관찰 190프레임, 피해 관찰 24프레임이며 저장 쓰기 0회다.
- [원본 보존](../evidence/aircraft-repair-20261109/dodge-preservation.json): 보호 파일 2,652개와 원본 유닛 160개 조건의 결과가 같다.
- [미션 55 후속 기록](../evidence/aircraft-repair-20261109/mission55-after-dodge.txt)은 사거리 정지 수정 뒤 같은 조건에 가감속을 추가한 관찰이다. 개별 관찰 결과를 전체 캠페인 밸런스 확정으로 확대하지 않는다.

일반 이동·사거리·무기 수치와 공통 이동 소스는 수정하지 않았다. 이번 단계는 헬기 전용 `AircraftTactics.hpp` 변경이다. 장시간 프레임·메모리와 실제 아이폰 설치본 비교는 최종 검사에서 진행한다.
