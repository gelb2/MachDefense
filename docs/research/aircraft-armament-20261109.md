# 헬기 무장 적용 — 2026-11-09

사용자가 지정한 4종 무장을 Lv.1–10에 연결했다. 기존 기체 이미지·비율·도장은 유지한다. 무기 효과와 소리는 아래 원작 정의를 복사해 사용한다. 원작 무장 행은 바이트 단위로 보존했다.

| 기체 | 무장과 연결점 | 원작 정의 |
|---|---|---|
| 스카웃 | 기수 기관총, 측면 미사일 | 같은 레벨 머신건 메크, 미사일 메크 |
| 샤이엔 | 좌측 발사대 4발, 우측 발사대 3발 | 같은 레벨 미사일 메크의 탄체·폭발·궤적·음원 |
| 벨루가 | 양측 HMG, 양측 미사일 | 같은 레벨 HMG 메크, 미사일 포탑 |
| AH-10 | 기존 회전 기관포, 좌측 미사일 발사대, 우측 내장 로켓 발사대, 전방 캐논, 동체 안쪽 공습 미사일 발사대 | 같은 레벨 발칸포탑, 미사일 메크, E_Turret17_Wpn_01, E_Tank31_Wpn, AirStrike-Missile |

AH-10의 로켓과 공습 미사일은 기체 그림에 포함된 발사대의 소켓에 연결했다. 원작의 보이지 않는 부품 소켓 기능을 이용하므로 그림을 추가로 겹치지 않는다. 두 발사대는 기체 방향을 따른다. 고속 캐논은 원작 E_Tank31_Wpn의 실제 탄속을 3배로 적용한다. 공습 미사일은 해당 특수기술의 미사일 탄체·폭발 범위·궤적·음원을 재사용하며 AH-10에서 발사한다.

샤이엔은 한 번에 7발을 발사한다. 1발은 목표물 중심, 6발은 중심에서 해당 미사일 폭발 반경의 0.5배 떨어진 임의 방향으로 향한다. 양쪽 발사대를 같은 틱에 발사하며 발사 간격은 0, 재장전은 2.5초다. 기존 기수 부품의 그림은 유지하고 기관포 발사는 제거했다.

## 수치와 확인

기존 수치안의 총 발사 DPS 목표를 유지하며 새 무장 사이에 배분했다. 스카웃·벨루가는 기관총/HMG 60%, 미사일 40%다. AH-10은 발칸 30%, 캐논 25%, 나머지 3종 각 15%다. 각 무장의 실제 발사 빈도를 기존 WeaponController에서 측정하고 발당 피해를 정수로 반올림했다. 40개 레벨 조합의 목표 대비 최대 차이는 2.38%다. 이는 전탄 명중 가정이며 실전 DPS와 다르다.

- [기존 컨트롤러 발사 빈도](../evidence/aircraft-implementation-20261109/weapon-rates.tsv)

실제 World에서 40개 조합의 무장 수·발사·피해·소리·저장 호출 0회를 확인했다. 샤이엔은 중앙 1발·주변 6발의 목적지를 검사했다. AH-10 캐논은 실제 투사체 타입과 탄속을 검사했다. 포연·주퇴·탄피의 위치 검사와 웹 치트 검사는 다음 단계다.

사용자의 후속 사거리 지시는 웹 치트 검사 뒤 별도 커밋으로 적용한다. 샤이엔=같은 레벨 샷건 메크×1.10, 벨루가=같은 레벨 플라즈마 메크다. 스카웃과 AH-10은 기존 기준을 유지한다.

## 공통 발사 효과 확인

Lv.1·10의 실제 장착 무장 26개를 하나씩 분리해 World에서 발사했다. 기존 Efx_Fire 총구 효과, 기관총/HMG/발칸의 BulletShell, 주퇴, 무장별 피격·폭발, 미사일의 Efx_Trail01, 원작 발사음 호출을 확인했다. 미사일·로켓·캐논에는 원작 정의에 없는 기관총 탄피를 추가하지 않았다. 회피 중 기관총 탄피 배출점에도 기체와 같은 기울임 변환을 적용했다. 원작 유닛의 좌표 처리는 유지한다. [효과·회귀 검사 15개](../evidence/aircraft-implementation-20261109/fire-effects-tests.txt)가 통과했다.
