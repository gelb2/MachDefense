# 작은 행성 전등지기 조사

2026-11-06. 대상은 [작은 행성 전등지기](https://little-lamplighter.onrender.com/)다. 공개 페이지와 배포된 JavaScript를 읽고, Mac Safari에서 이동·시점 회전·전등 끄기/켜기를 확인했다.

## 무엇을 만든 작품인가

작은 구형 행성에서 캐릭터를 움직이고, 가로등을 켜고, 앉거나 주변 사물과 상호작용하는 3D 웹 공간이다. 밤하늘·금빛 조명·짙은 녹색 의상·작은 행동 버튼이 같은 분위기를 만든다. 첫 화면에서 긴 설명 없이 이동하고 가까운 사물의 행동을 발견하게 한다. 이 부분은 좋은 제품 설계다.

‘산사’와 비슷한 소규모 온라인 공간이 늘어난 흐름은 확인된다. 연합뉴스는 2026-10-31 온라인 산사와 파생 공간의 확산을 보도했다. 그 보도의 이용 수치는 산사에 관한 것으로, 이 전등지기 사이트의 이용자 수를 뜻하지 않는다. [보도](https://www.yna.co.kr/amp/view/AKR20261031034300005). 전등지기는 [바이브 차트](https://vibe-chart.app/s/31)에 @solbri.studio의 작품으로 등록돼 있다. 실제 개발 인원·기간·AI 사용량은 확인하지 못했다.

## 웹에서 가능한 이유

브라우저가 JavaScript를 실행하고 Three.js가 WebGL로 3D 장면을 그린다. React가 메뉴를, React Three Fiber가 3D 장면과 React를 연결한다. 다른 이용자의 위치와 공용 상태를 받는 WebSocket 연결도 클라이언트에 구현돼 있다. 브라우저 자체가 이 프로그램의 실행 환경이다.

| 항목 | 배포 코드에서 확인한 내용 |
|---|---|
| UI·3D | React의 버전 문자열 19.3.1, Three.js revision 180, React Three Fiber 코드 |
| 형상 | 구·상자·원뿔·튜브·돌출 도형을 조립한다. 일부 표면은 128×128 canvas 텍스처를 만들어 캐시한다 |
| 월드·이동 | 반지름 5.5인 구 표면의 위치·방향 벡터를 계산한다. 구면 거리를 써서 사물과의 거리를 판단한다 |
| 충돌 | 원형 장애물과 벤치 영역을 검사한다. 이동을 최대 0.06 길이로 나누고 겹침을 반복 보정한다 |
| 화면 비용 | 렌더링 픽셀 비율을 1~1.5로 제한한다. geometry 메모이제이션과 텍스처 캐시가 있다. 실제 FPS·발열은 이번에 측정하지 않았다 |
| 통신 | 같은 호스트의 `/ws`에 WebSocket으로 연결한다. 서 있을 때 위치 전송 간격은 코드상 100ms 초과 조건이다 |
| 상태 반영 | welcome/state를 받고 위치를 갱신한다. correction/reject/result도 처리한다. 연결 종료 후 재시도 간격은 1초부터 최대 15초까지 늘어난다 |
| 음향 | Web Audio로 효과음을 합성하고, OGG/MP3 배경음 파일을 읽는다. 음악 전환 시 음량을 조절한다 |
| 로컬 저장 | 이름·음소거·말풍선·음악 선택을 localStorage에 저장하는 경로가 있다 |
| 상호작용 | 전등, 벤치, 여우, 장미, 잡초, 우물, 상자, 화산 관련 코드가 있다. 모든 상호작용을 직접 시험한 것은 아니다 |

서버가 상태의 영구 원본을 어떻게 보관하는지는 배포된 클라이언트만으로 알 수 없다. DB 제품, 서버 재시작 후 보존, 동시 접속 한도, 운영비도 미확인이다. 이름을 기억하는 기능을 게임 전체 데이터의 영속성으로 해석해서는 안 된다.

이번 HTML에는 PWA manifest 링크가 없고, 받은 번들에는 service worker 등록과 IndexedDB 사용 문자열이 없었다. 따라서 설치형 PWA·오프라인 지원을 확인한 상태가 아니다. 별도의 비공개 파일이나 다른 배포가 없다고 단정하지 않는다.

## REA로 어디까지 확인했나

REA로 배포 JavaScript의 구문과 함수 관계를 분석했다. 라이브러리를 포함한 전체 번들 분석은 1,536MiB 힙 한도에서 실패했다. 이후 게임 코드가 시작되는 바이트 1,111,661부터 끝까지 103,501바이트를 별도 분석 입력으로 잘랐다. 출처 바이트와 해시를 보존했다. 이 분석은 JavaScript 1개, AST 노드 34,605개를 읽었고 파싱 실패는 없었다. 동적 호출과 외부 라이브러리 별칭은 일부 미해결로 남았다.

- 원본 번들: `assets/index-UvzzVFgF.js`, 1,215,162바이트.
- SHA-256: `d4e58148f8ab9955c0f3a75a2f83ff086190ca7ebb107f579f79b82984021f8a`.
- 추출 부분 SHA-256: `f990733694fca883cb03b28e3345e62138b05983992a442f73444ce2e5a6bef9`.
- 전체 분석 근거: `ev_657ec123dc144e8a24d52d62b6e75a0e5b66401f9eac49ac42eef4538e4c4da0`.
- 좁힌 분석 근거: `ev_8a001af1cb7add89078148357c44f556ec45de958faa95ba74abd4a7faa68d26`.

함수 이름이 축약된 배포 코드에서 화면 조립, 이동, 충돌, 입력, 저장 키, 통신 메시지, 음향 경로까지 읽을 수 있었다. 원래 TypeScript/JSX 파일·주석·Git 이력·서버 소스가 복구된 것은 아니다. 원본 소스맵 참조도 받은 번들에서는 발견되지 않았다. 제3자 배포 파일은 무시된 로컬 조사 폴더에 보관하며 게임 소스에 편입하지 않는다.

실행 검사는 Safari에서 했다. W 이동 후 행동 안내가 ‘풀 뽑기’에서 ‘불 끄기’로 바뀌었고, 드래그로 시점이 바뀌었다. E 입력 후 ‘불 켜기’로 전환됐으며 다시 켠 뒤 조사 탭을 닫았다. REA 브라우저 캡처는 빈 actions 입력이 거절돼 실행되지 않았다. 통신 구조 설명은 배포 코드에 근거하며 패킷 캡처 결과로 보고하지 않는다.

## HeavyMach·MachDefense와 비교

| 비교 항목 | 작은 행성 전등지기 | HeavyMach·MachDefense 복원 |
|---|---|---|
| 경험 | 작은 공간에 머물며 사물·다른 접속자와 느슨하게 상호작용 | 전투·성장·미션을 진행하고 저장한 게임을 여러 환경에서 이어서 플레이 |
| 장점이 드러나는 곳 | 색감·조명·공간 구성·간단한 조작 안내 | 원작 동작 대조·공용 게임 규칙·플랫폼 연결·저장 호환·실기기 수정 |
| 주요 기술 과제 | 구면 이동·카메라·충돌·다중 접속 상태·일관된 분위기 | 전투·경제·강화·미션·원작 자원·음향·생명주기·데이터 이동 |
| 실행 구조 | JavaScript·React·Three.js·웹 통신 | C++ 공용 코어와 Apple/Android 실행기, Wasm 웹 실행기 |
| 이번 확인 범위 | Mac Safari 조작과 배포 클라이언트 분석 | 기존 복원 기록과 현재 소스. 이번 조사에서 게임 회귀 검사를 새로 돌리지는 않았다 |

이 사이트를 보고 개발을 그만둬야 한다는 결론은 나오지 않는다. 이 작품은 첫인상의 일관성과 접근성이 좋다. 그 성취는 인정할 만하다. 동시에 이 화면은 제작자의 개발 역량 전체나 다른 사람과의 서열을 보여주지 않는다. 사용자가 복원 과정에서 정한 공용 모듈 경계, 원작 대조, 플랫폼별 회귀, 코드 기반 데이터 이동도 구체적인 개발·기획 판단이다.

MachDefense가 참고할 부분은 첫 진입 안내의 짧은 길이, 가까운 행동만 드러내는 UI, 색과 재질의 일관성, 렌더 해상도 상한과 캐시다. React·Three.js로 게임을 다시 쓰거나 현재 게임 버튼을 DOM으로 옮길 이유는 없다. 작은 행성의 원래 설계에 맞는 선택과 MachDefense가 지켜야 할 원작 UI 절차는 각각의 요구에 따라 판단한다.
