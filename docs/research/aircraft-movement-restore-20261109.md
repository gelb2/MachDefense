# 헬기 이동 복구

2026-11-09. Codex는 헬기가 표적에 달라붙는 문제를 고치면서 사거리 안 정지와 회피 속도 곡선 변경을 적용했다. 사용자의 요구는 지상 유닛 정지 조건을 조사해 과도한 접근을 막는 것이었다. 기존 헬기의 선회·회피 움직임과 전투감각을 보존해야 했는데, Codex가 변경 범위를 넓혔다. 기능 검사 통과를 근거로 보존 조건을 충족했다고 판단한 것도 잘못이다.

## 복구

- `e80f2a2`의 사거리 정지와 `1c10585`의 긴급회피 속도 곡선을 철회했다.
- `AircraftTactics.hpp`를 이전 아이폰 확인본 `38903e4`와 바이트 단위로 같게 복구했다. 12방향 선회 목적지, 기체별 위상·방향·전환 시간, 관성·제동·기수 회전, 긴급회피·무적·재사용 대기가 복구 범위다.
- MCB 정의파일·Apple PNG 준비·선회 그림 연결은 유지했다. 원본 유닛 코드·이미지·수치는 바꾸지 않았다.
- 변경 전 검사를 복구했다. 철회한 동작을 요구하던 검사 소스와 당시 결과는 `rejected-movement` 및 기존 증거 파일에 남겼다. 과거 성공 로그를 현재 이동 동작의 성공으로 제시하지 않는다.

## 확인

[복구 대조](../evidence/aircraft-repair-20261109/movement-restore-checks.json): 코어 54개와 Chrome·WebKit 무장·회피 검사가 통과했다. 긴급회피 64조건의 모든 출력이 변경 전 기록과 같았다. 보호 파일 2,652개 해시와 원본 유닛 160조건의 결과도 같다.

표적에 과도하게 접근하는 원인과 거리 처리 수정은 별도로 다룬다. 지상 유닛식 정지나 새 회피 곡선을 다시 적용하지 않는다. 기존 선회·회피·속도·회전 수치를 보존하며 접근 목적지 계산을 조사한다.

## 아이폰 정식 설치

Xcode의 기존 서명 경로로 Release 복구본을 빌드하고 아이폰에 덮어 설치했다. 서명 검증·검사 플러그인 없음·선회 자원 유지·실행 성공을 확인했다. 설치 직전 저장 42,496바이트와 설치 직후 저장이 완전히 같다. [설치 확인](../evidence/aircraft-repair-20261109/movement-restore-iphone.json). 사용자 플레이를 위해 추가 기기 조작은 중단했다. 실기기 대량 효과 정량 계측은 아직 하지 않았다.
