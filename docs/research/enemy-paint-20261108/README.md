# 헬기 4종 텍스처 수정용 원작 도장 참조

2026-11-08. 적 유닛 조사는 스카웃·벨루가·AH-10·샤이엔의 텍스처 수정에 사용할 원작 참조를 마련하기 위한 작업이다. 원작 적 스프라이트 122개를 6개 비교판에 모았다. 원작 데이터의 적 기체·포탑·기지 58종이 119개 이미지를 참조한다. 파일 해시 122개를 현재 이미지와 대조해 일치를 확인했다.

사용자 승인 조건: 스카웃·벨루가·AH-10의 주색 변경은 채택했다. 부품 하나 전체를 임의의 다른 색으로 바꾸는 처리는 제외한다. 샤이엔도 색조 변경 대상이다. 승인된 기체의 크기·비율·외곽·구조·묘사를 보존하며 원작의 표식 크기와 배치 방식을 참고한다.

## 헬기에 적용할 기준

- 주색 위에 원작과 비슷한 면적의 위험 표식·짧은 띠·무장 강조를 검토한다. 구조를 추가하거나 기존 부품을 다시 설계하지 않는다.
- 무장 강조는 실제 연결된 무장과 대응시킨다. 그림만 보고 기관포·캐논포·로켓 구성을 확정하지 않는다.
- 스카웃의 짧고 넓은 몸체를 포함해 4종의 승인 비율과 크기를 유지한다. 로터·총구·부품 연결점도 보존한다.
- 실제 게임 크기에서 표식이 읽히는지, 명암과 패널 묘사를 덮지 않는지 원작과 나란히 비교한다.

이 문서는 수정용 참조 준비 결과다. 4종 텍스처 수정·웹 검사·커밋 완료 보고가 아니다. 공통 발사 효과의 코드 조사도 아직 미착수다. 해당 순서는 [발사 효과 TODO](../../usability-todo.md#md-aircraft-fire-fx-01--헬기-무장에-원작-공통-발사-효과-연결)에 기록했다.
