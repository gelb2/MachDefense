## 게임 규칙 — 반복 지원

사용자 정정: 한 번 주고 끝내는 지원이 아니다. 전투 시작부터 크레딧30초마다, 셀45초마다, 혼합60초마다 계속 소량을 제공한다. 미션별·프로필별1회 제한은 삭제했다. 지급액과5분·10분 누적 계산은 [반복 지급 초안](emergency-resupply-economy.md)을 따른다.

전투 시간 기준 고정 주기로 지원분을 준비한다. 수령 후부터 주기를 다시 세지 않는다. 잠금·백그라운드·일시정지 시간은 제외한다. 지원창은 기존 강화창처럼 전투를 멈추고, 닫으면 이전 상태에 따라 재개한다.

미수령 지원분은 해당 전투의 대기 잔액으로 누적한다. 셀은 실제 빈 공간만큼 받고 나머지를 남긴다. 혼합 항목의 크레딧·셀은 따로 차감한다. 중복 탭으로 같은 잔액을 두 번 받는 것은 막고 다음 인터벌 지원은 계속 허용한다. 용량·연구 강화는 다음 인터벌의 금액부터 반영한다.

## 화면과 문구

원작 GameHUD·Button·SpriteFont·Frame으로 버튼과 창을 만든다. 원작의 창 테두리·버튼 누름·선택·비활성 표현을 재사용한다. HUD 글로우는 포팅판의 스킬 선택 효과를 먼저 대조해 적용한다. 하나라도 실제 받을 자원이 있으면 SUPPORT가 빛나고, 셀이 가득 차서 아무것도 받을 수 없거나 모두 수령했으면 꺼진다.

세 항목은 받을 수 있는 누적액, 다음 지원까지 남은 시간과 CLAIM을 표시한다. 수령 뒤에도 다음 지원 카운트다운을 표시하며 영구 CLAIMED 상태로 끝내지 않는다. 혼합 지원에서 이미 받은 크레딧과 남은 셀을 구분한다. 닫기는 CLOSE다. 화면 문구는 모두 영어다.

수령 후 영문 메시지 초안:

- GENERAL J: “Welcome back, Commander. This front has waited since 2011. Command has released emergency credits.”
- ADMIRAL B: “Your return is noted, Commander. The supply reserve is yours. Keep your machines moving.”
- MARSHAL P: “You have returned to a war left unfinished in 2011. Credits and cells are authorized. Hold the line.”

J·B·P는 원작자 오마주용 가상 서명이다. 원작자의 실제 발언으로 표시하지 않는다. 원작 글꼴의 준비된 글리프를 순차 표시하고 같은 글꼴의 커서를 쓴다. 메시지를 누르면 즉시 전체 표시한다. 메시지 완료를 기다리지 않고 닫을 수 있다. 타이핑을 위한 새 음원·반복 효과음은 추가하지 않는다.

## 공통 모듈과 저장

| 위치 | 책임 |
|---|---|
| Core/Simulation/EmergencySupport | 세 항목 활성화·지급액 고정·잔여량·수령 판정 |
| 기존 BattleClock·WorldEconomy | 게임 시간·셀 용량·자원 반영 |
| Core/Session | 전투별 지원 상태 수명, 수령액 반영, 기존 저장·실패 처리 |
| Core/Presentation | 지원 창·글로우·영문·타이핑·터치 |
| 플랫폼 HostServices | 공통 저장 코드가 만든 바이트의 읽기·원자적 파일 교체만 연결 |

원본 MachDefense.sav의0xa600바이트와5슬롯 구조를 유지한다. 지원 시간·대기 잔액은 전투 상태이며, 이미 받은 크레딧은 기존 자금 필드에 반영한다. 기존 저장 지점에서 함께 저장한다. 전투 재시작은 지원 시간도0으로 초기화한다. 현재 원작처럼 전투 중간 상태는 재실행 후 재개하지 않는다.

미션별 영구 수령 제한을 위해 제안했던 별도 확장 파일과 다중 파일 복구 기록은 필요 없어졌으므로 삭제한다. 지급은 메모리의 동일 상태 갱신에서 대기액 차감과 자원 증가를 함께 처리한다. 시간·글로우·타이핑·수령마다 새로운 파일 쓰기를 넣지 않는다. 기존 저장 실패·재시도 검사는 유지한다.
