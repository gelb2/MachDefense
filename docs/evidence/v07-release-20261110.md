# v0.7 출시 전 검사

2026-11-10. 대상은 채택 타이틀을 연결한 공통 코드 `b310be4`와 그 코드로 만든 v0.7 배포 파일이다. 이 기록은 로컬 빌드와 출시 전 검사 범위다. 작성 시점에는 최종 main 병합, GitHub Release·운영 PWA 게시와 v0.7 아이폰 정식 설치를 수행하지 않았다. 이후 실제 배포·아이폰 설치 결과는 [v0.7 릴리즈 본문](https://github.com/gelb2/MachDefense/releases/tag/v0.7)에 기록한다.

## 타이틀과 기존 구현 보존

채택한 가로·세로 그림을 공통 Menu와 준비 자원에 연결했다. 중앙 원본 그림·기체·글자의 비례를 유지했다. 가로는 벼랑·하늘·구름을 자연스럽게 이어 채운다. 승인한 가로 1600×900 영역과 준비 그림의 중앙을 비교한 픽셀 차이는 0이며, CgBI 최적화 전후 RGBA도 같다.

Menu 검사는 7개 화면 비율과 비대칭 안전 영역 3조건을 통과했다. Chromium과 WebKit에서는 각각 320×480, 390×844, 820×1180, 1280×800, 1600×900, 3440×1440의 타이틀과 슬롯 진입을 확인했다. 경계선 수정 뒤 비교 지점의 인접 RGB 차이는 0이다. 독립 대조에서도 초광폭 수직 정렬과 승인 중앙 영역 보존을 확인했다.

이번 타이틀 작업은 `20b714c`의 원본 유닛·헬기 소스와 에셋을 변경하지 않았다. [타이틀 구현·화면·해시·검사 근거](https://github.com/gelb2/MachDefense/blob/v0.7/docs/evidence/title-integration-20261110.md).

Chromium 검사 종료 때 브라우저 종료가 5초를 넘겨 시험 프로세스를 닫았다는 로그가 있다. 그 전에 위 기능 검사는 모두 완료됐다. 이 결과를 모든 기기·장시간 전투의 무충돌·무프레임드랍 보증으로 확대하지 않는다.

원시 로컬 근거는 `.local/title-release-20261110/`의 `core-test.log`, `normal-chromium.log`, `normal-webkit.log`, `android-build-final.log`, `tauri-build-final.log`, `cargo-test.log`, `storage-host.log`, `release-artifact-review.json`에 보존했다. 기기 식별자와 사용자 저장 내용은 이 문서에 싣지 않았다.

## 남은 코어 검사 실패

`AircraftAudit`와 `AircraftCampaign`은 통과하지 않았다. 승인 V5 그림을 적용한 기존 `b4184ed` 이후의 에셋과 검사의 옛 기대값이 맞지 않는다. `AircraftCampaign`은 `AircraftCampaignTests.cpp`의 `has(f,body)` 검사에서 멈췄다. 감사 입력 167개와 관련 검사·보상 코드를 `20b714c`와 대조한 결과 동일하여, 이번 타이틀 변경으로 생긴 차이는 없었다.

실패를 통과로 바꾸거나 전체 코어 검사가 성공했다고 기록하지 않는다. 헬기 개선 보류 지시에 따라 이번 릴리즈 작업에서 헬기 에셋·로직과 이 두 검사를 수정하지 않았다. 헬기 도색·입체감·선회·사거리·성능을 포함한 남은 개선은 [보류 과제](../public/roadmap.md)에 남아 있다.

## 배포 파일 준비

`build/release/v0.7`의 8개 파일 존재와 SHA-256을 대조했다. Android·Mac 체크섬 목록의 모든 항목이 실제 파일과 같고, 업데이트 명세의 0.7.0 버전·v0.7 다운로드 경로·서명이 준비한 패키지와 맞는다.

- Android 정식·치트 APK 2개와 `android-SHA256SUMS.txt`.
- Mac ARM64 ZIP, 업데이트용 `.app.tar.gz`, 서명 파일과 `desktop-SHA256SUMS.txt`.
- `tauri-update.json`.

Android APK는 개발용 서명, Mac 앱은 ad-hoc 서명이다. 웹 자원 명세 SHA-256은 `95d1a4ac80ccba45c328e224ef58d72daf7953ab679995e7c460f598c9f2d334`다. 배포 과정에서 실행 코드나 자원이 바뀌면 해당 빌드·검사 근거를 다시 확인해야 한다.
