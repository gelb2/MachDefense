# 레이저 포탑 생산 가격

2026-11-07 사용자 지시: 레이저 포탑도 레벨별로 생산 가격을 올린다.

| 표시 레벨 | 이전 셀 가격 | 새 셀 가격 |
|---|---:|---:|
| 1 | 200 | 200 |
| 2 | 200 | 220 |
| 3 | 200 | 240 |
| 4 | 200 | 270 |
| 5 | 200 | 300 |
| 6 | 200 | 330 |
| 7 | 200 | 360 |
| 8 | 200 | 390 |
| 9 | 200 | 420 |
| 10 | 200 | 450 |

시작 가격이 같은 원작 라이플 포탑의 Lv.1~5 가격을 기준으로 삼았다. Lv.6~10은 마지막 증가폭 30셀을 유지한다. 원작 레이저는 전 단계 200셀이므로 이 증가는 사용자 요청에 따른 복원판의 변경이다. 강화 구입에 쓰는 크레딧, 피해·내구력·사거리·탄수·사운드는 이 변경에 포함하지 않는다.

`MachBuild_Name.tsv`의 `Cost`를 수정했다. `plan_level10.py`와 `apply_level10.py`에도 같은 규칙을 넣어 테이블 재생성 때 가격이 되돌아가지 않게 했다. 각 레벨에서 가격보다 1셀 부족하면 생산 불가·잔액 보존, 정확한 가격이면 생산 성공·잔액 0을 검사했다.

`Production`, `Level10Data`, `SaveData` 검사 3개가 통과했다. 웹·iOS·Android의 실제 HUD와 배포 결과는 최종 플랫폼 검사에서 추가한다.
