## 저장과 검사 조건

기존 치트 앱 저장 42,496바이트를 로컬에 백업했다. 일반 앱은 Library를 백업하고 기기 파일 목록을 조사했다. 검사 시작 전 일반 앱 컨테이너에는 MachDefense.sav가 없었다. 자동검사는 UUID 임시 폴더에 시험 저장을 만들고 검사 후 지운다.

명령줄 빌드는 개발팀 미지정, 개발팀 지정 후에는 코드 서명 오류로 중단됐다. Xcode에서 기존 개발팀을 선택한 뒤 빌드와 설치에 성공했다. 검사는 치트 앱을 호스트로 사용하며 Xcode 디버거가 연결됐다.

## 설치 앱 직접 조작

검사 뒤 Xcode에서 일반·치트 앱을 각각 새로 빌드해 무선 설치했다. 설치용 앱에는 XCTest PlugIns를 넣지 않았다. 설치 후 직접 조작은 디버거 없이 실행했다. 별도 일반·치트 Release 컴파일도 모두 성공했다. 실제 설치본의 빌드 구성은 Debug다.

일반 앱에서 다음을 직접 눌렀다.

- 새 프로필 `ipad` 생성 → Stage 1 → 도움말 닫기 → 전투 진입.
- MachineGun·Missile 생산: 대기열과 셀 차감, 출격 확인.
- RifleTurret 선택 → Tap to build 안내 → 지형 터치 → 생산·배치 확인.
- 기지 강화 창 열기·닫기, 크레딧 부족 항목 비활성 표시 확인.
- 스킬 버튼 → 공습 선택 → 지형 터치: 보유 수량 2에서 1로 감소.
- 홈 화면 이동 → 앱 복귀 → System Menu → Resume Game: 메뉴가 닫히고 셀 증가와 유닛 이동 재개.
- Save & Exit → 프로세스 종료 → 재실행: 프로필 `ipad`, Stage 1을 다시 불러왔다.

치트 앱에서 TEST 패널을 열어 크레딧 1,910→2,910 변경, START로 Stage 1 진입, 기관총·미사일 생산을 확인했다. Cr Research를 선택해 UPGRADE를 눌렀다. 크레딧은 2,910→2,410, 강화는 Lv.1→Lv.2로 바뀌었다. CLOSE로 창을 닫고 홈 이동·복귀·Resume 후 적 이동과 기지/유닛 사격이 재개되는 것을 확인했다.

직접 조작 구간도 메모리에 프레임 기록을 모아 앱 비활성 시 CSV로 내보냈다. 112.53초, 6,693프레임, 효과음 127회, 저장 쓰기 0회다. 프레임 간격 p99는 16.667ms, 25ms 초과는 5회였다. 게임 갱신 p95는 3.367ms, 오디오 호출 최댓값은 0.153ms다. 이 구간에는 타이틀·치트 패널·전투·강화 창이 함께 들어 있다.

기존 치트 저장 42,496바이트는 자동검사 뒤와 직접 조작 뒤 모두 백업과 일치했다. 일반 앱에는 새 시험 프로필이 남아 있다. 마지막에 일반·치트 프로세스를 종료하고 실제 iPad 홈 화면을 확인했다.

## 경고와 남은 검사

Xcode는 오디오 세션 활성화·설정의 메인 스레드 호출에 대해 응답 지연 가능 경고 2건을 남겼다. 실제 기관총·강화 무장·동시 사격 측정 구간에는 25ms 초과가 없었다. 경고의 호출 위치와 생명주기 전환 비용은 후속으로 조사한다.

원작 출력음 녹음 전수 대조와 기준/후보 각 3회 성능 비교는 남아 있다. 미션 10·11 정체, 밀집 터렛 정체, 화면 밖 표적, HUD·타이틀 그림은 기존 TODO다.

로컬 증거: `.local/module-ipad-device/`. 개인 저장과 기기 식별자는 저장소에 넣지 않는다.

## iPhone 정식 앱 설치 — 2026-11-05 06:08

같은 소스의 일반 MachDefense 앱을 Xcode에서 빌드하고 실제 iPhone Air에 무선 설치했다. 설치본은 Debug 구성이며 TEST 버튼·XCTest PlugIns가 없다. 코드 서명 검사를 통과했다.

설치 전 저장 42,496바이트를 백업했다. 설치 직후 저장은 백업과 바이트 단위로 같았다. 기존 슬롯의 Stage 17·Lv.65를 확인하고 전투에 진입했다. MachineGun 생산 버튼으로 대기열·셀 차감을 확인하고, MENU → Resume Game으로 메뉴가 닫히고 전투가 재개되는 것을 확인했다. 검사 후 프로세스를 종료하고 홈 화면으로 돌아왔다.

검사 후 저장은 4바이트가 달라졌다. 검사 전 파일을 복원하고 다시 받아 백업과 바이트 단위로 일치하는 것을 확인했다. 사용자 진행도는 검사 전 상태로 남겼다.
