# AH-10 장갑과 무장 하우징

AH-10 Lv.1–10에 중앙이 열린 장갑 10개와 기관포·캐논·미사일 후방 하우징 30개를 연결했다. 각 장갑은 중립·좌우 선회 7자세를 갖는다. 기존 몸체, 로터, 로켓·공습의 공유 이미지와 총구는 보존했다. 사거리·레벨 수치·무장 구성·이동·회피는 수정하지 않았다.

40개 제작 PNG를 CgBI로 준비하고 기존 PartsList·TileList·MCB 조립 경로로 읽는다. 각 레벨은 해당 장갑과 하우징을 명시적으로 참조한다. 기존 무장 별칭을 유지하므로 실제 5종 무장은 계속 연결된다. 장갑 셀은 24×22이며 몸체 기준 시작점은 (28,47), body socket 0과 자체 socket (-2,2), z=1을 쓴다. 70개 자세의 장갑 알파가 기존 몸체 외곽 안에 있다. [제작 입력·출처](../../Art/Aircraft/upgrades-20261109/ah10/README.md).

확인 결과:

- 정의·발사 효과·무장·전체 헬기·조작·캠페인 검사 6개 통과. 기존 좌표와 총구를 240개 조립 자세 및 1,260개 고정 포드 사례로 대조했다. [검사 기록](ah10-upgrades-20261109/core-tests.txt).
- 44개 기체 정의의 실제 소비를 조사했다. AH-10은 레벨마다 표시 부품 9개이며 새 그림 40개가 사용된다. [소비 조사](ah10-upgrades-20261109/consumption.json).
- Chrome·WebKit 각각 10레벨×7자세에서 새 40개 이미지를 읽었다. 같은 레벨·자세를 다시 표시할 때 추가 텍스처 업로드는 0이었다. [Chrome](ah10-upgrades-20261109/candidate-chrome.json), [WebKit](ah10-upgrades-20261109/candidate-webkit.json).
- 두 브라우저 총 140개 화면에서 AH-10 영역 밖 픽셀이 기준 자원과 완전히 같다. 다른 세 헬기·원작 탱크·배경을 포함한다. 기준은 `10ae41c`의 자원과 후보와 같은 레벨 선택 검사 화면이다. 처음 기준 바이너리가 레벨 선택을 지원하지 않아 얻은 화면은 폐기하고 다시 캡처했다. [비교](ah10-upgrades-20261109/web-preservation.json), [검사 수정 기록](ah10-upgrades-20261109/validation-notes.txt).
- 두 브라우저에서 4종×10레벨 전투·피해·사운드·접근·회피를 확인했다. 전투 중 저장 쓰기는 0이며 AudioContext 생성·종료 횟수는 검사 시작 이후 늘지 않았다. [Chrome](ah10-upgrades-20261109/combat-chrome.json), [WebKit](ah10-upgrades-20261109/combat-webkit.json).
- 원작과 다른 기체의 기존 정의·이미지를 보존했다. 원작 160개 시나리오의 추적 결과가 이전 검증 결과와 일치한다. 무장 30개는 CgBI 준비 후에도 알파와 전방 전체 RGBA가 기존과 같다. 실제 웹 패키지의 관련 55개 자원도 소스 자원과 같다. [보존 대조](ah10-upgrades-20261109/preservation.json), [패키지 대조](ah10-upgrades-20261109/package-preservation.json), [검사 대상 해시](ah10-upgrades-20261109/tested-sha256.json).

[확대 비교](ah10-upgrades-20261109/visual-review-3x.png), [시각 검토 범위](ah10-upgrades-20261109/visual-review.txt). 다른 134장은 자동 비교했으며 전부 수동 검수했다고 보고하지 않는다.

새 이미지 전체의 POT RGBA 계산량은 370KiB다. 한 레벨의 장갑과 하우징은 37KiB다. 장갑은 기체당 표시 부품 1개와 그림자 포함 제출 2회를 추가한다. 실제 최종 통합본의 GPU·다수 기체 성능은 별도 검사 대상이다. 이 결과는 AH-10 강화 외형 연결에 한정한다. 다른 기체의 남은 작업이나 전체 미술 승인을 뜻하지 않는다. iPhone 설치와 main 배포는 이 변경에서 수행하지 않았다.
