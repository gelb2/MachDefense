# 복귀 뒤 음악만 나오고 효과음이 멈춘 오류 — 2026-11-05

사용자는 모듈화 설치본에서 백그라운드로 나갔다 돌아오면 음악은 들리지만 포탄 발사·메크 생산 효과음은 들리지 않는다고 보고했다.

## 원인

공용 OpenALEffects는 비활성 때 `alcSuspendContext`, 활성 때 `alcProcessContext`를 호출했다. 포함된 OpenAL Soft 1.22.2에서 이 함수들은 기본 설정상 즉시 반환한다. 효과음을 출력하는 CoreAudio 장치를 정지·재시작하지 않는다. OS 오디오 세션이 비활성화되어 출력 장치가 멈춰도 기존 소스에 `alSourcePlay`를 호출할 수 있어 재생 호출 횟수만 증가한다. 음악은 별도 AudioQueue가 재개하므로 음악만 나오는 상태가 됐다.

이전 복귀 검사는 음악의 재생 시간과 효과음의 호출 횟수를 확인했다. 효과음의 실제 샘플 재생 위치를 검사하지 않아 이 실패를 놓쳤다. 메인 스레드 경고 0건은 효과음 복귀를 증명하지 않는다.

## 재현과 수정

실제 iPad에서 효과음의 `AL_SEC_OFFSET`을 읽는 검사를 추가했다. OS 세션을 실제 비활성화한 뒤 재활성화하고, HMG01.wav·BuildMachComplete.wav를 재생했다. 수정 전 최초 실행에서는 약 0.19초까지 진행했지만 복귀 후 두 효과음 모두 0초에서 멈춰 검사가 실패했다.

비활성 전환에서 `alcDevicePauseSOFT`, 세션 활성화 완료 뒤 `alcDeviceResumeSOFT`를 호출하도록 고쳤다. 이 경로는 CoreAudio의 AudioOutputUnitStop/Start까지 실행한다. 같은 활성 상태를 반복 요청하면 다시 시작하지 않는다. 음원 77개의 버퍼·소스와 컨텍스트를 재사용하고 게임의 생산·피해·저장 계산은 변경하지 않았다.

OpenAL Soft의 [장치 정지·재개 규격](https://openal-soft.org/openal-extensions/SOFT_pause_device.txt)은 모바일 백그라운드에서 장치 처리를 정지하고 복귀 후 재개하는 용도로 이 확장을 설명한다.

## 실제 iPad 결과

iPad Air 13-inch M2 / iPadOS 27.0.1, Xcode 디버거를 연결했다.

| 검사 | 결과 |
|---|---|
| 수정 전 복귀 검사 | 실패. 기관총·생산 완료음 재생 위치 0초 |
| 수정 후 같은 검사 | 통과. 0.2초 대기 뒤 0.192~0.213초 진행 |
| 중단·복귀 3회, 종료 알림 누락, 지연 알림, 오디오 재설정, 빠른 전환 10회 | 복귀 후 효과음 진행 확인 |
| 오디오·복귀·30초 전투 검사 | 6개 통과, 실패·실행 경고 0개 |
| 77개 효과음 재사용·생성/폐기 20회·음악 전환/반복 | 통과 |
| 1,800프레임 대기·기관총·강화 무장·동시 교전 | 모든 구간 p99 16.667ms, 25ms 초과 0회 |

검사는 효과음의 샘플 진행과 음악의 시간 진행을 확인했다. 스피커 출력 녹음 대조는 포함하지 않았다. 개인 저장은 검사 전 로컬에 백업했다. 로컬 증거는 `.local/effects-resume/`의 before/after/final-summary.json과 각 diagnostics다. 실패 기록을 보존했다.

후속 검사는 `MenuRenderTests.testForegroundRecoversWithoutInterruptionEnded`에서 음악·효과음 양쪽을 검사한다. 일반·치트 앱 모두 iPad에 다시 설치했다. 테스트 플러그인이 없는 빌드다.

## 설치본 직접 조작

디버거 없이 일반·치트 앱에서 기존 프로필로 미션 1에 들어갔다. MachineGun·Missile을 생산한 뒤 실제 홈 화면으로 나갔다 돌아왔다. 양쪽 모두 같은 프로세스에서 일시정지 메뉴가 열렸고, Resume Game과 추가 생산 입력이 작동했다. 메크 출격·이동·교전 재개를 화면으로 확인했다.

검사 후 두 앱을 종료하고 검사 전 저장 파일을 복원했다. 기기에서 다시 내려받은 파일이 백업과 바이트 단위로 일치했다. iPad는 홈 화면으로 돌려놓았다. 이번 수정본은 iPhone에 설치하지 않았다.
