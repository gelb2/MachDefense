# 레이저 크기·HD 자원·로컬 저장 레벨 대조

2026-11-07. 작업 브랜치 `feat/pwa-tauri-followup-20261107`. [현재 과제](../usability-todo.md)의 10·16·26번 조사다.

## 레이저 포탑 크기

확보한 원본 세 패키지의 포탑 7계열 × 5단계, 총 105개 PNG를 현재 자원과 대조했다. Apple CgBI 이미지의 알파 채널과 그림 경계는 모두 같았다. 레이저 Lv.5는 원본부터 다른 무장보다 크다.

| Lv.5 부품 | PNG 캔버스 | 투명 여백을 뺀 그림 범위 |
|---|---:|---:|
| 라이플 | 64×64 | 61×43 |
| 미사일 | 64×64 | 52×43 |
| 발칸 | 128×64 | 60×43 |
| 레이저 | 128×128 | 95×61 |
| 이온 | 128×64 | 69×26 |
| 플라스마 | 128×64 | 77×40 |
| 공용 몸체 | 64×64 | 53×60 |

`PartsList`의 레이저 무장과 `TileList`의 1×1 분할, `BattleModels::pose`와 `MachineSprites`의 균일 배율을 확인했다. 레이저만 확대하는 코드가 없다. Lv.6~10 무장은 사용자 지시대로 Lv.5 그림을 그대로 쓴다. 이 조사에서는 레이저 외형을 축소하지 않았다. 최종 앱에서는 몸체를 얹은 실제 표시 크기도 다시 확인한다.

## 확보한 세 판본과 HD 자원

세 패키지는 모두 `UIDeviceFamily=[1,2]`다. 이미지 수는 배포사 1.0.3이 1,109개, indieapps 1.0.3이 1,089개, indieapps 1.0.5가 1,094개다. 확보한 자료 안에서 별도 MachDefense HD 패키지는 찾지 못했다. HeavyMach2 HD와 혼동하지 않는다.

배경에는 512×1024와 iPon 256×512가 함께 있다. 도움말도 iPad 768×1024, iPon 320×480, Retina 640×960으로 나뉜다. 포탑·유닛의 별도 HD 세트는 확인하지 못했다. PNG 크기는 CgBI 청크 다음의 IHDR에서 읽었다.

현재 복원판은 전투 좌표 폭 256을 유지하고, 화면의 생산 HUD 왼쪽 공간에 월드를 균일 확대한다. 배율은 `(논리 캔버스 너비-64)/256`이다. 따라서 넓은 iPad·데스크톱에서는 유닛도 커진다. 가로·세로를 따로 늘리지 않는다. 원본의 iPad 투영·합성 텍스처·필터를 실행 화면과 대조하는 작업은 남았다. [기존 판본 조사](version-audit-20261104.md), [현재 좌표 규칙](../coordinate-policy.md).

## 로컬 저장의 비정상 레벨

실제 사용자 저장 대신 `SaveData::empty`로 만든 독립 프로필을 썼다. 표시 Lv.10은 저장값 9다. 표시 Lv.11에 해당하는 10, 255, uint32 최댓값을 넣고 같은 데이터를 복원 코드 검증기와 로컬 로드에 각각 전달했다. 기지는 한 바이트이므로 255까지만 시험했다.

| 대상 | 정상 저장값 9 | 범위 밖 코드 입력 | 범위 밖 로컬 저장 |
|---|---|---|---|
| 기지 | 미션 진입 성공 | 거부 | 미션 진입 시 `Assembly references unknown part` |
| 레이저 포탑 | 미션 진입 성공 | 거부 | 미션 진입 시 `Unknown saved build` |
| 핵공격 | 미션 진입 성공 | 거부 | 미션 진입 시 `Unknown special attack level` |

로컬 `SaveData::decode`는 길이와 체크섬을 검사하지만 테이블의 레벨 범위는 검사하지 않는다. 프로필 선택 때 한 차례 저장한 뒤 미션 진입에서 예외가 발생했다. 정상 플레이가 이 비정상 값을 만든다는 근거는 없다. 임의로 레벨을 낮추거나 사용자 저장을 덮어쓰는 보정은 추가하지 않았다.

후속 수정은 원본의 범위 밖 레벨 처리부터 확인하고, 최초 로드 때 비정상 프로필을 안내하며 원본 파일·다른 슬롯을 보존하도록 설계한다. 코드 입력의 거절 검사만으로 이 항목을 완료하지 않는다.

조사 스크립트·전체 이미지 목록·합성 저장 결과는 로컬 `.local/followup-audit/`에 보존했다. 원본 패키지와 실행 파일은 외부로 전송하지 않았다.
