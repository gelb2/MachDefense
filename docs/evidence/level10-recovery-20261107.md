# 10레벨 진행도와 복원 코드 검사

2026-11-07. 대상은 배포한 v0.4와 정식 웹 빌드 `cf230badbf0c7bae`다.

## 구현 확인

`Modules/SaveTransfer/Codec.hpp`는 원본 저장 전체 42,496바이트를 압축하고 CRC와 함께 MD1 코드로 변환한다. 레벨별로 별도 필드를 골라 복사하지 않는다. 5슬롯, 크레딧, 미션 완료 기록, 보유 유닛 순서·레벨·INSTALL 상태, 특수공격 레벨·개수·INSTALL 상태, 기지 강화 6종을 같은 바이트로 보존한다.

`Validate.hpp`는 현재 앱의 MachBuild·BaseUpgrade·SpAttackList 테이블로 허용 레벨을 검사한다. 원작 상한 5·7·8을 고정한 분기는 없다. 게임 내부의 레벨 0~9가 화면의 Lv.1~10에 대응한다. 추가 레벨의 유닛·무기·부품 연결은 복원 후에도 현재 공용 카탈로그에서 읽는다.

Apple·Android는 공용 Menu에서 코드 검사를 마친 뒤 `FileStore`에 저장 전체를 전달한다. 웹은 같은 Menu를 거쳐 IndexedDB 트랜잭션으로 저장한다. 플랫폼 어댑터가 레벨이나 유닛 목록을 다시 조립하거나 낮추지 않는다. 복원 중 실패하면 기존 저장을 유지한다.

## 추가 검사

- `TransferLevel10Tests`: 1~10레벨을 가진 5슬롯을 각각 게임의 ENTER CODE → CHECK → 확인 버튼으로 복원했다. 50슬롯의 저장 전체가 일치했다. GET CODE로 다시 얻은 코드도 같았다.
- 폰·패드 좌표의 100개 월드에서 복원된 기지 무기·체력, 포탑의 체력·사거리·무기 연결, 메크 조립과 이미지 연결을 검사했다.
- 기지 6종·유닛 14종·특수공격 5종에 지원하지 않는 11레벨을 넣은 1,250건을 실제 복원 메뉴에서 거절했다. 어느 슬롯이 잘못돼도 기존 5슬롯을 덮어쓰지 않았다.
- Lv.6~10을 섞고 유닛 순서·INSTALL 상태·특수공격 보유량·진척도·크레딧을 슬롯마다 다르게 만든 저장을 사용했다. 운영 Chrome·WebKit에서 실제 입력창과 게임 버튼으로 복원했다. 42,496바이트 일치, 재생성 코드 일치, 미션 진입, 백그라운드 복귀, GPU 복구, 오프라인 재실행을 통과했다. 페이지 오류는 0건이다.
- 복원 후 폰·패드 월드에서 특수공격 5종을 1~10레벨로 실제 사용한 100조건을 검사했다. 개수가 1씩 줄었고 발사체·효과 이미지가 연결됐다. 관련 CTest 6개가 모두 통과했다.
- 같은 혼합 저장으로 네이티브 FileStore의 백업·3지점 중단/재시작·rename/fsync 실패·롤백 검사를 통과했다.

v0.4의 기존 검사에도 130개 강화 조건의 코드 왕복과 iPad 치트 검사가 포함돼 있었다. 이번 후속에서는 5슬롯 전체와 실제 복원 메뉴·운영 브라우저를 보강했다. 새 혼합 코드를 실제 iPhone·iPad·Galaxy에 다시 입력하는 실기기 검사는 이번 후속에서 하지 않았다. 설치된 iPhone·iPad 정식·치트 앱 4개의 버전은 기기 조회로 0.4(4)를 다시 확인했다.

## 구버전으로 복원할 때

v0.3의 실제 강화 테이블을 별도 읽기 전용 폴더에 꺼내 검사했다. 구버전은 추가 레벨을 지원하지 않아 복원 코드를 거절한다. 원작 상한으로 낮춰 덮어쓰지는 않는다. 추가 레벨이 든 코드는 받는 앱과 PWA도 v0.4 이상이어야 한다. 기존 레벨의 코드 형식은 계속 MD1이다.

게임 규칙·복원 모듈·플랫폼 코드는 이번 조사에서 수정하지 않았다. 검사와 안내를 추가했다. 원본 IPA나 개인 저장을 공개 자료에 넣지 않았다.
