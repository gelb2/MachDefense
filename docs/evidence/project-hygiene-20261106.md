## 실제 코드 대조

[기능별 문서·코드·검사 연결](../code-document-map.md)에8개 영역을 정리했다.

- Core41개 구현 파일이 CMake 목록과 일치한다. Core에 플랫폼 SDK 헤더가 없고 OpenAL Soft317파일 해시와 Apple 시스템 OpenAL 미연결을 확인했다.
- GameSession은 월드를 그린 뒤 HUD를 추가한다. WorldPresentation은 배경 맵 폭과 유닛 표시를 별도로 처리한다. HUD 위 월드 누락은 재현/수정 전이며 이번 감사로 해결되지 않았다.
- GameHUD의 표시와 터치는 최대7개를 사용한다. 원작 제한 여부·전체 목록 개선은 미조사이며 기존 코드와 문서를 그대로 완료로 처리하지 않는다.
- 긴급지원의30/45/60초 주기, 미션 보상4%/2%, 셀 용량10%와 연구4초분 중 작은 값, 대기액 누적·부분 수령은 코드와 산식 문서가 일치한다. 지원창 열림은 게임 pause 조건에 포함된다. 지원 수령 때 새 파일 쓰기를 추가하지 않았다.
- 효과음은 OpenAL Soft, 음악은 AudioFile/AudioQueue다. 세션 설정은 Apple 실행기의 직렬 큐, 장치 복귀는 OpenALEffects의 pause/resume 연결이다. 과거 Apple OpenAL/일괄PCM변환 진단은 수정 전 기록이다.
- 저장은 GameSession의 기존 persist 경로를 사용한다. 한 줄 복원 코드는 아직 없다. 새로운10레벨 확장도 현재 구현으로 설명하지 않는다.
- GameHUD.cpp와 GameHUDTests.cpp는 develop 기준 `5bc233e`와 일치한다. 타이틀 변경은 feature에만 있고 마지막 설치 기록은 긴급지원 빌드다.

## 검사와 남은 범위

유지 문서72개의 로컬 파일·절 앵커·업무 라우트·스킬 사본 해시 검사를 통과했다. 문서 검사 회귀5개를 포함한 도구 검사11개, 모듈41개 파일 목록·플랫폼 헤더 경계·OpenAL 원본317파일 해시 검사와 diff 공백 검사도 통과했다. Git 이력3,383개 blob의 원본 패키지/바이너리 검사와27개 커밋의 gitleaks 검사도 통과했다. 이번 미커밋 문서·도구 변경을 별도 디렉터리로 복사한 시크릿 검사에서도 탐지0건이었다. 변경 파일의 원본 패키지/바이너리 검사도 통과했다. 보고 캡처4개는 기존 사이트 파일과 바이트가 같다. 결과와 로그는 `.local/hygiene-20261106`에 보존한다. 외부 링크 접속·보고 사이트 재배포, 최신 원격 fetch, 게임 재빌드·시뮬레이터·실기기 재검사는 이번 범위에 포함하지 않았다.

원작과 게임 전체의 완전 일치가 입증됐다는 뜻은 아니다. 이동 정체·HUD 위 월드 누락·타이틀 경계·생산 목록과 출력음/실제 OS 중단 등의 미완료는 [TODO](../usability-todo.md)에 유지한다. 운영 사이트는 이전 게시 상태이므로 다음 게시 때 최신 원고·TODO 다운로드를 함께 갱신한다.
