# 강화 목록 겹침 수정

2026-11-10. 헬기 추가 후 유닛 목록이 4행으로 늘었으나 상세창은 기존 위치에 남아 있었다. 제공된 화면에서는 이온 캐논·발칸이 상세창에 가려졌다. 수정 전 웹 치트빌드에서도 마지막 행과 상세창의 겹침을 재현했다.

공통 `UpgradeDialog`에서 화면 높이와 목록 행 수로 목록 영역을 정한다. 긴 세로 화면에서는 4행 전체를 표시하고 상세창·닫기 버튼을 그 아래 배치한다. 작은 화면과 가로 화면에서는 목록 안에서만 스크롤한다. 목록의 표시 경계와 입력 경계를 함께 적용한다. 드래그·다중 터치·화면 회전 중의 입력이 선택이나 구매로 이어지지 않도록 취소한다.

원본 이미지와 카드 크기, 기지·특수공격 강화창, 유닛·헬기 동작과 수치, 저장 형식은 변경하지 않았다. 일반 웹 빌드 ID는 `191e310b7d6c18ea`이며 치트 기능이 꺼져 있다. 이번 배포 대상은 웹·PWA다. 네이티브 앱을 빌드하거나 설치하지 않았고, GitHub 최신 릴리즈 v0.7의 설치 파일과 업데이트 명세를 유지한다.

## 검사

- 웹 치트빌드의 Chromium·WebKit에서 18개 유닛을 각각 선택하고 강화했다. 저장 경계를 지난 검사 프로필에서 선택한 유닛만 레벨이 올랐고, 비용이 차감됐음을 확인했다. 장착·해제도 각각 확인했다.
- 393×852, 320×480, 1200×800, 820×1180에서 마지막 행 선택·강화, 휠·드래그, 닫기와 다시 열기를 확인했다. 긴 화면의 전체 목록과 상세창은 겹치지 않는다. 짧은 화면은 목록을 스크롤한 뒤 마지막 행에 접근한다.
- 드래그 구간의 저장 쓰기와 구매는 없었다. Lv.10 이후 추가 강화 비용이 차감되지 않았다. 두 브라우저의 페이지 오류는 0이었다.
- `UpgradeDialog`, `GameHUD`, `GameSession` 코어 검사 3개가 통과했다. 목록 경계, 안전 영역, 화면 회전 중 입력 취소와 기존 기지·특수공격 버튼을 포함한다.
- 별도 읽기 전용 검토에서 좌표·클리핑·입력 연결을 대조했다. 필수 수정 결함은 발견하지 못했다.

검사는 개인 저장을 가져오지 않는 임시 치트 프로필로 진행했다. 첫 검사에서는 메모리에 반영된 강화 결과를 이전 디스크 저장으로 비교해 실패했다. 기존 검사 저장 명령으로 저장한 뒤 비교하도록 검사를 수정했다. 게임의 저장 횟수나 저장 정책은 변경하지 않았다.

재현 가능한 검사는 `Web/tests/upgrade-layout.mjs`다. 원시 로그·전후 화면·독립 검토 기록은 로컬 `.local/upgrade-layout-hotfix-20261110/`에 보존한다. 운영 게시 완료와 기존 PWA의 업데이트·오프라인 저장 유지 결과는 실제 배포 뒤 확인한다.
