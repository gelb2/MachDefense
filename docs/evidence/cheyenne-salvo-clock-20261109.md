# 샤이엔 동시 발사 시각 수정

샤이엔의 무지연 7발 사격이 특정 시각에 첫 틱 2발로 끊겼다. 기존 무기 컨트롤러는 발사 시각을 float로 저장하지만 월드는 double을 전달한다. 발사 후 저장한 시각이 위로 반올림되면 같은 틱의 남은 발사를 다음 시각으로 미뤘다.

기존에 추가한 헬기 분기에서 `ADuctMissile*`이고 `shotDelay == 0`인 무기의 입력 시각만 컨트롤러의 float 시각에 맞췄다. 월드 시계와 발사체 생성 시각은 유지한다. 원작 무기 컨트롤러, 원작 유닛 입력 분기, 기체 이동과 회피, 무장 수치, 이미지와 정의 파일은 바꾸지 않았다.

동일한 최종 회귀검사를 837ff38 코어에 연결하면 Lv1·대기 18틱에서 첫 사격이 2발로 실패한다. 수정 후 phone/pad × 10레벨 × 8시각의 160개 실제 World 사격은 모두 같은 틱 7발, 중앙 1발과 폭발 반경 절반 거리에 주변 6발을 유지했다. 상향 반올림 80개와 하향 반올림 60개, 정확한 float 시각 20개를 포함한다. 검사 표적은 Lv10의 발사 직후 탄착이 관측 개수를 줄이지 않도록 사거리 안의 `140 × deviceScale` 거리에 배치했다. 원래 컨트롤러 자체의 상향 반올림 재현도 검사에 보존했다.

관련 코어 검사 4개가 통과했다. 원작 유닛만 사용하는 phone/pad의 80개 스테이지를 각각 360틱 진행한 총 160개 시나리오에서 배우 상태·그림 명령·월드 시각·저장·사운드 추적 해시가 수정 전후 모두 같았다. 이 커밋의 웹 배포와 iPhone 빌드는 수행하지 않았다. 헬기 접근 경로 수정은 별도 작업이다.
