# AH-10 공용 텍스처

AH-10 몸체·로켓·공습 발사대의 독립 조립 노드는 그대로 두고, 세 그림을 한 CgBI 텍스처에 배치했다. 각 부품의 7자세·76×112 셀, 전체 여백, 연결점, 총구, 층 순서와 공용 렌더러를 보존했다. 원작의 PartsList·TileList가 그림과 시작 칸을 선택한다. 스카웃 강화 자원과 다른 기체는 바꾸지 않았다.

| 항목 | 이전 | 현재 |
|---|---:|---:|
| 해당 세 그림의 GPU 텍스처 공간 | 1.5 MiB | 1 MiB |
| 100기 고정 장면의 실제 텍스처 전환 | 1,152회 | 1,102회 |
| 같은 장면의 그리기 호출 | 1,352회 | 1,352회 |

512 KiB와 텍스처 전환 50회가 줄었다. `bindTexture` 호출 자체는 그리기마다 발생해 1,352회로 같다. 이 세 그림 아틀라스의 GPU 처리 시간은 측정하지 않았다. 앞서 두 그림만 묶은 후보의 교대 계측은 차이 방향이 반복마다 바뀌었으므로 GPU 시간 개선 근거로 쓰지 않는다.

## 제작과 소비

[준비 도구](../../tools/prepare_ah10_parts.py)는 기존 승인 그림에서 세 부품을 분리한 뒤 [아틀라스 도구](../../tools/prepare_ah10_atlas.py)를 호출한다. [작성 명세](../../Art/Aircraft/runtime/assembly.json)는 몸체·로켓·공습에 각각 시작 칸 0·7·14와 21×1 격자를 기록한다. `prepare_aircraft_definitions.py`와 `optimize_aircraft_png.py`로 표·MCB·CgBI를 재생성한다. 분리 전후 그림과 미사용 독립 PNG도 보존했다.

[생성 기록](../../Art/Aircraft/parts-separation-20261109/ah10/atlas/manifest.json)은 세 영역의 실제 CgBI 해독 픽셀이 기존 독립 그림과 같음을 확인한다. [소비 감사](ah10-atlas-20261109/consumption.json)는 실제 MCB의 44기체와 PartsList·TileList를 읽는다. [보존 대조](ah10-atlas-20261109/preservation.json)는 원작·스카웃과 AH 외 표 행의 바이트 동일성을 확인한다.

## 검사 범위

[코어 결과](ah10-atlas-20261109/core-tests.txt)는 실제 조립·40레벨·7자세·총구·이동·회피를 검사한다. 폭을 항상 7칸으로 고정하던 기존 검사 가정을 셀 76×112와 실제 시작 칸 검증으로 바꿨다. 최초 검사 실패도 [기록](ah10-atlas-20261109/initial-fixed-grid-assumption.txt)에 남겼다.

앞서 격리한 `fe72d80` 후보에서 Chrome·WebKit [14자세](ah10-atlas-20261109/atlas3-pixel-comparison.json), [20개 공격 캡처](ah10-atlas-20261109/atlas3-combat-pixel-comparison.json)가 채택 full-canvas 판과 픽셀 단위로 같았다. 40레벨 전투도 두 브라우저에서 검사했다. 이번 `837ff38` 적용 아틀라스는 그 후보와 파일 해시가 같다. AH 조립·공용 코드가 같고 스카웃 후속 자원도 보존해 이 AH 비교를 재사용했다. 현재 모든 병렬 변경을 합친 새 웹 빌드 검사를 실행했다는 뜻은 아니다.

크롭 두 후보의 실패는 재적용하지 않았다. 기존 full-canvas 판에 기록한 분리 전 기준과의 작은 그림자 차이를 새로 해결했다고 보고하지 않는다. 강화 외형·표면 개선과 최종 4종 대량 전투 성능은 별도 작업이다.

## 통합 검사

샤이엔 강화·7발 발사 시각·표적 접근 수정을 포함한 작업 브랜치에 적용했다. 표와 작성명세는 두 변경의 항목을 함께 유지해 재생성했고, 셀 검사에는 샤이엔 장갑 폭과 AH-10 아틀라스 시작 칸을 모두 남겼다. [관련 코어 10개 통과](ah10-atlas-20261109/integrated-core.txt), [통합 파일 해시](ah10-atlas-20261109/integration.json). 통합 웹 시각·성능 검사는 이어서 진행한다.
