# 레이저포탑 생산 가격 대조 — 2026-11-07

사용자는 레이저포탑을 업그레이드해도 생산 가격이 오르지 않는다고 보고했다. 확보한 원본 3개 판본의 `MachBuild_Name.tble`을 직접 읽었다. 모두 Lv.1~5의 `Cost`가 200셀이다. 원본 테이블에는 생산 가격 증가분이 없다. 의도적으로 고정했는지, 해금하지 않은 유닛이라 조정을 마치지 않았는지는 테이블만으로 판단할 수 없다.

| 항목 | 원본 Lv.1 → Lv.5 | 복원판 Lv.6 → Lv.10 |
|---|---|---|
| 생산 가격 | 200 → 200셀 | 200 → 200셀 |
| 다음 단계 강화 비용 | 200·500·1,000·2,000크레딧, Lv.5는 상한 | Lv.5→6부터 4,000·8,000·16,000·32,000·64,000크레딧, Lv.10은 상한 |
| HP 테이블 값 | 1,500 → 3,500 | 4,000 → 6,000 |
| 탄당 피해 | 20 → 40 | 45 → 65 |
| 사거리 `ShtRng` | 220 → 240 | 245 → 265 |
| 연사 수 | 14·16·18·20·24 | 26·28·30·32·34 |
| 발사 간격 | 0.18 → 0.14초 | 0.135 → 0.115초 |
| 재장전 간격 | 2.3 → 1.9초 | 1.85 → 1.65초 |
| 생산 시간 | 전 레벨 12초(기본값) | 전 레벨 12초(기본값) |
| 발사음 | Lv.1~3 Plasma02, Lv.4~5 Plasma05 | 원작 Lv.5의 Plasma05 재사용 |

원본 3개 판본의 Lv.1~5 `WeaponInfo`·`MachList` 레이저 행은 현행 행의 모든 필드와 일치한다. 피해·HP·사거리·연사 수·발사 간격의 원작 증가분은 들어 있다. 표의 HP는 파일에 적힌 값이며 전투 중 최종 보정값을 새로 측정한 수치는 아니다.

## 현재 가격을 읽는 경로

- `Sources/Core/Simulation/Production.cpp`: `Cost`를 생산 가격, `UpgCost`를 강화 가격으로 읽는다. 생산 시 `Cost`만큼 셀을 차감한다.
- `Sources/Core/Simulation/WorldEconomy.cpp`: 보유 레벨의 생산 행을 선택한다.
- `Sources/Core/Session/GameSession.cpp`: 같은 행의 `cost`를 HUD의 `mineralCost`에 넣는다.
- `Sources/Core/Presentation/GameHUD.cpp`: `mineralCost`를 가격표에 그린다.
- `tools/plan_level10.py`: 추가 레벨 계산에서 LaserTurret의 생산 가격 증가분을 0으로 정했다. `tools/apply_level10.py`가 이 계산값을 Lv.6~10 행에 넣었다.

따라서 200셀 표시는 현행 테이블과 차감 경로에 맞는다. 원작에서 비활성화돼 있던 유닛을 해금하고 10레벨까지 확장하면서 생산 가격도 조정할지는 남은 과제다. 이번 조사에서는 가격·게임 코드·에셋을 변경하지 않았다.
