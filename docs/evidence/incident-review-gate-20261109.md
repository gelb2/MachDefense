# 경위서 읽기·재대조 검사 적용

2026-11-09. [작업 절차](../incident-review-policy.md)에 작업 전 원문 읽기·적용 항목 기록과 작업 후 재읽기·변경/검사 근거 대조를 연결했다. pre-commit의 첫 검사이며 누락은 종료 코드 1로 실패한다.

격리 Git 저장소의 [17개 회귀 검사](incident-review-gate-20261109/tests.txt)가 통과했다. 읽기 없음, 수정 후 뒤늦은 읽기, 적용 항목 미기록, 재읽기 없음, 재대조 없음, 검증 뒤 stage/작업 파일 변경, 경위서 변경, 그래픽 작업의 사전 읽기 누락, 미해결 항목, 근거 파일 부재·변경, 다음 커밋에 이전 기록 재사용을 검사했다. 필요한 기록과 근거가 있는 정상 경로, 그래픽 경로, 파일 변경 없는 업무지시 분석도 검사했다.

작업 후 원문을 수정하거나 경위서 목록을 갱신했다면 최종 버전을 다시 읽고 대조해야 한다. Git 기록은 worktree별로 분리한다. 이 도구는 읽기·적용·재대조 기록과 파일 일치를 검사하며, 실제 이해나 검사 근거의 진실성을 자동으로 보증하지 않는다. 각 작업자는 원문을 직접 읽고 실제 결과를 대조해야 한다.

[보존 확인](incident-review-gate-20261109/preservation.json): 게임 Sources·Resources·Art 변경 0개. 자동 인계·대화 전환·원작 게임 실행 경로는 추가하지 않았다.
