# 샤이엔·벨루가 체력과 가격 조정

2026-11-10. 기존 Lv.7 체력은 샤이엔 3,410, 벨루가 6,384였다. 사용자 지정 기준을 Lv.1–10 각각에 적용하고 구매·강화 가격을 함께 낮췄다. 다른 헬기 개선 과제는 계속 보류한다.

강화 비용은 해당 레벨에서 다음 레벨로 올리는 비용이며 Lv.10은 종료다. Lv.1→10 강화 총액은 샤이엔 229,920크레딧, 벨루가 344,910크레딧이다.

## 실제 소비 경로와 보존

샤이엔은 `Orca_01`–`Orca_10`과 `AircraftDuct_01`–`AircraftDuct_10`, 벨루가는 `OrcaBomber_01`–`OrcaBomber_10`과 `AircraftTransport_01`–`AircraftTransport_10`을 쓴다. `MachBuild_Name.tsv`의 두 기체 20행에서 Cost·UpgCost만, `MachList.tsv`의 두 기체 20행에서 HP만 수정했다. 다른 행은 줄바꿈까지 같다.

기존 BuildCatalog·ProductionQueue·Settlement·MachineDefinition과 공통 GameSession이 변경한 표를 읽는다. 실제 게임 소스, 원작 유닛 행·에셋, 스카웃·AH-10 수치, 무장·사거리·이동·회피·저장 형식은 변경하지 않았다. 플랫폼별 별도 수치나 실행 중 보정 코드를 추가하지 않았다.

## 확인 결과

- 변경 전 체력 검사가 실패하는 것을 확인한 뒤 표를 적용했다. `AircraftBalance`, `Production`, `Economy`, `Settlement` 4개 검사가 통과했다. phone/pad의 두 기체 20레벨, 원본 체력 로더, 셀 지출·잔액, 자금 부족 시 생산·강화 차단, 정확한 강화 차감과 최대 레벨을 확인했다.
- 웹 치트빌드의 Chromium·WebKit에서 실제 월드에 두 기체를 각 레벨로 생성했다. 20개 HP, 웹 실행 자원의 구매·강화 가격이 표와 일치했다.
- 두 브라우저에서 강화창으로 Lv.1→10을 각각 올렸다. 총 18회 유효 강화의 차감액과 대상 레벨을 확인했고, 다른 소유 유닛은 같았다. Lv.10 이후에는 추가 차감이 없었다. Lv.1·7·10 화면을 남겼다.
- Lv.7 실제 강화창에는 샤이엔 DEF 1,700·강화 28,800, 벨루가 DEF 3,800·강화 43,200이 표시됐다. 유휴 프레임 중 저장 쓰기와 두 브라우저의 페이지 오류는 0이었다.
- 일반 웹 빌드 ID는 `f9f26e94f1d4e3d6`이며 치트 기능이 꺼져 있다.

코어 검사는 `Tests/AircraftBalanceTests.cpp`, 웹 검사는 `Web/tests/aircraft-hp-price.mjs`다. 원시 표 변경 대조·검사·캡처는 로컬 `.local/aircraft-hp-price-hotfix-20261110/`에 보존한다. 운영 게시와 iPhone 정식 설치 결과는 실제 실행 후 기록하며 이 문서의 검사 통과로 대신하지 않는다.
