# Tauri Mac 구현과 검사

2026-11-07. `Desktop/Tauri`에 별도 Mac 실행기를 만들었다. 기존 웹 일반판의 JS·Wasm·data·그림·음향을 해시로 확인한 뒤 앱에 포함한다. Apple·Android의 게임 실행기와 공용 전투 소스는 변경하지 않았다. 이번 작업의 공용 게임 자원 변경은 별도 승인된 레이저 생산 가격 표다.

## 구현

- Tauri 2.12.5, Rust, WKWebView. macOS 14 이상 Apple Silicon 대상.
- 게임의 메뉴·HUD·복원 버튼은 기존 C++ Frame과 WebGL2 렌더러가 그린다. 텍스트 입력은 기존 웹 연결을 사용한다.
- 진행은 앱 데이터 폴더의 파일에 저장한다. 42,496바이트 저장, SHA-256, 순번을 검사한다. 임시 파일 쓰기·동기화·교체·읽기 검증을 수행하고 이전 저장과 복원 전 저장을 보존한다.
- 실패한 저장은 재시도할 수 있다. 닫기 처리는 미완료 저장을 기다린다. 다른 앱 인스턴스를 열면 기존 창을 앞으로 가져온다.
- 시작 화면에서만 업데이트를 제안한다. 공식 updater가 서명된 앱 전체를 검증해 교체한다. 서명 속 버전도 대조한다. PWA는 변경 자원 조각을 받지만 Tauri는 전체 앱 패키지를 받는다.
- 서명 개인키는 저장소 밖에 둔다. 일반 소스 빌드에는 개인키가 필요 없다. 앱은 ad-hoc 서명이며 Developer ID 공증은 하지 않았다.

## 실행한 검사

| 검사 | 결과 |
|---|---|
| Rust 파일 저장 | 저장·재실행·백업·오래된 쓰기 거절·손상 보존·중단된 임시 파일 3개 검사 통과 |
| JS 저장 연결 | 실패 후 재시도·쓰기 순서·닫기 대기·닫기 실패 후 재시도 통과 |
| 실제 WKWebView | 새 프로필·재실행·미션 진입·음향 호출·비활성/활성·저장 후 종료 통과 |
| 실제 iPhone 저장 백업 | Stage 46·31,297Cr·보유 장비 13종의 저장을 코드로 복원. 코드 재출력 일치와 미션 진입 확인 |
| 10레벨 합성 저장 | 별도 5슬롯 시험 자료의 복원·재출력·미션 진입 확인. 실제 사용자 저장과 구분 |
| 공식 updater | 정상 서명 통과. 손상·절반만 받은 패키지 거절. 서명 버전과 안내 버전 불일치 거절. 다운그레이드 무시 |
| 앱 교체 | 시험용 앱 사본에 공식 updater 설치 실행. 설치 후 실행 파일 바이트 일치, 번들 밖 저장 표식 보존 |
| 공용 게임 | CTest 42/42 통과. 같은 입력에서 게임 구현 변경 없이 검사 |

실기기와 웹 결과는 `.local/release-v06/`, WKWebView 세부 기록은 `.local/followup-audit/tauri-*.json`에 있다. 사용자 저장과 복원 코드는 Git에 넣지 않는다. 자동 검사에는 별도 validation 저장 폴더를 사용했다.

## 남은 확인

직접 GUI에서 Desktop QA 프로필을 만들고 Cmd-Q로 종료했다. 다시 열어 같은 프로필이 남은 것을 확인하고 메뉴의 Quit MachDefense Desktop으로도 종료했다. 두 경우 모두 프로세스 종료를 확인했다. 창 닫기, 공개 Release에서 실제 업데이트 다운로드·재실행, 디스크 부족과 새 실행 파일의 시작 실패 검사는 남았다.

## 앱 번들 서명 검사

최종 포장 검사에서 실행 파일의 링커 서명만 있고 앱의 자원 서명이 빠진 것을 확인했다. `bundle.macOS.signingIdentity`를 `-`로 지정해 앱 전체를 ad-hoc 서명하도록 수정했다. 다시 만든 앱에 `codesign --verify --deep --strict`를 적용했다. 업데이트 패키지용 서명과 macOS 앱 서명은 별도로 검사한다. Developer ID 공증은 하지 않았다. [Tauri의 ad-hoc 서명 안내](https://v2.tauri.app/distribute/sign/macos/#ad-hoc-signing).
