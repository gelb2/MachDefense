# v0.6 배포 결과

2026-11-07. 작업 브랜치 → develop `8bab8ad` → main `2f82a09` 순서로 병합했다. main에 v0.6 태그를 붙였고 [Release](https://github.com/gelb2/MachDefense/releases/tag/v0.6)에 Android 정식·치트 APK, Tauri Mac ZIP·업데이트 패키지·서명·해시 목록을 올렸다.

[운영 웹·PWA](https://gelb2.github.io/MachDefense/) 빌드는 `87ea3cfe8a8dc249`, gh-pages 커밋은 `c539cde43f4bd9411efef2327601b37a6a7355e5`다. 저장소 검사와 Pages 배포가 성공했다.

## 운영 검사

- 배포 전 운영 v0.5 `2ef4e04fca811fca`를 설치한 시험 브라우저에 진행을 저장했다. 배포 후 v0.6으로 바뀐 것을 확인했고 저장 SHA, 실행 중 테이블 네 개, 오프라인 재실행과 이전 자원 캐시 보존이 통과했다.
- 새 Chrome·WebKit 환경에서도 코드 입력 취소, 정상 복원 바이트 일치, 코드 재출력, 잘못된 코드 거절, 미션 진입, 생명주기, 그래픽 복구, 오프라인 재실행, 오래된 쓰기·저장 실패 후 보존 검사를 통과했다. 두 환경 모두 페이지 예외는 없었다.
- Release에서 Mac ZIP을 다시 내려받았다. 로컬 배포 파일과 SHA-256이 같았고, 압축을 푼 앱의 `codesign --verify --deep --strict`가 통과했다.
- 공개 Release의 업데이트 패키지와 서명도 다시 받았다. 서명·버전 대조, 손상·잘린 파일 거절, 시험 앱 교체와 번들 밖 저장 보존이 통과했다.
- iPhone·iPad의 정식·치트 네 앱은 설치와 실행·종료에 성공했다. 설치 전후 저장 바이트가 모두 같았다. Galaxy 정식·치트 앱 설치와 기능 검사는 [실기기 기록](native-release-20261107.md)에 있다.

운영 검사 중 최초 다운로드 대기가 30초에 끝나 실패한 검사는 테스트의 옵션 위치가 잘못돼 있었다. `waitForFunction`의 두 번째 인자가 아니라 세 번째 인자로 제한 시간을 전달하도록 고친 뒤 Chrome·WebKit을 다시 실행했다. Chrome의 검사 프로세스 종료가 5초를 넘겨 해당 시험 프로세스만 종료한 기록이 있다. 게임 검사 항목과 브라우저 종료를 구분했다.

## 변경 범위

게임의 전투·이동·피해·저장 코덱 구현은 변경하지 않았다. 승인된 레이저 생산 가격 표와 Apple·Android 버전 값, 웹 실행·갱신 연결과 별도 Desktop/Tauri 실행기를 변경했다. 원본 IPA와 사용자 저장은 Git·Release·Pages에 넣지 않았다. Git 훅에서 4,567개 blob의 원본 패키지·실행 파일 검사를 통과했고 gitleaks도 통과했다.

## 남은 일

타이틀 확장 그림은 원본과 맞지 않아 제품에 넣지 않았다. 원본 iPad의 시야·투영 대조, 비정상 로컬 저장 보정, Tauri 창 닫기와 실제 업데이트 후 자동 재실행 검사는 남았다. 공중유닛은 [연구와 시안](../research/aircraft-plan-20261107.md)까지이며 게임에 추가하지 않았다.
