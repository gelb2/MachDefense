# 강화·무장 전체 단계와 기기 검사 — 2026-11-04

## 시뮬레이터 기능 검사

실제 GameSession 버튼으로 기지·유닛·특수기술의 전체 단계 구매를 실행했다. 원본 표 191개 행에서 구매 166건, 자금 부족·최대 단계 거부 216건, 디스크 저장 후 새 GameSession에서 재읽기 191건이 통과했다. 검사 본문은 56.462초였다. 기지 체력과 기관총의 강화 반영도 확인했다.

무장 정의 211개를 phone/pad 좌표 조건에서 각각 실행했다. 422개 조건에서 발사 3,688건과 충돌·직접 피해 경로 3,688건을 확인했다. 연속 발사 수, 사거리 밖·표적 없음·공격 불가 상태의 발사 차단, 투사체 종료, 실제 World의 발사·GPU 그리기·효과음 경로가 통과했다. 검사 본문은 25.645초였다.

무장 검사는 시험 기지의 무장을 순서대로 교체해 같은 조건에서 발사한다. 기체마다 다른 포구 위치·부품 연결까지 전부 비교하는 검사는 별도로 남아 있다. 투사체 충돌 검사는 의도된 분산과 분리해 표적 중심에서 피해 처리를 확인한다.

증거: `.local/full-sweep-r2.log`, `.local/full-sweep-r2.xcresult`. 초기 테스트 코드의 span 인수 컴파일 오류는 vector로 수정했다. `.local/full-sweep-r1.log`도 보존했다.

## 아이패드 검사 연결

기기에서는 XCTest에 실행 앱이 필요해 기존 MachDefenseCheat를 호스트로 연결했다. 테스트 중에는 호스트의 일반 게임 화면을 초기화하지 않는다. 각 XCTest가 별도 게임 객체·렌더러·오디오·임시 저장을 만든다. 이로써 OpenAL 장치를 두 번 초기화하는 충돌을 제거한다. 일반 실행과 정식 앱은 기존 경로를 사용한다.

CLI 서명은 errSecInternalComponent로 실패했고 기존 절차대로 Xcode GUI에서 빌드했다. 호환 포팅 앱과 저장은 변경하지 않았다.

## 앱 아이콘

`Resources/Images/iPad_Title_Main.png`의 전투 일러스트를 바탕으로 정사각형 아이콘을 만들었다. ImageGen으로 구도를 조정하고 제목 글자를 제외했다. 원본 픽셀을 그대로 자른 파일은 아니다. 게임 안의 원본 타이틀 에셋은 유지했다.

사용 파일은 `Apple/iOS/Assets.xcassets/AppIcon.appiconset/AppIcon.png`다. 정식·치트 앱이 같은 아이콘을 사용하고 앱 이름으로 구분한다. Xcode 자원 빌드와 project.yml 양쪽에 연결했다.

## 기기 설치

새 아이콘을 포함한 정식 앱은 iPhone·iPad에, 치트 앱은 iPad에 설치했다. iPhone 치트 앱은 무료 개발 서명의 3개 앱 제한으로 설치를 보류했다. iPad의 HeavyMach 치트 앱은 사용자 승인에 따라 저장·설정을 백업한 뒤 삭제했고 HeavyMach 정식은 유지했다. iPhone 포팅판은 삭제하지 않았다.

정식 앱 피드백으로 뒤이어 발견한 안내·음향·로딩·복귀 문제는 [후속 수정 기록](source-ui-audio-lifecycle-20261104.md)에 있다. 위 16개 검사 통과를 원작의 모든 연출이 일치한다는 뜻으로 사용하지 않는다.
