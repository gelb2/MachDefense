# 타이틀 바깥 그림 수정과 화면 검사

2026-11-06 사용자 검수: 1280×800 가로창 후보는 메크·탱크 왜곡으로 기각됐다. 해당 Wide.png를 채택하거나 다음 앱·운영 배포에 포함하지 않는다. 원본 기체의 형태·부품·비율을 보존하는 외곽으로 다시 작업한다. 다른 비율 시안도 승인된 것으로 취급하지 않는다.

기존 타이틀은 좌우 1픽셀을 넓게 늘리고 위아래 그림을 뒤집어 채웠다. 폭이 넓어질수록 같은 색 줄이 늘어졌고, 세로 화면에서는 구름과 바위가 반복됐다. HeavyMach1의 `menu-art-extension-20261025.md`와 `menu-joins-20261025.md`에서 원본 중앙과 새 외곽 그림을 분리한 방법을 확인했다.

## 수정

- 원본 `Title.jpg` 파일과 중앙 320×480 배치를 유지한다. 반전·가로 늘이기를 중앙 그림에 적용하지 않는다.
- 가로·세로 후보를 각각 만들었다. 게임에서는 후보의 좌우 또는 상하 외곽만 사용한다. 생성 이미지 중앙의 글자와 기체는 출력하지 않는다.
- 좁은 여백은 새 그림을 잘라서 채운다. 가장자리 8 논리 픽셀에 원본 경계색을 투명하게 겹친다. 큰 영역에 원본의 한 줄을 늘리던 처리는 제거했다.
- 원본 텍스처의 반 픽셀 안쪽을 샘플링해 투명 패딩이 경계로 섞이는 것을 막았다. 원본 파일의 SHA는 유지한다.
- 타이틀 프레임을 다시 만들 때 메시도 비운다. 슬롯 화면으로 넘어가면 확장 그림과 메시가 남지 않는다.
- 생산 HUD·월드·카메라·입력 좌표·전투·저장·오디오 계산은 바꾸지 않았다. 슬롯·미션 메뉴의 기존 금속판 확장은 유지했다.

소비 코드: [TitleBackdrop](../../Sources/Core/Presentation/TitleBackdrop.hpp), [Menu](../../Sources/Core/Presentation/Menu.cpp). 자원 출처·크기·해시는 [명세](../../Resources/Generated/Title/provenance.json)에 있다.

## 실행 검사

C++의 Menu·GameSession·SaveFailure·TransferMenu 4개 검사가 통과했다. Menu 검사에는 전체 화면 채움, 원본 그림 1개와 비율, 자원 크롭 경계, 반복 갱신 때 메시 개수, 슬롯 진입 후 메시 제거, 추가 저장 없음 조건을 넣었다.

Chrome·WebKit 각각 다음 다섯 화면에서 치트 웹판을 실행했다. 원본 그림은 논리 좌표 320×480 하나이며, 타이틀 터치 후 슬롯 화면 진입과 저장 쓰기 0회를 확인했다. 페이지 오류도 0개였다.

| 조건 | 브라우저 창 크기 |
|---|---|
| 원본 비율 | 320×480 |
| iPhone 비율 | 390×844 |
| iPad 비율 | 820×1180 |
| 데스크톱 | 1280×800 |
| 넓은 데스크톱 | 1600×900 |

재실행: `node Web/tests/title-layout.mjs <로컬 치트 주소> <결과 폴더>`. WebKit은 `MD_BROWSER=webkit`을 앞에 붙인다. 원본 로그와 전체 크기 캡처는 `.local/title-audit/selected-chromium` 및 `selected-webkit`에 있다. 브라우저 창 비율 검사이며 실제 iPhone·iPad 설치 검사는 이번에 추가하지 않았다.

## 그림 검수

정사각 후보는 여백에서 기체가 겹쳐 보여 제외했다. 첫 가로 후보의 추가 포신과 첫 세로 후보의 하단 회색 띠도 다시 생성했다. 현재 후보는 보고서에서 실제 게임 렌더로 비교할 수 있다.

원본과 새 그림의 색·붓질이 만나는 부분은 여전히 눈으로 검토할 대상이다. 특히 넓은 가로 화면의 기체 후방과 세로 화면 하단을 확인한다.
