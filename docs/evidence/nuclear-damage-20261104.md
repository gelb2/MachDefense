# 핵폭탄 피해 검사 — 2026-11-04

사용자가 특수기술 핵폭탄의 피해 계산을 재확인하도록 지시했다. 원본 무기 표·피해 함수와 새 코드를 대조하고, Mac 코어 검사와 실제 iPad 치트 앱 안에서 같은 검사를 실행했다. 검사한 조건에서 계산 오류는 발견하지 않았다. 제품 피해량은 변경하지 않았다.

## 원본 계산

기준은 WeMade 1.0.3 ARMv7이다. `GobBullet::setCollide`(0xa568)의 범위 피해 분기는 진영 목록에서 살아 있는 대상의 중심과 폭발 지점 사이 거리를 사용한다. 새 `Projectile.cpp`와 비교했다.

- 거리 d가 범위 R 이상이면 피해 0.
- 범위 안에서는 `정수 절삭(D × min(1, 1.5 − d/R))`.
- 중심부터 반경 절반까지 기본 피해 전부, 반경 75% 지점에서 75% 피해.
- 아군이 사용한 핵폭탄은 적 목록에 적용한다. 적 기지도 같은 목록에 포함된다.
- 핵폭탄 자체의 별도 지속 피해나 방어력 감산은 없다.

| 레벨 | 기본 피해 D | phone 좌표 반경 | pad 좌표 반경 |
| --- | ---: | ---: | ---: |
| 1 | 1500 | 150 | 300 |
| 2 | 2000 | 160 | 320 |
| 3 | 2700 | 180 | 360 |
| 4 | 3700 | 200 | 400 |
| 5 | 5000 | 225 | 450 |

원본 `GlobalInfo::openWeaponInfo`의 phone 배율은 범위·속도에 적용하며 피해량에는 적용하지 않는다. 현재 유니버셜 앱은 iPad에서도 phone 논리 좌표를 사용한다. 표의 pad는 원본 pad 좌표 설정을 넣어 검사한 값이다.

첫 미션 적 기지 체력은 40,000이다. 1레벨 중심 명중 피해 1,500은 그 체력의 3.75%다. 체력바가 조금 줄어드는 모습만으로 피해 누락을 판정할 수는 없다.

## 실행한 검사

`Tests/NuclearDamageSweep.hpp`를 Mac의 WorldSpecialTests와 iPad XCTest에서 함께 사용한다.

- 5레벨 × 좌표 설정 2종 × 거리 7개(0·25·50·75·99·100·101%) = 범위 70조건.
- 실제 `activateSpecial` → 공습기 이동 → 투하 → 탄환 충돌 → 체력 차감 경로 10회.
- 매 공습에서 적 기지·지상 차량·공중 기체·아군 차량의 체력을 충돌 전후로 비교했다. 다른 무기의 피해가 섞이지 않도록 시험 월드에서 다른 무장만 비웠다.
- 적 기지·지상·공중의 중심부 피해는 각 레벨에서 1500/2000/2700/3700/5000, 아군 피해는 0이었다.
- 특수기술 재고는 2→1, 저장 파일 쓰기는 0회였다. 기존 사용자 저장은 사용하지 않았다.

Mac 검사 통과: `.local/nuclear-damage-core.log`.

iPad Air 13-inch M2 / iPadOS 27.0.1의 `testNuclearDamageAllLevels` 통과: 0.166초. 설치·검사 도구 실행 전체는 16.725초. 결과와 수치 첨부는 `.local/nuclear-damage-ipad-r2.xcresult`, 로그는 `.local/nuclear-damage-ipad-r2.log`에 있다.

원본 함수와 표를 대조한 검사다. 포팅판의 실행 메모리에서 같은 체력 값을 직접 읽어 맞대조한 검사는 이번에 수행하지 않았다.
