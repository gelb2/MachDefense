# 원고 로컬 편집기 — 2026-11-10

사용자 지시는 사이트에서 수정 → 채팅으로 수정 통보 → 기존 커밋·푸시·작업 브랜치→develop→main 병합이다. 사용자가 서버 저장을 거부한 뒤 서버·D1·MCP 구현을 게시 대상에서 제외했다. 서버 시안은 로컬 미게시 자료로 남았다. 실제 게시물은 기존 정적 보고 사이트와 로컬 편집기다.

- 원고·글감의 한국어·영어 네 문서를 편집한다. 저장 버튼은 브라우저 IndexedDB와 내려받는 JSON 수정본 파일만 사용한다. 기존 접근은 소유자 전용으로 유지한다.
- Chrome·WebKit 390·1280px 네 화면에서 원문 다운로드 일치, 새로고침 후 복원, 이전 버전 복구, 저장 실패 시 입력 보존, 같은 브라우저 두 창의 충돌, 새 브라우저 보관함에서 수정본 파일 열기를 확인했다.
- 페이지 요청을 수집해 편집·저장 과정의 서버 쓰기 0건·외부 전송 0건을 확인했다. HTML CSP도 연결을 차단한다. 게시물의 hosting manifest는 static만 유지하며 D1·R2·MCP를 추가하지 않았다.
- 내려받은 실제 검사 파일을 importer의 적용 없는 모드로 읽어 본문·SHA·경로·기준 해시를 확인했다. 사용자 원고에는 검사 문장을 적용하지 않았다. 임시 저장소의 importer 회귀 4개는 정확한 본문·재시도·후속 버전, 외부 수정 보존, 경로·저장소·해시·번호 거절, 심볼릭 링크 거절을 검사해 통과했다.
- 기존 네 보고서의 article 본문은 그대로다. 게임 소스·자원·앱과 원고 본문은 이번 기능에서 바꾸지 않았다. 실제 GitHub 반영은 사용자의 수정 통보 뒤 별도 진행한다.
