# v0.5 배포 검사

2026-11-07. 추가 포탑의 Lv.6–10 무기는 각 원작 Lv.5 PNG와 같은 바이트를 사용하고 몸체 5단계만 채택 시안으로 교체했다. 레이저 포탑 해금과 이온·플라즈마 피해 성장도 이번 릴리스에 포함한다.

## 빌드와 보존

- Apple·Android 내부 버전 0.5, build 5.
- 정식 웹 빌드 `701b376ebb23a762`.
- iPhone·iPad 일반/치트 저장을 설치 전에 백업했다. iPhone 정식 저장은 마지막 프로필 선택 시각(0x40c)과 체크섬만 달랐다. 두 필드 외의 모든 바이트와 진행·자금·장비는 일치했다. 오래된 저장으로 덮어쓰지 않았다.

- iPad 실기기 XCTest 후 Clean Build Folder와 치트 스킴 빌드로 테스트 플러그인이 없는 앱을 다시 설치했다.

## Galaxy USB·무선 연결

USB 기본값을 `svc usb setScreenUnlockedFunctions mtp`로 설정했다. `dumpsys usb`에서 `screen_unlocked_functions=MTP`, `current_functions=MTP`, `current_functions_applied=true`를 확인했다. 실제 케이블 재연결 뒤 유지 여부는 아직 확인하지 않았다.

무선 디버깅은 켜져 있고 기기의 연결 포트도 열려 있다. Mac과 Galaxy는 같은 Wi-Fi 이름을 표시한다. 그러나 Mac의 `adb connect`와 TCP 연결은 `No route to host`로 실패한다. ADB 서버를 다시 시작해도 같았다. 무선 설치·실행은 미완료다. USB 연결과 디버깅은 동작한다.
