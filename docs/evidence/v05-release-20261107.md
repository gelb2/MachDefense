# v0.5 배포 검사

2026-11-07. 추가 포탑의 Lv.6–10 무기는 각 원작 Lv.5 PNG와 같은 바이트를 사용하고 몸체 5단계만 채택 시안으로 교체했다. 레이저 포탑 해금과 이온·플라즈마 피해 성장도 이번 릴리스에 포함한다.

## 빌드와 보존

- Apple·Android 내부 버전 0.5, build 5.
- 정식 웹 빌드 `701b376ebb23a762`.
- iPhone·iPad 일반/치트 저장을 설치 전에 백업했다. iPhone 정식 저장은 마지막 프로필 선택 시각(0x40c)과 체크섬만 달랐다. 두 필드 외의 모든 바이트와 진행·자금·장비는 일치했다. 오래된 저장으로 덮어쓰지 않았다.
- Galaxy 일반/치트 설치 전후 저장 바이트가 일치했다. 치트 검사 후에는 검사 전 치트 저장을 복원했다.
- iPad 실기기 XCTest 후 Clean Build Folder와 치트 스킴 빌드로 테스트 플러그인이 없는 앱을 다시 설치했다.

## 확인 결과

- 공용 C++ art/save-transfer/session/level10 검사 4개 통과.
- Chrome·WebKit 각각 144자세: 몸체·무기 위치와 길이·프레임 경계 대조.
- 웹 치트의 생산 280·배치 120·특수공격 100조건, HUD·강화·복원 130행 통과.
- iPad 실기기: 두 XCTest 통과. 포탑 조립 144자세와 레벨/HUD 130행, 구매 117건, 거절 143건, 저장·복원 130건, 화면 523건을 검사했다.
- Galaxy 정식·치트 설치. 치트에서 생산·일시정지·기지/유닛 강화창·오디오 포커스 5회·EGL 재생성·백그라운드 3회·긴급지원·승리·다음 미션·패배·재시작을 통과했다.
- Galaxy 자동 검사의 기존 4초 생산 대기는 강화된 유닛의 생산 시간보다 짧았다. 게임 수치는 그대로 두고 검사에서 실제 생산 수가 늘어날 때까지 최대 게임 시간 30초를 진행하도록 수정했다.
- 로컬 정식 Chrome·WebKit: 코드 복원, 취소·잘못된 코드 보존, 미션 진입, 오프라인 재실행, 이전 창의 저장 거절 검사 통과.

- iPhone 정식 앱에서 기존 프로필 표시·미션 47 진입·일시정지·재개·앱 종료 후 홈 복귀를 확인했다.
- Apple 일반/치트와 Android 일반/치트 패키지 4개에서 강화 그림 44개의 SHA-256이 채택 매니페스트와 일치했다.
