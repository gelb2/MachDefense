# iPhone·iPad 화면 확장 — 2026-11-05

## 변경

320×480 고정 프레임을 디바이스 비율과 안전 영역에 맞춘 논리 캔버스로 변경했다. 유닛과 전투 좌표의 크기는 유지한다. iPhone은 원래 맵의 세로 영역을 더 표시한다. HUD의 오른쪽·하단 버튼과 터치 판정을 같은 거리만큼 이동한다. 중앙 창도 그림과 입력을 함께 옮긴다.

원본 phone 맵은 폭 256, 높이 1024다. iPad 배경은 같은 내용을 큰 이미지로 제공하며 추가 지형이 아니다. 맵 폭·충돌·길찾기를 늘리지 않았다. iPad에서 오른쪽 메뉴 이동으로 드러나는 맵 밖은 원본 GameUI_MachSlot의 금속 부분으로 채운다. 하단 버튼 하우징 사이도 원본 금속 부분을 사용한다.

전투 화면을 먼저 설치했지만 타이틀·슬롯·미션 선택은 320×480 상태로 남아 있었다. 사용자가 iPhone 상하 여백을 다시 지적했다. 메뉴 배경의 머리·몸통·바닥을 나누어 배치하고 하단 버튼을 아래쪽 안전 영역 위로 옮겼다. 타이틀 그림 전체와 로고는 유지하며 남는 영역에 원본 가장자리의 구름·불꽃 부분을 반사해 표시한다. 별도 이미지를 그리거나 게임 버튼을 UIKit으로 만들지 않았다. 이름 입력은 기존 OS 입력창을 사용한다.

문 전환과 로딩 일러스트는 캔버스 전체를 덮는다. 그림·게임 수치·원본 맵 파일은 변경하지 않았다.

## iPad 회색 영역 — 사용자 지적 후 재검토

회색 영역은 원본 맵 데이터가 아니다. 이번에 GameHUD::append에 추가한 `x=250`부터 화면 오른쪽 끝까지의 금속 타일 채우기에서 생겼다. `GameUI_MachSlot.png`의 `(144,896)` 부분을 반복한다. World의 원본 배경은 x=0..256에 그대로 남고, HUD만 `layout.width-320`만큼 이동한다.

1024×1366, 상하 안전 영역 24/20 조건에서 논리 폭은 371.80이다. 맵 오른쪽은 256, 이동한 생산 HUD의 불투명 부분 시작은 307.80이다. 약 51.80 논리 단위의 간격을 회색으로 덮었다. 추가로 x=250에서 시작해 원래 맵 오른쪽 6단위도 가린다. 이 처리는 사용자가 요구한 월드 표시 확장을 충족하지 못하므로 화면 대응 완료로 판정하지 않는다.

원본 배경 파일 27쌍의 크기는 phone 256×512, pad 512×1024다. 파일 크기만 두 배인 것을 맵의 사용 가능한 폭이 두 배라는 증거로 쓰지 않는다. 다음은 iPad 원본의 카메라·배경·HUD 배율과 재개발판을 대조하고, 화면 투영 변경과 실제 지형 범위 변경을 구별해 수정안을 만든다. iPhone 정식 앱은 현재 설치본을 유지하고 후속 실기기 검사는 아이패드로 제한한다.
