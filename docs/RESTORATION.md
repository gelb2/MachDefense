# 개발자의 변

## 다시 실행하고 싶었던 게임

나는 캐나다와 미국 앱스토어 계정으로 MachDefense를 구매해 플레이했다. 내가 기억하는 게임은 유닛 이름까지 모두 영어였다. 복원 중 생산 아이콘에 한글 이름이 보였을 때, 원본의 다른 판본과 언어 처리부터 확인하도록 했다.

HeavyMach 1을 복원한 뒤 MachDefense도 같은 절차로 다시 만들기로 했다. 원본을 실행하는 포팅판을 먼저 만들고, 내 아이폰에서 생산과 교전, 미션 클리어와 실패를 확인했다. 그다음 소스코드부터 새로 구현한 앱을 포팅판과 비교했다.

## 내가 확인한 것

새로 만든 앱에서는 포팅판에서 보이던 가격과 선택 효과가 빠지기도 했고, 생산 아이콘이 다른 방향을 보이기도 했다. 기지 기관총을 쏠 때 프레임이 떨어졌고, 앱을 나갔다 돌아오면 효과음이 들리지 않는 경우도 있었다. 나는 직접 플레이하며 차이를 지적하고, 원작의 동작과 구현 절차를 다시 확인하도록 했다.

게임 안의 버튼은 원작자가 쓰던 에셋과 입력 방식으로 만들어야 한다고 지시했다. 기능이 같아 보여도 버튼을 플랫폼마다 다른 UI로 만들면, 다른 기기로 옮길 때 같은 일을 다시 해야 하기 때문이다.

모듈화에서도 같은 기준을 적용했다. 게임의 피해 계산·이동·생산·성장·저장을 공통 코드로 나누고, Android를 추가할 때는 이미 동작하는 iPhone·iPad 쪽 파일을 바꾸지 않도록 했다. 새 플랫폼을 만드는 일이 기존 플랫폼을 망가뜨려서는 안 된다.

## 원작 위에 더한 것

긴급지원은 내가 추가한 기능이다. 한 번 받고 끝나는 보상 대신 전투 시간에 따라 소량의 크레딧과 셀을 반복해서 받도록 했다. 현재의 자금난을 덜어 주되 게임을 지나치게 쉽게 만들지 않도록, 자원 용량과 연구 수치에 맞춰 지급량을 계산하게 했다.

이 기능에도 원작의 자금 버튼과 창·글꼴을 사용했다. 광고나 인앱결제는 넣지 않는다. 게임에 들어가는 텍스트는 영어로 맞춘다.

## 불씨를 다시 지피는 일

게임을 만들었던 사람들의 그림과 소리, 유닛을 조립하고 움직이게 한 방법이 이 복원의 기준이었다. 나는 그것들이 지금의 기기에서도 동작하도록 복원을 지시하고, 직접 플레이하며 결과를 확인했다.

나는 무명이나, 예술가들은 불멸이다. 나는 그저 불씨를 다시 지폈을 뿐이다.
