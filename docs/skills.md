# 스킬과 출처

HeavyMach 1 프로젝트 스킬 11개 전체를 `reference/heavymach1/skills`에 원문으로 보존했다. 현재 적용본은 `.agents/skills`에 있다. 원본 사본의 과거 앱 이름·주소·완료 기록은 실행 지시가 아니다.

| HeavyMach 1 | MachDefense 적용본 |
|---|---|
| engineering-browser/debug/test/review | 같은 이름, 공통 절차 유지 |
| write-project-text | 같은 이름, 원문·번역 규칙과 참고 문서 보존 |
| apple-wireless-device | 같은 이름, 앱 ID·타깃은 새 프로젝트에서 확인 |
| port-heavymach-android | port-machdefense-android |
| debug-heavymach-android | debug-machdefense-android |
| game-keyboard-input | 같은 이름, 원작 조작부터 매핑 |
| integrate-game-art | 같은 이름, 원작 파츠와 채택 에셋 대조 |
| present-game-artifacts | 같은 이름, 보고 위치와 비공개 범위 확인 |
| 전역 reverse-engineer-anything | 로컬에 스킬·references 전체 복사 |
| 후속작 복원 절차 | restore-machdefense로 진입 |

[출처와 SHA](skill-source-manifest.json)에 복사본 해시를 기록했다. REA는 당시 사용한 v42 스킬이다. 원본 분석 기록은 reference/heavymach1/policies/public/rea-restoration-method-20261025.md에 있다. 스킬만으로 서버와 분석 엔진이 설치되거나 연결되지는 않는다.

imagegen, Sites, repair-computer-use는 환경 제공 스킬이다. 필요한 시점에 세션의 현행 위치와 사용 가능한 도구를 확인한다. 공급자별 인증 설정·키·개인 계정 파일은 복사하지 않는다. 게임 소스나 원본 IPA를 스킬 꾸러미에 넣지 않았다.
