# 한·영 원고 갱신

방문자 문서의 한국어·영어 경로는 [대응 목록](scope.json)에 있다. 개발 정본·스킬·사용자 제공 원문·과거 검사는 번역 대상에서 제외했다.

1. 최신 main을 가져와 사용자가 직접 고친 원문과 현재 작업을 비교한다.
2. 해당 언어판의 문단·인칭·비유·비판·수치·완료 상태를 대조해 수정한다. 원고를 요약하거나 임의로 순화하지 않는다. 개발자의 변 국문은 사용자 최종본을 따른다.
3. 명령·복원 코드는 보존한다. 셸 주석과 인수 자리표시자는 번역할 수 있다. 그림은 같은 파일을 쓰고 캡션만 번역한다.
4. 영문에서 번역 대상 문서를 연결할 때 영어 경로와 영어 절 앵커를 쓴다. 번역하지 않는 검사 근거는 원래 기록으로 연결한다.
5. 두 본문을 읽고 검토한 뒤 `manifest.json`의 해당 파일 SHA-256을 갱신한다. 해시만 갱신해 미번역 상태를 숨기지 않는다.
6. `python3 tools/check_translations.py`와 `python3 tools/document_contract.py check`를 실행한다. 각 문서의 언어 선택과 주요 링크도 실제 GitHub에서 누른다.

“돈은 이승에서나 필요한 것이다”는 HeavyMach1에서 채택한 “Money is only needed in this life.”를 사용한다. 날짜의 숫자가 영문 월 이름으로 바뀌거나 “5개”가 “five”가 되는 차이는 의미를 대조한다.

CI는 대응 파일·검토 해시·언어 링크·명령 블록·내부 경로와 앵커를 검사한다. 문장의 뜻과 저자 어조는 사람이 읽는 방식으로 대조해야 한다. 내부 개발 문서만 바뀌면 방문자 번역을 다시 쓰지 않는다.
