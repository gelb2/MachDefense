# 포팅판 플레이 관측과 재개발 비교 항목

2026-11-04. 기준은 아이폰에 설치한 Mach Defense 1.0.5 호환 실행판이다. 사용자 실기기 관측과 Codex의 시뮬레이터 검사, 정적 파일 비교를 구분한다. 사용자가 플레이 중인 아이폰은 종료·재설치·저장 변경을 하지 않는다.

## 사용자 실기기 확인

| ID | 사용자 관측 | 상태 | 재개발판에서 대조할 동작 |
|---|---|---|---|
| MD-PLAY-01 | 적 유닛을 부술 수 있다. | 사용자 확인 완료 | 생산·이동·공격·피해·파괴와 효과음/효과 |
| MD-PLAY-02 | 적 기지를 부수고 미션을 클리어할 수 있다. | 사용자 확인 완료 | 기지 파괴→원본 승리 판정→미션 클리어 화면 |
| MD-PLAY-03 | 아군 기지 파괴 후 미션 실패 창에 진입하고 미션 선택 화면으로 돌아간다. | 사용자 확인 완료 | 아군 기지 파괴→패배 판정→실패 창→미션 선택 |
| MD-UI-01 | 생산 가능한 유닛의 가격 표시가 보이지 않는다. | 원인 조사 중 | 생산 버튼 가격의 유무·위치·표기·값·갱신 시점 |

| MD-ART-01 | 메인게임의 적·아군 유닛이 자글자글하게 렌더링된다. | 판본/배율 비교 필요 | 정지·이동·회전 중 텍스처·외곽선·부품 경계, 기기별 배율·필터 |

사용자는 가격과 한글 이름이 현재 판본만의 상태인지 다른 원본 판본에서도 같은지 확인하도록 지시했다. 유닛 화질도 다른 판본과 비교하고 HD판/일반판의 에셋 차이를 확인하도록 지시했다. 확인 전에는 글자를 영문으로 교체하거나 가격 UI를 새로 만들거나 유닛 그림을 다시 그리지 않는다.

위 관측에서 미션 번호·전체 캠페인 완료·클리어 후 다음 스테이지 진입까지 확인됐다고 확대하지 않는다. 다음 스테이지 진입과 보상·저장 유지는 별도 검사한다.

## 현재 확인한 판본과 에셋

확보한 MachDefense는 indieapps 1.0.3, indieapps 1.0.5, WeMade 1.0.3이다. 세 패키지 모두 iPhone/iPad 지원 정보가 있다. 별도 MachDefense HD 패키지는 현재 확보 목록에서 확인되지 않았다. HeavyMach 2/HD 구분을 MachDefense에도 있다고 가정하지 않는다.

2026-11-04 로컬 ZIP 비교 결과:

| 비교 | PNG 개수 | 1.0.5와 이름이 같은 PNG | 그중 해시·크기가 다른 파일 |
|---|---:|---:|---|
| indieapps 1.0.3 | 936 | 934 | Default, EnemyGauge, Icon114, Icon57, Icon72 |
| indieapps 1.0.5 | 942 | 942 | 기준 판본 |
| WeMade 1.0.3 | 948 | 939 | Default-Landscape~ipad, Default-Portrait~ipad, Default, Default@2x, MachButton |

`GameUI_MachSlot.png`, `GameUI_BuildSlot.png`, `MachBuild_Name.tble`, `MachBuild_Parts.tble`는 세 판본에서 바이트 해시가 같다. `iPad_`, `iPon_`, `@2x` 자원은 한 패키지 안에도 있다. 공통 PNG의 일치는 런타임의 에셋 선택·합성·필터까지 같다는 증거는 아니다. WeMade의 MachButton 차이와 각 판본에만 존재하는 자원도 함께 추적한다.

현재 `Compatibility/MachDefense_options.txt`에는 `--device-family=iphone`이 있다. 시뮬레이터가 iPad여도 게스트 게임은 iPhone 모드로 실행한다. 자글거림의 원인으로 확정하지 않았으며, 원본의 기기별 분기와 비교할 항목이다.

## 구매 당시 영문 표시와 현재 포팅 기준 — 2026-11-04 추가

사용자는 캐나다 계정과 미국 계정으로 구매해 플레이했을 때 유닛 이름을 포함한 모든 화면이 영문이었다고 확인했다. 구매 당시 정확한 버전과 기기의 언어·지역 설정은 아직 확인하지 않았다. 이 관측을 MD-UI-02의 원본 비교 기준으로 추가한다.

현재 포팅판은 `Mach_Defense v1.0.5 - (kr.indieapps.MachDefense).ipa`를 사용한다. 로컬 아이폰 빌드에 포함된 `MachDefense.ipa`의 SHA-256도 기준 파일의 `2c3e9aba0d249827da95c557f905762e3e2df08f79602f5404f93aa8f4c3d052`와 일치했다. WeMade 1.0.3을 포팅한 앱은 아니다. 이 확인에서는 사용자가 플레이 중인 아이폰을 조작하지 않았다.

세 판본의 `CFBundleDevelopmentRegion`은 모두 `English`다. 패키지 목록에서는 `.lproj`·`.strings` 및 English/Korean/localization/language 이름의 별도 자원을 찾지 못했다. 게임 자체의 테이블·이미지·실행 코드에 언어가 들어 있을 가능성은 남아 있다.

시뮬레이터 치트앱의 기존 실행 로그에는 게임이 현재 지역과 선호 언어를 요청하고, 호환 실행기가 지역 `KR`, 선호 언어 `ko, en`을 전달한 기록이 있다. 호환 실행기의 `NSLocale` 구현은 기본적으로 시스템 언어·지역을 읽으며 `--preferred-languages=`로 검사 언어를 지정할 수 있다. 현재 앱 옵션에는 언어 지정이 없다. 기기 언어에 따른 한글 선택 가능성이 있으나, 생산 아이콘의 한글을 선택하는 함수까지 확인한 결과는 아니다. 시뮬레이터의 설정을 실제 아이폰의 설정으로 간주하지 않는다.

후속 검사는 다음 순서로 진행한다.

1. 같은 1.0.5와 같은 저장 사본에서 한국어·영어를 바꾸어 생산 아이콘·가격·도움말·메뉴를 비교한다. 치트앱에서만 설정을 바꾼다.
2. 새 슬롯과 기존 슬롯을 비교한다. 원본의 `initSlotWithName:Country:`와 저장 국가 값이 표시 언어에 관여하는지 확인한다.
3. 언어와 지역을 따로 비교한다. 영어/KR·영어/US·영어/CA 조건의 차이를 조사하고, App Store 구매 국가와 기기 지역을 혼동하지 않는다.
4. 같은 조건으로 indieapps 1.0.3과 WeMade 1.0.3을 대조한다. 이름의 출처가 문자열인지 이미지인지, 가격과 이름이 같은 합성 경로를 쓰는지 확인한다.
5. 재개발판에는 확인된 원본 영문 자원과 다국어 선택 절차를 반영한다. 공용 그림과 언어별 글자·이미지를 구분해 관리한다. 원본 영문을 확인하기 전에 새 번역으로 대체하지 않는다.

근거: `.local/cheat-validation/language-package-inventory.json`, `run-upgrade.log`의 `NSLocale` 기록, 외부 빌드의 `src/frameworks/foundation/ns_locale.rs`, `Compatibility/MachDefense_options.txt`.

## 이어서 검사할 내용

- MD-UI-01: `DlgBuildMach refreshButtonsWithType:`의 버튼 합성과 가격 텍스트 생성·렌더 위치를 추적한다. 가격 원본 값과 표시는 별개로 확인한다. 숫자 에셋, 합성 컨텍스트, 크롭, 겹침을 비교한다.
- MD-UI-02: 세 판본의 실제 생산 버튼 자원, 국가/언어 설정 및 문자열 테이블을 대조한다. 원본 한글과 포팅 중 대체된 폰트를 구분한다.
- MD-ART-01: 동일 유닛·부품을 원본 크기와 실제 화면 크기로 비교한다. iPhone/iPad·Retina 에셋 선택, 썸네일/파츠 합성 해상도, 텍스처 min/mag 필터, 확대 배율, 소수점 좌표·피벗을 확인한다. 테스트 설정을 바꾸는 경우 시뮬레이터 치트앱에만 적용한다.
- MD-PLAY-02/03: 치트앱에서도 직접 재현하여 결과 버튼·다음 스테이지·재도전·저장·앱 재시작까지 확인한다.

## 재개발 단계에서의 사용

[복원 계획](restoration-plan.md)과 [치트 검증 계획](compatibility-cheat-validation-plan.md)에 따라 포팅판을 먼저 검증한다. 각 ID에 원본 판본·함수·자원·입력·관측 결과·수정 파일을 연결한다. 재개발 착수와 그래픽/좌표/UI 변경 때 이 문서를 읽는다. 재개발판과 포팅판의 차이는 같은 맵·장비·언어·논리 화면 조건으로 비교한 뒤 화면 크기 대응을 확인한다.

로컬 근거는 `.local/cheat-validation/ui-version-comparison.json`, `png-version-comparison.json`, `.local/build-buttons.asm`이다. 원본·추출 실행 파일·에셋 사본은 저장소 밖에 유지한다. 원본 패키지 목록과 해시는 [원본 명세](source-provenance.md)를 따른다.
