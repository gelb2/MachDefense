# 전체 무기·미션 검증

원본의 전체 유닛·무기·스킬·미션 목록을 먼저 작성한다. 각 항목의 생성·이동·공격·피격·파괴·보상과 스테이지 시작/종료·성장·업그레이드·재실행 복원을 대조한다. 치트 앱은 같은 게임 로직을 호출하고 초기 조건만 제공한다. 일반 앱도 별도 검사한다. 특정 장면 성공으로 전체 목록을 통과 처리하지 않는다.

현재 C++ 재개발판의 기능 대조와 실기기 검사를 진행 중이다. [현재 작업 순서](usability-todo.md#현재-작업-순서--2026-11-04-ipad-수정본-기준)와 [트러블슈팅](troubleshooting.md)을 함께 따른다. 아래 포팅판 검사는 당시 결과다.

## 실기기 전체 무기 측정

기지 기관총의 오디오 컨텍스트 오류를 고친 뒤 iPad에서 248.82초·14,912프레임을 수집했다. 전체 무기 측정은 아직 남았다. [측정 결과](troubleshooting.md).

1. 원본 무장·특수기술 표에서 무기와 강화 단계 목록을 만든다. 기지·아군·적 사용자를 함께 기록한다.
2. 치트 앱에서 같은 미션·배치·강화 조건으로 발사 전 대기, 최초 발사, 반복·동시 사격, 명중·폭발을 검사한다.
3. 프레임 간격·게임 계산·렌더 제출·오디오 호출·텍스처 업로드·저장 쓰기를 기록한다. 검사용 수치는 메모리에 모으고 전투를 멈춘 뒤 내보낸다.
4. 지연이 있는 조건을 Instruments로 조사하고 수정 후 같은 조건으로 다시 측정한다. 모든 항목에 실행 여부와 근거 파일을 남긴다.
5. 일반 앱의 실제 버튼 조작, 오디오 중단·복귀, 저장·재실행을 확인한다. 검사 후 앱 종료와 홈 화면 복귀를 확인한다.

세부 완료 기준은 [MD-PERF-01~05와 MD-AUDIO-01~03](usability-todo.md#전체-무기-프레임-검사--2026-11-04-사용자-지시)을 따른다.
